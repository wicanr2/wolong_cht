# 08 — `SINARIO.DAT` / `SAVE.DAT`：劇本與存檔

**狀態：整體結構 confirmed，武將能力值 confirmed，其餘欄位進行中。**

- 日期：2026-08-07
- 兩檔**大小相同（88,832 B）、結構相同**，`cmp` 差 12,566 byte。
  `SINARIO.DAT` 是四個劇本的初始狀態，`SAVE.DAT` 是玩家存檔。

## 1. 檔案 ＝ 4 個劇本區塊 × 22,208 B

```
4 × 0x56C0 = 0x15B00 = 88,832   ← 完全等於檔案大小
```

| 劇本 | 區塊起點 | 據點表 | 武將表 |
|---|---|---|---|
| 1 呂布歸天 | `0x00000` | `0x008C0` | `0x042C0` |
| 2 赤壁之戰 | `0x056C0` | `0x05F80` | `0x09980` |
| 3 蜀地偏安 | `0x0AD80` | `0x0B640` | `0x0F040` |
| 4 劉禪繼位 | `0x10440` | `0x10D00` | `0x14700` |

區塊內固定佈局（相對區塊起點）：

| 偏移 | 長度 | 內容 |
|---|---:|---|
| `+0x0000` | 2,240 | 未解。劇本標題在 `+0x40`（「第一章」「呂布歸天」） |
| `+0x08C0` | 6,144 | **據點表：192 筆 × 32 B** |
| `+0x1EC0` | 7,168 | 未解 |
| `+0x3AC0`…`+0x42C0` | — | 未解 |
| `+0x42C0` | 4,096 | **武將表：127 筆 × 32 B**（第 127 筆是空的終止筆） |
| `+0x52C0` | 1,024 | 全零 |

**192 個據點**與維基說的「城池 192 個」一致 ✅

## 2. ⚠ 武將是 127 人，不是 146

社群資料（維基）寫「武將 146 人」。**一手資料是每個劇本 127 人**
（第 127 筆全零，之後也全零）。

可能的解釋：146 是四個劇本的**聯集**，或包含君主／不可用武將。
**沒查證前不要引用 146。**（`CLAUDE.md` §5：一手資料贏二手推論。）

**委任戰術時 AI 的指揮品質由 `+18` 決定**。

## 5. 武將名單隨劇本變化，而且符合史實

| 劇本 | 前八名 |
|---|---|
| 1 呂布歸天 | 袁胤、袁尚、袁紹、袁術、袁譚、王朗、郭汜、韓玄 |
| 2 赤壁之戰 | 王朗、韓玄、金旋、曹叡、曹彰、曹植、曹操、曹丕 |
| 3 蜀地偏安 | 王朗、曹叡、曹彰、曹植、曹操、曹丕、孫桓、孫權 |
| 4 劉禪繼位 | 王朗、曹叡、曹植、曹丕、孫桓、孫權、孫韶、孫瑜 |

袁氏在劇本 2 消失（官渡後）、韓玄金旋在劇本 3 消失、
**曹操與曹彰在劇本 4 消失**（曹操卒於 220 年，劉禪 223 年繼位）。

**這本身就是一條驗證**：名單的變化符合史實，代表劇本區塊的切分是對的。
