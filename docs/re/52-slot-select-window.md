就是這個視窗換一個標題（§2）。**

## 1. 視窗與靜態層

```asm
sub_18BD1(al = 模式):
  ax = al × 13h + 98C8h            ; ← 標題表，每筆 19 bytes
  si = ax
  al = 1Fh / dx = 6 / bx = 3 / cx = 0F13h
  sub_1895D                        ; 框 (96, 80) 304×240
  al = 6 / dx = 68h / bx = 58h
  sub_10337                        ; 場景 6，原點 (104, 88)
  ax = 0F03h / dx = 0B8h / bx = 5Bh
  sub_106F5                        ; 標題 → (184, 91)
  al = 20h / bx = 90h / cx = 4
  loop: sub_1E3D7(al, bx, dx=100h, cx=20Fh)   ; 熱區 (256, 144+48k) 120×16
        al++ / bx += 30h
```

| 元件 | 座標 | op |
|---|---|---|
| 名稱欄 ×4 | (120, 118／166／214／262) 256×20 | 03 |
| 日期欄 ×4 | (256, 144／192／240／288) 120×16 | 03 |
| 日期欄的外框 ×4 | 每個兩筆，(254,142)／(255,143) 起 | **04**（矩形外框，立體邊）|
| 水平分隔線 | (104, 111) 長 287 色 `0x0F` | **05** |
| 「年　月　日」×4 | (288, 144／192／240／288) | 08，色 `0x00` |
| 標題 | (184, 91) | `sub_106F5` |

**四個熱區 `0x20`–`0x23` 與四個日期欄逐格重合**——可點的是右邊那一格，
左邊的名稱欄只是顯示。

## 2. ⭐ 三個標題，同一個視窗

`ds:98C8` 起每筆 19 bytes（16 個全形字 ＋ 終止）：

| 模式 | 標題 | 呼叫端 |
|---:|---|---|
| 0 | `ＮＥＷ　ＧＡＭＥ　` | `sub_18B12` |
| 1 | `ＬＯＡＤ　ＤＡＴＡ` | `sub_18B40` |
| 2 | `ＳＡＶＥ　ＤＡＴＡ` | `sub_18B5D` |

**所以原版沒有獨立的「選劇本」畫面**：新遊戲時這四個槽是
`SINARIO.DAT` 的四個劇本，讀取／儲存時是 `SAVE.DAT` 的四個存檔。
名稱、年、月、日的位置與判讀完全一樣——**同一份版面讀兩個檔**。

## 3. 哪些槽不能選

```asm
sub_18B7C(al = 模式):
  bp = ax
  sub_18BD1 / sub_18C20            ; 畫框與內容
  ds = ds:987Ch                    ; ← 讀進來的四筆槽頭
  等待:
    sub_121E7 / jb → 取消
    sub_1E453 / sub al, 20h
    jb → 等待                       ; 熱區不是這四個
    cmp bp, 2 / jz → 接受           ; ⭐ 模式 2（SAVE）任何槽都能選
    bx = 槽 × 128
    cmp word [bx+40h], 0D0A1h
    jz → 等待                       ; ⭐ 名稱是「空槽」標記就不能選
  接受: clc
```

`+0x40` 是名稱欄位，`0xD0A1` 是它的第一個全形字。
**只有儲存可以覆蓋空槽**，新遊戲與讀取都要求槽裡有東西。

## 4. `sub_18C20`：四個槽的內容

```asm
bx = ds:987Ch / si = 0 / ax = 0 / cx = 0 / bp = 4 / di = 80h
loop: sub_1E38C                    ; 讀 0x80 bytes 到 [bx:si]
      si += 80h / ax += 56C0h / adc cx, 0    ; ← 檔內位移每筆 +0x56C0
      dec bp / jnz loop
ds = ds:987Ch / si = 0 / di = 2D21h / bx = 78h / cx = 4
loop: 名稱 si+40h → sub_106F5(dx=78h, bx)          ; (120, Y)，色 09
      [si+6] → sub_1062F(bx=5003h, di)             ; 年，3 位
      [si+4] → sub_1062F(bx=5002h, di+5)           ; 月，2 位
      [si]   → sub_1062F(bx=5002h, di+9)           ; 日，2 位
      si += 80h / bx += 30h / di += 0EF7h
```

**每個槽只讀前 128 bytes**，四筆在檔案裡相隔 `0x56C0` ＝ 22,208 bytes。
欄位與 [`../formats/08`](../formats/08-sinario-save.md) 的區塊頭一致：
`+0x00` 日、`+0x04` 月、`+0x06` 年、`+0x40` 名稱。

| 值 | 座標（第一槽）| 位數 | 色 |
|---|---|---:|---|
| 名稱 | (120, 120) | — | `0x09` |
| 年 | (264, 144) | 3 | `0x05` |
| 月 | (304, 144) | 2 | `0x05` |
| 日 | (336, 144) | 2 | `0x05` |

`di` 的三次位移 `+5`／`+4` 是 VRAM byte 數，換算成 X 是 `+40`／`+32`——
年、月、日三個數字正好各自嵌在「年　月　日」那三個字的前面。
每槽 `+0xEF7` ＝ 往下 48 px 再回到年的位置。
