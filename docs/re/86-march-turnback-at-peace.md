# 86 — 和平就出不了兵：軍團走到別人的邊界會自己掉頭

**狀態：confirmed（機器碼 ＋ 執行期逐日追蹤）。**
`sub_142AB` **不是**「玩家下行軍令」的寫入端——它的唯一呼叫者是
`sub_12662`（每 tick 的軍團更新），而且只在**軍團走在野外路徑上**時被呼叫。
它做的是一件玩法層的事：**前方那一端的據點若屬於別的勢力、不是中立，
而我方與那個勢力處於和平，就把目標換成路的另一端**——軍團掉頭。

⇒ **沒有交戰就進不去別人的地盤。** 指令下得成、訊息也跳「向{2}移動下」，
但軍團會在邊界上折返，回到最後一個自家據點停住。

## 1. `sub_142AB`（85 B）：掉頭判定

```asm
000142AB  push di / push bp
000142AD  mov  bp, bx                    ; bx ＝ 目前所在的「路」記錄
000142AF  xor  di, di
000142B1  cmp  byte ptr [si+0Ah], 0FCh   ; +0x0A ＝ 路徑步進量（−4／+4）
000142B5  jz   +2
000142B7  inc  di / inc  di              ; di ＝ 0 或 2：前方是路的哪一端
000142B9  mov  bx, es:[bx+di+6]          ; 那一端的據點編號 × 8
000142BD  shl  bx,1 / shl bx,1           ; ×4 → 據點記錄偏移（32 B 一筆）
000142C1  mov  dl, [si+1]                ; 軍團所屬勢力
000142C4  mov  al, [bx+841h]             ; 前方據點的所屬勢力
000142C8  cmp  al, dl  / jz  → 不動      ; ← 自己的地盤，過
000142CC  cmp  al, 18h / jz  → 不動      ; ← 中立（24），過
000142D0  dx = 勢力 × 24 ; bx = 600h + dx
000142E2  xlat                            ; al ＝ 交友度[我方][前方勢力]
000142E3  cmp  al, 80h / jb → 不動        ; ← 最高位元 0 ＝ 交戰中，過
000142E7  xor  di, 2                      ; ★ 換成路的另一端
000142EA  mov  bx, es:[bp+di+6]
000142EE  mov  [si+14h], bx               ;   目標據點 × 8
000142F1  shr  bx,1 ×3 / mov [si+20h], bl ;   目標據點（無縮放）
000142FA  or   byte ptr [si], 2           ;   下一步要重算
```

三個「過」的條件與一個「掉頭」的條件，合起來就是一條規則：

> **軍團只能走進：自己的據點、中立的據點、以及正在交戰的勢力的據點。**

交友度的最高位元 **1 ＝ 和平、0 ＝ 交戰**
（[`../formats/08`](../formats/08-sinario-save.md) §1.5），所以
`cmp al, 80h / jb` 讀成「交戰中才放行」。

## 2. 呼叫點：只有在野外才問

```asm
; sub_12662（軍團到站／推進），每 tick 由 sub_125A3 叫
00012662  bx = [si+0Eh] / cmp bx, [si+14h] / jz → 到站
0001267D  cmp bx, 800h          ; 0x800 ＝ 256 × 8
00012681  jnb → sub_142AB       ; ★ ≥ 0x800 ＝ 在野外的路上
00012683  al = [si+1] / cmp al, cs:byte_10CFF
0001268B  jz  → 12697           ; ★ 玩家的軍團：站在據點上時什麼都不判
0001268D  call sub_14300        ; AI：站在據點上時要不要留下來守
```

⇒ **掉頭只在路上發生，不在據點上。** 所以症狀是「軍團走出城、走一段、
折回來、停在上一個城」，而不是「指令被拒絕」。

## 4. ⚠ 推翻：`sub_142AB` 不是玩家下令的寫入端

本專案先前把 `sub_142AB` 記成「玩家下行軍令時寫 `+0x14`／`+0x20`」
（[`34`](34-corps-status-bits.md) §2.1、[`08`](08-hourly-update.md) §7、
[`27`](27-list-row-fields.md) §7.2、[`40`](40-garrison-relief-request.md) §5）。
**呼叫者只有 `sub_12662` 一支**，玩家下令走的是 `sub_17FDB`
（[`45`](45-corps-command-mode.md) §1），而那一支只寫 `+0x20` 與 `+0x0B`。

它示範的 **`+0x20` ＝ `+0x14` ÷ 8** 這個關係仍然成立——
錯的是「誰在什麼時候呼叫它」，不是它寫了什麼。
