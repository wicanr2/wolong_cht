## 3. ⭐ 沒命名的軍師不能直接「確定」

```asm
sub_1E453 / sub al, 20h
jb → 回去等
ja → 回傳 al                      ; 熱區 0x21（自定）→ al = 1
; al == 0（確定）
cmp byte [si+2], 7Fh / jnz → 回傳  ; 軍師欄不是 0x7F（無）→ 回傳 0
cmp word ds:5222h, 0D0A1h / jnz → 回傳
al = 1                             ; ⭐ 兩者都成立就當成「自定」
```

`0x7F` 是「沒有軍師」（[`../formats/08`](../formats/08-sinario-save.md) 勢力 `+0x02`），
`0xD0A1` 是空字串標記（與四槽視窗判空槽用的是同一個值，
[`52`](52-slot-select-window.md) §3）。

**所以按「確定」但軍師欄是空的、名字也還沒取，就會被導去命名畫面**
（場景 9 的注音輸入）。回傳值 0 ＝ 確定、1 ＝ 自定。

右鍵取消走 `sub_18F7C` 並 `stc`。

## 4. ⭐ `ds:5222h` 是自訂軍師名的緩衝區（2026-08-23）

先前這一欄標「推測，配置端未讀」。用 `tools/ida_disp_users.py` 掃位移 `5222`
掃出六處，六處合起來就把它定住了：

| 位址 | 動作 |
|---|---|
| `sub_1905E` `00019062` | `mov word ptr [si+5222h], 40A1h` ← 初始化 |
| `sub_1906E` `00019075` | 同上 |
| `sub_190C0` `0001911E` | `mov [si+5222h], ax` ← **實際寫入名字** |
| `sub_1915B` `00019168` | `mov si, 5222h` ← 讀 |
| `sub_19223` `0001922D` | `mov si, 5222h` ← 讀 |
| `sub_18F7C` `00018F8A` | `mov bx, 5222h` ← 取消時擦除 |

⭐ `40A1h` 這個初值本身就是證據：little-endian 存成 bytes 是 `A1 40`，
**Big5 的全形空白**。所以那塊是一個以全形空白填初值的字串緩衝區，
與 §3 拿 `0xD0A1` 判「名字還是空的」對得起來。

⚠ **為什麼線性 xref 掃不到它。** `ds:5222h` 是**執行期段內位移**，
不是映像裡的位址——IDA 的 xref 只涵蓋直接位址參考，
`基址暫存器 + 常數位移` 完全不在裡面。第一次用 `XrefsTo(0x15222)` 掃回零筆，
而那個零是**掃描條件錯**不是「沒有人用」（同 `docs/re/30` §6 的坑）。
