## 1. 呼叫鏈

```
sub_19FA0 → sub_1A1C5（0001A1C5）
  等 50 tick
  cmp byte_1D34B, 1 ；≠1 → 直接 retn（整段開場喊話都不會發生）
  call sub_1A2E8    ；挑戰段（§2）。CF=1 → 跳到決著段
  [si+1Bh]=[di+1Bh]=8 ；兩側大將命令＝8（單挑）
  word_1D31F = 0     ；互嗆情境歸零
loc_1A1F1:           ；單挑回合迴圈（§4）
  call sub_1A3C3     ；互嗆 pair（§3）
  call sub_1A298     ；（未讀）
  兩大將移到 (0x18,0x20)／(0x28,0x20) 對峙
  等 20 tick × 判 [±3] 體力 < 0x46 就跳決著
  word_1D31F++（上限 4）→ 迴圈
決著（loc_1A23F）：體力高的一方為勝者；敗方說 0x1CC、勝方說 0x1CD
```

## 2. `sub_1A2E8`：挑戰段（已實作）

```asm
si=0 / di=0x600                    ; 兩側戰場記錄
ax = sub_1A34F(si) / bx = sub_1A34F(di)   ; 氣勢評估（§2.1）
若 ax < bx：交換（si ＝ 氣勢高的一方），dl 記側
若 ax ≥ 0x12C0（4800）：
    強側說組 0x1B7（sub_1A398：喊話 ＋ 把該側大將移到單挑位、命令＝8、等 40）
    word_1D311 += 6
    若 bx < 0x12C0 或 bx < ax/2：
        弱側說 0x1B9、等 20、強側說 0x1CC   ; 拒戰（弱方不接受單挑）
    否則（勢均）：走 loc_1A341（未讀完，推定接受單挑 → 回到 §1 的迴圈）
```

### 2.1 `sub_1A34F`：氣勢評估**帶亂數**

核心是 `[bx+0x18]（隊長隊兵數）× [bx+3]（大將體力）`；之後還有
兩次 `sub_1ECE0`（亂數）：門檻 `rand&7 + 8` 比不過就把整個值**歸零**、
最後再加 `(rand&7)<<8`。**開場喊不喊話、誰喊，在邊界情況下是擲骰的**——
這一段是 `CLAUDE.md` §5 要求「亂數介入要當場記」的案例。

## 3. `sub_1A3C3`：互嗆 pair（單挑回合內）

```
ax = 0x1BA                          ; 第 0 回合的 pair
dl = word_1D31F 低 byte；≠0 時：
    dx = 0x1BC + (dl−1)×4           ; 回合 1–4 各佔 4 組
    |[si+3] − [di+3]| < 0x14 → dx += 2   ; 體力差 < 20 用「勢均」pair
第一句 cx=dx（氣勢高側）、第二句 cx=dx+1（另一側）
```

⚠ **`0x1BA`／`0x1BB` 是單挑回合的互嗆，不是一般開戰對白。**
remake 先前把它當成無條件的開場 pair，內容與時機都錯。
