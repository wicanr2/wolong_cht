## 2. 這一輪才讀的

### 2.1 交友度矩陣的雙向索引：`sub_13697`（45 B）

```asm
bx = al × 24 + ah        ; shl×3 得 ×8，再 shl 一次相加 ＝ ×24
si = bx
bx = ah × 24 + al        ; 反過來一次
```

**24 × 24 的方陣，兩個方向各存一格。** `si` 與 `bx` 同時回傳，
上層要改「A 對 B」與「B 對 A」時不必算兩次。

### 2.2 交戰狀態同步：`sub_13669`（46 B）

```asm
cmp al, 18h / retn ; cmp ah, 18h / retn     ; 勢力 24 ＝ 無所屬，直接跳出
call sub_13697                              ; 兩個方向的位址
cl = [si+600h] ; ch = [bx+600h]
cl = min(cl, ch) | 0x80                     ; ★ 取**低**的那一個，並設位元 7
[si+600h] = [bx+600h] = cl
```

⭐ **雙向拉齊時取的是較低的那個值**，然後把位元 7（和平位元）設起來。
`+0x600` 是同一個矩陣段裡的第二張表。

### 2.3 停戰／滅亡的兩支清理

| 函式 | bytes | 做什麼 |
|---|---:|---|
| `sub_145F8` | 37 | 兩個勢力（`al`、`ah`）的記錄裡，`+0x19` 若指著對方就寫回 `0xFF`。索引是 `編號 × 0x40`——勢力記錄 64 B（[`62`](62-strategy-minimap.md)）|
| `sub_14236` | 51 | 掃 192 筆據點（`0x840` 起，stride `0x20`）：據點屬於 `al`／`ah` 其中一方，而 `+0x1A` 也指著這兩方之一時，`+0x1A ← +0x01`（改回自己）|

兩支的呼叫端相同：`sub_13262`、`sub_13327`（開戰／停戰）與
`sub_14FCE`（滅亡）。**互指的攻擊目標在關係結束時要一起解開**，
否則會留下指向已消失對象的欄位。

### 2.4 ⭐ 遷都：`sub_133FD`（136 B）——報告要有外交官才收得到

```asm
sub ax, 840h / shl ax,1 ×3 / mov al, ah      ; 新首都的據點編號
xchg ah, [si+3]                              ; si ＝ 勢力記錄，+0x03 ＝ 首都
cmp al, ah / jz retn                         ; 沒換就什麼都不做
call sub_14502                               ; 掛舊首都的軍團改掛新首都
cmp si, cs:word_10CFD / jnz loc_13449        ; ★ 這是玩家的勢力嗎
```

**是玩家**：君主（`[si+1]`）用自己的說話型講 `cx = 0x1A4`
——展開後是訊息 **518–520**（「將首都移{2}，立刻準備！！」）。

**不是玩家**：先看 `[si+2Ah]`，那是**派駐該勢力的外交官**
（[`07`](07-monthly-settlement.md) §「勢力 `+0x2A`」）。

```asm
mov ch, [si+2Ah]
cmp ch, 0FFh / jz retn                       ; ★ 沒有外交官 → 一句話都不報
```

有外交官才播兩則：先 `cx = 0x39`（**#57**「駐{3}勢力的外交官{1}大人
前來報告。」），再 `cx = 0x1A4` 配外交官自己的說話型 `[di+1Eh]`
——展開後是訊息 **521–525**（「{3}遷都到{6}{2}了，特此報告」）。

⭐ **所以「別的勢力遷都了」是一則情報，不是公開事實**：
沒有在那邊佈外交官就完全看不到。這與說明書把外交官寫成
「外交行動的前置佈署」（[`../mechanics/50-diplomacy.md`](../mechanics/50-diplomacy.md) §3）
是同一件事的另一面——**外交官也是情報站**。

### 2.5 軍團的行進方向：`sub_12808`（41 B）＋ `sub_127F6`（14 B）

```asm
sub_12808:
  ax += [si+0Ch]            ; 目前道路節點指標
  ax = [si+10h] − es:[bx]   ; 目標 X − 節點 X
  若不為 0 → [si+8] = 符號位元 rol 1          ; 0 或 1
  若為 0   → 改比 Y（[si+12h] 對 es:[bx+2]），結果 +2   ; 2 或 3
```

`+0x08` 是**四向的朝向**（X 差優先，相等才看 Y），
由與下一個道路節點的相對位置決定。

`sub_127F6` 是**掉頭**：把 `[si+0Ah]` 取負代進同一支，再 `xor [si+8], 1`
把左右翻面。呼叫端是 `sub_12662`／`sub_12708`（行軍主流程，
[`09`](09-combat.md)、[`64`](64-corps-arrival-state-machine.md)）。

### 2.6 `sub_12438`（33 B）：把一筆登記作廢

掃 `0x2040`–`0x2140`（16 筆 × 16 B），`[si] ≥ 0x80` 且
`[si+2] == dx` 且 `[si+4] == bx` 的那一筆 `[si] ← 0`。
呼叫端 `sub_134B1`。**那張 16 筆的表是什麼還沒查**（§3）。

### 2.7 檔案 I/O 的三支底層

| 函式 | bytes | 做什麼 |
|---|---:|---|
| `sub_1F69E` | 62 | **緩衝式逐 byte 讀檔**：`[bp+0]` 剩餘數、`[bp+2]` 緩衝索引、`[bp+4]` handle。緩衝空了就 `int 21h AH=3Fh` 補一批；讀到 0 byte 回 `ah = 0xFF`（EOF）|
| `sub_1F691` | 13 | `inc si`，溢位就 `ds += 0x1000`——**跨段的指標遞增** |
| `sub_1E364`／`sub_1E378` | 20 each | `sub_1F5E7`／`sub_1F4A2` 的**重試包裝**：失敗（CF set）就 `int 50h` 叫錯誤處理，然後跳回自己重試 |

`sub_1E364`／`sub_1E378` 的 `jmp short` 目標是函式自己的入口，
所以那是**無上限重試**——換句話說原版對開檔失敗的處置是「一直問使用者」。

### 2.8 `sub_1E6FF`（24 B）：登記一筆待繪

```asm
[si] = di ; [si+2] = bp ; [si+4] = cx ; [si+6] = ah ; [si+7] = al
es = dx ; es:[di] = cs:byte_1E47F
```

八個 byte 一筆，寫完順手在目的地先蓋一個標記 byte。
四個呼叫點都在 `0001E6B2`–`0001E6F6` 這段（沒有函式邊界，
`tools/ida_range.py` 才看得到）。
