## 1. `sub_1614A`：指令列 ＝ 一個框 ＋ 一串字

```asm
sub_101B4                        ; 繪圖前後的成對常式
or  ds:98A6h, 1                  ; 標記「指令列已畫」（[`42`](42-leaf-functions.md) §2）
al = 0Bh / dx = 0 / bx = 0 / cx = 21Bh
sub_1895D                        ; ← 框
si = 6181h / dx = 8 / bx = 28h / ax = 0F01h
sub_106F5                        ; ← 畫變長字串（[`33`](33-shared-draw-helpers.md) §1）
al = 0Ch / bx = 28h / dx = 18h / cx = 230h
sub_1E3D7                        ; ← 登記熱區 0x0C
sub_101DB
```

八個指令名是**文字**，來源 `cs:6181h`，用一般的字串繪製常式畫；
外框由 `sub_1895D` 的樣式 `0x0B` 畫。**沒有任何一次圖庫存取。**

> 所以 `ICONGRF` 段 1 與指令列無關。段 1 的消費者
> （`sub_1C7F4`／`sub_1C863`／`sub_1CA3B`／`sub_1CAA8`，
> [`../formats/03`](../formats/03-grf-images.md) §5.3）**全部落在
> `0x1C000` 的戰術區段**——那是戰術畫面的底列，不是大地圖的指令列。

## 2. `sub_1895D`：一次呼叫寫三個地方

`sub_1895D(al ＝ 樣式, bx ＝ X, dx ＝ Y, cx ＝ 尺寸)`：

```asm
si = bx / di = dx / bp = cx
ah = 0 ; al == 0 → ah = 1            ; 樣式 0 是「擦除」（[`24`](24-unread-function-catalogue.md) §2.1）
sub_1D5D4                            ; ① 格子屬性表
si += 2
if al != 0: sub_10C14(bx=si,dx=di,cx=bp)   ; ② 框線層
bx = si<<1 / dx = di<<1 / cx = bp<<1
if al != 0: ah = al
sub_189DE                            ; ③ → sub_1E3D7，熱區
```

**三層都不碰圖庫。**

| 層 | 目標 | 形狀 |
|---|---|---|
| ① `sub_1D5D4` | 段 `cs:word_1D84E` | 每格 8 bytes，列距 `0x140`（＝ 40 × 8）→ **40 欄的格子表**。樣式 0 設 `0x10`／清 `0x80`，其餘清 `0x10`／設 `0x60` |
| ② `sub_10C14` | 段 `cs:word_10D4A` | 用 `sub_10C60`（上下邊）與 `sub_10C77`（左右邊）各畫兩次——**四條邊分開畫**，`ax = 0801h` 是樣式參數 |
| ③ `sub_189DE` | `sub_1E3D7` | 座標各再 `<<3`（格 → 像素），登記熱區 |

③ 的 `shl ×3` 說明**①②的座標單位是 8 pixel 的格**，
而 `sub_1895D` 進來時的 `bx`／`dx` 又比它們少一次 `<<1`，
所以呼叫端傳的是**16 pixel 為單位的粗格**。

以指令列驗算：`bx = 0`、`dx = 0`、`cx = 0x021B` →
高 byte `0x02`、低 byte `0x1B`（27）。②③ 用的是 `cx<<1` ＝ `0x0436`，
即 4 列 × 54 欄的 8 px 格 ＝ **432 × 32 pixel**，落在 640×400 畫面的左上角。

## 3. 對 remake 的意義

`cmd/wlgame/strategyhud.go` 用 `chrome.Window` 畫外框、`vector.DrawFilledRect`
畫色標，證據來源是**壓縮過的參考影片**。原版的外框是格子層堆出來的，
兩者不可能逐像素相同。

> **要做畫面 parity，得先把 ①② 兩層的像素產生方式讀出來**，
> 而不是繼續調自繪矩形的顏色與座標。這是 `docs/playtest/20` 那種
> 「PARTIAL、幾何對得上但逐像素不對」的結構性原因。
