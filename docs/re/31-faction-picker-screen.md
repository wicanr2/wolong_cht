# 31 — 勢力選擇畫面：22 格的兩欄版面與選中狀態

**狀態：`sub_15AFC` 的版面、命中判定、顏色規則與兩個守門條件 confirmed。
畫詳情的兩支（`sub_15DBB`／`sub_15CC6`）內部未讀。**

- 日期：2026-08-13
- 範圍：只驗松崗 DOS/V
- 原始 `KI.EXE` SHA-256：`fffeba985231cda4d636e93d10f598470b1f691d00275e4aa38e285893d43868`
- 原始 `KI.EXE.i64` SHA-256：`7b7c1aa67c47f99062cfdd4439b3423302808c874f929c3ea6f75ec564034c26`
- 工具：IDA Pro 9.4，`tools/ida_corps_next.idc`（唯讀副本，跑完雜湊未變）
- 位址空間：IDA DOS/V linear address，segment base `0x10000`

`sub_15AFC`（264 B）是 [`21`](21-function-census.md) 的 T4 清單裡**最大的一支**，
先前只有「1 個呼叫者、沒有任何文件提過」這一行結構資料。
它是**選一個勢力**的畫面——外交、進言等需要指定對象的地方都會走到。

## 1. 外層

```asm
sub_15AD1:                       ; 由 sub_119CA 呼叫
  sub_15CA4 / sub_19528
  sub_18853(cx=4)                ; 狀態列 #4「以滑鼠的右鍵回復。」
  sub_15AFC                      ; ← 選擇畫面
  sub_18853(cx=0FFFFh)
  test cs:byte_198A6, 2
  jz → …
  sub_15E1E                      ; 重畫狀態畫面 #F
```

狀態列只掛一句「以滑鼠的右鍵回復。」——**這個畫面沒有「取消」按鈕，
右鍵就是唯一的退出路徑**。

## 2. 版面：22 格分兩欄

```asm
al = 0
loop:
  ah = 90h                       ; 一般
  cmp al, cs:byte_10CFF / jnz →
    ah = 9Ah                     ;   玩家自己
  cmp al, cs:byte_198A7 / jnz →
    ah = 93h                     ;   目前選中
  sub_15C14                      ; 畫這一列
  inc al / cmp al, 16h / jb loop ; 0 … 0x15
```

- **22 列**（`0x16`），與勢力表 22 筆一致。
- `ah` 是 [`28`](28-text-number-rendering.md) §2.1 那種「背景 4 位︰前景 4 位」的屬性：

  | 屬性 | 意義 |
  |---|---|
  | `0x90` | 一般（背景 9、前景 0）|
  | `0x9A` | **玩家自己的勢力** |
  | `0x93` | **目前選中的勢力** |

- **`cs:byte_198A7` 是「目前選中的勢力編號」**，`cs:byte_10CFF` 是玩家勢力編號
  （後者已由 [`../formats/08`](../formats/08-sinario-save.md) 定案）。

### 2.1 命中判定反推出版面

```asm
sub_1E453                        ; 熱區編號 → al；cx/dx ＝ 座標
cmp al, 20h / jnz → 忽略         ; 整個清單是同一個熱區 0x20
sub dx, 0D8h                     ; 扣掉清單頂端
cmp cx, 240h / jb →
  add dx, 0B0h                   ; ← 右欄：y 再加 0xB0
dx >>= 4                         ; 每列 16 像素
ax = dx                          ; ← 勢力編號
dx <<= 6                         ; ×64 → si ＝ 勢力記錄
```

- **整張清單只註冊一個熱區（`0x20`）**，是哪一列靠座標算，不是靠 22 個熱區。
- **兩欄**：`x ≥ 0x240` 算右欄，右欄的列號要加 `0xB0 ÷ 16 = 11`。
  所以左欄 11 列、右欄 11 列，合起來 22。
- 列高 16 像素，正好是一個全形字高
  （[`29`](29-font-service-int15.md) §4.3 的字型是 16×15，第 16 列空白）。

### 2.2 兩個守門條件

```asm
cmp byte ptr [si], 80h / jb → 忽略      ; 勢力不存在
cmp al, cs:byte_10CFF / jz → 忽略       ; 不能選自己
```

- 勢力存在旗標是 `+0x00 ≥ 0x80`，與
  [`../formats/08`](../formats/08-sinario-save.md) 一致——
  **不是拿君主欄當哨兵**，那條路會把在野武將誤認成君主。
- **點自己的勢力沒有反應**，不是報錯也不是提示。

選中時的三步：

```asm
sub_15C14(al=舊的 byte_198A7, ah=90h)   ; 舊的那列還原成一般色
cs:byte_198A7 = al                       ; 記下新的
sub_15C14(al=新的,        ah=93h)        ; 新的那列畫成選中色
sub_15DBB / sub_15CC6                    ; 右側詳情
```

**只重畫兩列，不重畫整張清單**——這是 16-bit 真實模式下常見的省法，
remake 若整張重畫不會有視覺差異，但要知道原版沒有全畫面刷新。

## 3. 進入畫面時畫了什麼

```asm
sub_1895D(al=1Fh, dx=20h, bx=0Ah, cx=0D08h)     ; 外框
sub_1E3D7(al=20h, dx=208h, bx=0D8h, cx=160Eh)   ; 熱區 0x20，涵蓋整張清單
sub_1F1A3(dx=208h, bx=0C8h, si=277h, di=0D7h, ah=7)   ; 圖塊
sub_1F1A3(dx=208h, bx=0D8h, si=277h, di=187h, ah=9)   ; 圖塊
sub_106F5(si=5C04h, dx=220h, bx=0C8h, ax=7001h)       ; cs 段的標題字串
```

畫框與熱區是同一組幾何（`sub_1895D` 尾端會呼叫寫熱區圖的常式，
見 [`24`](24-unread-function-catalogue.md) §2.1），所以框畫到哪、
可點區域就到哪——**這解釋了為什麼原版可以任意重疊視窗而不必重算命中判定**。
