## 2. 到站處理：`sub_14325` 與它的十二支

`sub_14325`（51 B）由 `sub_12662`（軍團到站）與 `sub_17F90`（玩家點自己的軍團）
呼叫，**碰據點表**，底下掛十二支：

```
sub_14370(45,據點) sub_1439D(18) sub_143AF(96,據點,亂數) sub_1440F(87)
sub_14466(29) sub_14483(22) sub_14499(16) sub_144A9(45,據點) sub_144D6(44,據點)
共用 sub_14548(45,據點)
```

`sub_14499` 再呼叫 `sub_1461D`（退兵回池 ＋ 重分配，[`30`](30-corps-formation-ui.md) §4.1）
與 `sub_16FD2`（重算派生值）；`sub_1463E` → `sub_14651`（碰**武將職務 ＋ 軍團**）
是解除編成那一條。

> **這一叢是「軍團走到據點之後會發生什麼」的完整清單。**
> 帶亂數的只有 `sub_143AF` 一支——所以到站的結果**大部分是決定性的**，
> 只有一個環節擲骰。

`sub_147BB`（192 B）同樣由 `sub_12662` 直接呼叫，是這一區第二大的未讀函式。
