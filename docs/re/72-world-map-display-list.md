`word_1D84C` 與 `MMAP.MCH` 的對應）與軍團那條資料流。

## 1. 四支串起來

| 位址 | 做什麼 |
|---|---|
| `sub_12AF4` | 掃整張軍團表：`si=2240h`、每筆 `0x40`、127 筆 |
| `sub_12B2A` | 取一支軍團的座標與圖塊編號 |
| `sub_1D4C7` | 把圖塊**推進顯示表**（不是畫）|
| `sub_1D66A` | 顯示表的 blitter，逐格把地形與疊圖畫出來 |

## 2. `sub_12AF4`：存在旗標是 `>= 0xC0`

```asm
mov     si, 2240h
mov     cx, 7Fh             ; 127 筆
loc_12B18:
cmp     byte ptr [si], 0C0h ; ← 軍團記錄 +0x00
jb      short loc_12B20     ; 小於就不畫
call    sub_12B2A
loc_12B20:
add     si, 40h
loop    loc_12B18
```

前面還有一輪掃 `test byte [si], 20h` → `sub_12B3C`（未讀，推測是擦除舊位置）。

## 3. `sub_1D4C7`：顯示表的結構

```asm
bx -= cs:word_1D856         ; 減鏡頭 Y，借位就不畫
cmp bx, 17h / jnb 不畫      ; 可視 23 列
dx -= cs:word_1D854         ; 減鏡頭 X，借位就不畫
cmp dx, 28h / jnb 不畫      ; 可視 40 行
bx = (Y*40 + X) * 8         ; 每格 8 bytes
ds = cs:word_1D84E          ; 顯示表段
bl = [si+1]                 ; 這格疊了幾張
cmp bl, 4 / jnb 不畫        ; ⭐ **推入端**最多 4 張
xchg al, [bx+si+3]          ; 疊到第 bl 層
[si+1] = bl + 1
若值有變 → or [si], 20h     ; 標記重畫
```

每格 8 bytes 的版面：`+0` 旗標、`+1` 疊了幾張、`+2` 地形圖塊、
**`+3`–`+7` 五個疊圖槽**。

⚠ **「五個槽」與「最多推 4 張」是兩件事，不要混。**
槽位有五個——`sub_1D66A` 收尾時 `mov [si+3], al` ＋ `mov [si+4], ax`
＋ `mov [si+6], ax` 填的正是 `+3`..`+7`，而清空迴圈跑到 `cmp bl, 8`。
但 `sub_1D4C7` 的守衛是 `cmp bl, 4 / jnb`，**第五個槽它永遠不會用到**。
第五個槽由誰填、或者只是留白，未讀。

## 4. ⭐ 兩個圖庫段差 `0x800`

`sub_1D66A` 畫的時候地形與疊圖用**不同的段**：

```asm
mov     ah, [si+2]              ; 地形
mov     ds, cs:word_1D84A       ; ← 地形圖庫
call    sub_1D7E7
mov     bl, 3
loc_1D6F4:
mov     ah, [bx+si]             ; 疊圖
mov     ds, cs:word_1D84C       ; ← 疊圖圖庫
call    sub_1D804
inc bx / dec dh / jnz loc_1D6F4
```

而 `sub_1D46A` 把兩者串起來：

```asm
mov     cs:word_1D84A, ax
add     ax, 800h                ; ＝ +32,768 byte
mov     cs:word_1D84C, ax
```

**32,768 byte 正好是 `MMAP.MDL`**（256 張 16×16 4bpp）。
所以疊圖庫就是緊接其後的 **`MMAP.MCH`**——`internal/assets/world`
早就在解它，首都疊圖 `CapitalOverlayTile = 0xFF` 用的就是這一組。

## 5. ⚠ 這一輪的教訓不是找法，是**沒先查**

照著資料流走確實有效：dump `sub_1D4C7` 看到它只寫表不畫 → xref
`word_1D84E` 找到消費端 `sub_1D66A` → 它用了兩個段 → xref 那兩個 →
`sub_1D46A` 一行 `add ax, 800h` 定案。三次 xref，零次猜測。

**但這條路本來有一半不必走。** [`67`](67-city-emblem-on-strategy-map.md) §4
早就寫著「五個疊圖槽，從 `cs:word_1D84C`（**軍團與災害物件用的那個**）畫上去」
——`word_1D84C` 是什麼、軍團用它，兩件事都已經在文件裡。

⭐ **沒查到不是因為查不到，是因為查錯關鍵字。** 當時 grep 的是
`sub_1D4C7` 與「軍團.*地圖」，而 `67` 用的詞是「疊圖槽」與 `word_1D84C`。
`CLAUDE.md` §10 的五張表就是為了擋這個——**動手前查 `docs/INDEX.md`
的斷言總表，而不是憑自己想得到的字去 grep**。

順帶一提，走不通的那條岔路也記著：數了 `ICONGRF` 段 1 的長度
16,128 ÷ 128 ＝ 126 塊、軍團要 110 張，覺得「數字對得上」——
**那是統計特徵不是語意**（§7 第 17 條）。
