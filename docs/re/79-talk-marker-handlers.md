## 1. 分派

```asm
loc_1088A:                      ; sub_1084A 讀到 `\` 之後的那個字
        sub  al, 31h            ; '1' → 0
        push ds / push cx / push si
        xor  ah, ah
        mov  si, ax
        shl  si, 1
        mov  ax, cs:[si+8A4h]   ; ⭐ 七項跳躍表
        call ax
        pop  si / pop cx / pop ds
        add  dx, 30h            ; 畫完把文字游標往右推一格全形
```

表的內容（檔案位移 `0xAA4`，`MZ` 標頭 32 段 ⇒ 載入模組起點 `0x200`）：

```
B2 08  DB 08  04 09  39 09  5B 09  7E 09  84 09  | 2E 8E …
```

| 標記 | handler | 線性位址 |
|---|---|---|
| `\1` | `CS:08B2` | `000108B2` |
| `\2` | `CS:08DB` | `000108DB` |
| `\3` | `CS:0904` | `00010904` |
| `\4` | `CS:0939` | `00010939` |
| `\5` | `CS:095B` | `0001095B` |
| `\6` | `CS:097E` | `0001097E` |
| `\7` | `CS:0984` | `00010984` |

⭐ **表就是七筆**：第八個 word 是 `8E2E`，也就是 `\1` handler 第一條指令的
`2E 8E`（`cs:` 前綴 ＋ `mov ds`）。表尾與程式碼首相接，沒有第八項。

## 2. 五支「畫一個名字」的 handler

五支的骨架相同：**設資料段 → 算出記錄位址 → `si` 指到欄位 → `ah` ＝ 顏色、
`al` ＝ 3 → `call loc_10701`（畫 Big5 字串）**。

```asm
2E 8E 1E 52 0D      mov ds, cs:word_10D52      ; 資料段
36 8B 05            mov ax, ss:[di]            ; 取一個 16 位元參數
47 47               inc di / inc di            ; 消耗它
80 FC FF / 75 xx    cmp ah, 0FFh / jnz .direct ; ⭐ ah ≠ 0FFh ⇒ ax 本身就是段內位址
8A E0 / 32 C0       mov ah, al / xor al, al    ; ax = al × 256
D1 E8 …             shr ax, 1 × N              ; N=3 → ×32；N=2 → ×64
05 lo hi            add ax, <表基址>
.direct:
8B F0               mov si, ax
```

| 標記 | 參數 | 記錄大小 | 表基址 | 取哪一欄 | 顏色 `ah` |
|---|---|---:|---|---|---:|
| `\1` | 武將編號 | 32 | `0x4240` 武將表 | **`+0x08` 呼び名** | 9 |
| `\2` | 據點編號 | 32 | `0x0840` 據點表 | `+0x02` 名稱 | `0x0B` |
| `\3` | **勢力編號** | 64 | `0x0000` 勢力表 | `+0x01` ＝ 君主的武將編號 → 武將 **`+0x02` 姓名** | `0x0C` |
| `\4` | **沒有** | — | `cs:word_10CFD` ＝ 玩家勢力記錄 | `+0x02` ＝ 軍師編號 → 武將 **`+0x08` 呼び名** | 9 |
| `\5` | **沒有** | — | 同上 | `+0x01` ＝ 君主編號 → 武將 **`+0x02` 姓名** | `0x0C` |

三個表基址與 [`00`](00-index.md) §1 的記憶體佈局逐項對得上
（據點 `0x840` × 32、武將 `0x4240` × 32、勢力「編號 × 64 即記錄位址」）。

### 2.1 ⭐ `\1` 畫的是**呼び名**，不是姓名

`\1` 的 `add si, 8`（`83 C6 08`）與 `\3`／`\5` 的 `add si, 4242h`
（`81 C6 42 42` ＝ `0x4240 + 2`）指的是**同一張表的兩個欄位**：

| 欄位 | 內容（[`../formats/08`](../formats/08-sinario-save.md) §3）|
|---|---|
| `+0x02` | 姓名，6 B ＝ 3 全形字 |
| `+0x08` | **呼び名（暱稱）**，多數武將與姓名相同 |

松崗版四個劇本裡兩者不同的只有四人，而**三個是名人**：

| 姓名 | 呼び名 | 出現的劇本 |
|---|---|---|
| 司馬懿 | **仲達** | 全部四個 |
| 諸葛亮 | **孔明** | 全部四個 |
| 龐統 | **鳳雛** | 全部四個 |
| 李暹 | **（三個全形空白）** | 只有劇本一 |

⚠ **李暹那一格是空的**——原版真的會畫出一片空白。照抄就是照抄。

`\4`（軍師）走的也是 `+0x08`（`add ax, 4248h` ＝ `0x4240 + 8`），
所以玩家自己扮演的軍師被 `\1`／`\4` 提到時，原版顯示的同樣是呼び名。

### 2.2 `\3` 與 `\5` 的差別只在「誰的君主」

兩支的尾段完全相同（`+0x01` → `×32 + 0x4242` → 顏色 `0x0C`），
差別只有勢力記錄從哪裡來：`\3` 吃一個**勢力編號參數**，
`\5` 直接讀 `cs:word_10CFD`（**玩家所仕的勢力**）。

⭐ **`\5` 不是「不存在」，是「沒有一則訊息用到」。**
[`../formats/01`](../formats/01-talk-dat.md) §3 的出現次數表兩版都是 0，
而 handler 好端端地在表裡。

## 3. `\6` 與 `\7`

```
\6  CS:097E   47 47 83 EA 30 C3
              inc di / inc di / sub dx, 30h / retn
```

⭐ **是 `sub dx, 30h`（`83 EA 30`），不是左移。** 分派端畫完每個標記都
`add dx, 30h`，所以 `\6` 的淨效果是**把那一格加回來的位移抵銷掉**——
它消耗一個參數卻不畫東西，游標留在原地。**排版控制標記**，不是說話者名稱。

```
\7  CS:0984   36 8B 05 47 47 53 52 57 D1 E3 D1 E3 …
              mov ax, ss:[di] / inc di ×2 / push bx,dx,di / shl bx,1 ×2 …
```

`\7` 取一個 16 位元參數後進 `sub_1062F` 的數值繪製路徑（十進位）。

## 4. 這對 remake 代表什麼

規格與接線在 [`../spec/119`](../spec/119-talk-marker-fields.md)。
一句話：**`\1` 與 `\4` 要代入 `Alias`（呼び名），不是 `Name`**。
`\2`／`\3` 現行的代入是對的。
