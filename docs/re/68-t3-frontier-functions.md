## 2. 戰術呈現：顯示格的物件 producer 與 eraser

`sub_1DB34`（登錄）與 `sub_1DB9B`（擦除）是同一組，**前半段逐指令相同**：

```asm
si = dx                      ; 存 X
dx = X + Y                   ; 欄
bx = ((Y − X) sar 1) + 0x20 − Z   ; 列
dx -= word_1E160 ; jl 跳過 ; cmp 1Fh ; jge 跳過   ; 裁切 31 欄
bx -= word_1E162 ; jl 跳過 ; cmp 18h ; jge 跳過   ; 裁切 24 列
xchg bl,bh / shr bx,1 ×3 / add bx,dx / shl bx,1 ×5   ; bx = (列×32 + 欄) × 32
ax = Z*2 + 1 → dx ; si = (Z*2 + 2)*2 = 4Z + 4      ; 槽內的深度位移
si += bx
```

⭐ 三件事被這兩支獨立印證（與 `sub_1DD22`／`sub_1DE95` 那一路互相對上）：

| 事實 | 出處 |
|---|---|
| 一格 32 B、一列 32 格、深度位移 ＝ `4 + 4Z` | `add bx,dx` 之後 `shl ×5`；`si = 4Z+4` |
| **槽位已被佔用就不覆蓋** | `sub_1DB34` 的 `cmp word ptr [si], 0 / jnz 跳過` |
| 可見範圍 31 欄 × 24 列 | 兩支各自的 `cmp 1Fh`／`cmp 18h` |

### 2.1 ⭐ 表頭 `+1` 與 `+3` 的分工：含物件的高度 vs 只有地形的高度

`sub_1DB34` 登錄物件時：

```asm
cmp dl, [bx+2]  / jb 跳過      ; 深度低於「起始深度」就不收
mov [si], cx                   ; 存進槽位
or  al, 80h                    ; 髒
cmp dl, ah / jb 略過 / mov ah, dl   ; ⭐ [bx+1] 取**大**的
```

`sub_1DB9B` 擦除時：

```asm
cmp word ptr [si], 0C0h / jb 跳過   ; ⭐ 只擦**物件**（< 0xC0 是地形子圖塊）
cmp dl, [bx+1] / jb 略過
mov al, [bx+3] / mov [bx+1], al     ; ⭐ 用 +3 還原 +1
mov word ptr [si], 0 / or byte ptr [bx], 80h
```

所以：**`+1` 是「含物件」的高度、`+3` 是「只有地形」的高度**。
`sub_1DD22`（地形 producer）兩個都寫，物件 producer 只抬高 `+1`，
物件消失時再從 `+3` 還原——這樣物件離開之後深度範圍會自己縮回去。

物件存的高度是 **`2Z+1`**（奇數），地形是 **`2Z`**（偶數），
所以那個 byte 同時編碼「第幾層」與「是不是物件」。

`0xC0`（192）正是地形子圖塊的數量：一個圖塊組 61,440 B ÷ 320 B ＝ 192
（[`../formats/07`](../formats/07-battle.md) §8），編號 ≥ 192 的是
`BATTLE.SCH` 的人物與物件。

## 5. 戰略資料存取：挑一位官員

`sub_137F5`（呼叫者 `sub_13771` ×2）掃整張武將表（基址 `0x4240`、127 筆 × 32 B），
挑出**同一個勢力、無職、政治最高**的那一位：

```asm
ax = 勢力記錄位移 → ax*4 後取高位元組 ＝ 勢力編號     ; 勢力表 stride 64，×4 剛好進 ah
cmp ah, [bx+1Ch]   / jnz 下一筆      ; +0x1C ＝ 所屬勢力（0xFF ＝ 在野）
cmp byte [bx+17h], 0 / jnz 下一筆    ; +0x17 ＝ 職務，0 ＝ 無職
cmp al, [bx+13h] / jnb 下一筆        ; +0x13 ＝ 政治，取最大
```

找到就回記錄位址（`ax`）並 `clc`，一個都沒有就 `stc`。

⚠ **與 AI 派將那一支不同**：`docs/re/44` 記的「派將只看武力」是編軍團那一條路，
這一支看的是**政治**——內政官／外交官的人選。同樣是「無職才挑」。
