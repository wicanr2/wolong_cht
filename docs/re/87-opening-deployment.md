# 87 — 開場擺位：X 寫死在戰場邊界，Y 是亂數

**狀態：confirmed（機器碼 ＋ 執行期寫入監看）。**
`sub_19C45` 把每個兵放上戰場：**X 寫死**（側 0 ＝ 1、側 1 ＝ 0x3E ＝ 62），
**Y ＝ 亂數 `& 0x1F` ＋ 0x10**，也就是 **16–47 均勻分佈**。
**不查佔用**，所以同一格會有好幾個兵。開場之後他們才走進陣形位置。

- 日期：2026-09-05
- 範圍：只驗松崗 DOS/V
- `KI.EXE` SHA-256：`fffeba985231cda4d636e93d10f598470b1f691d00275e4aa38e285893d43868`
- 工具：**IDAPython** `tools/ida_range.py`（`sub_19C45` 沒被 IDA 認成函式的
  前半段要用區間 dump）；執行期用 dosgolem 的 `unitwatch` 監看記憶體寫入
- 位址：IDA DOS/V linear address

## 1. 怎麼找到的

⭐ **靜態找不到。** `sub_19AF4` → `sub_19B6D` 是「開場填兵」，
它寫體力（`+0x03`）、戰力（`+0x18`）、命令（`+0x1A`），
**就是沒寫座標**。而 `+0x06`／`+0x08` 這種段內欄位**沒有交叉參考**
（`CLAUDE.md` §4.1 的第 4、5 條）。

改用執行期的**記憶體寫入監看**（dosgolem 的 `unitwatch:0,0,0`），
一跑就把三個寫入端印出來：

```
#46398899 寫 744D6 ← 00（X）    來自 19ADF   ← 清零
#46422756 寫 744D8 ← 1C（Y）    來自 19C61   ← ★ 擺位
#46422762 寫 744D6 ← 01（X）    來自 19C7B   ← ★ 擺位
```

⭐ **「誰寫了這個位址」用觀測回答，比用交叉參考掃描可靠**——
後者對絕對定址與間接寫入都是盲的，而**兩支工具都回 0 的時候，
要做的是換一種觀測，不是換一個假說**（`CONTEXT.md` §6 有同一個形狀的事故）。

## 2. `sub_19C45`

```asm
00019C49  mov  es, cs:word_1D30A       ; 兩軍的編成摘要（每側 0x20 B）
00019C4E  bx = (si >> 8) << 2          ; si ＝ 單位記錄偏移 ⇒ bx ＝ 隊 × 4
00019C58  call sub_1ECE0               ; ★ 亂數
00019C5B  and  al, 1Fh                 ;   0–31
00019C5D  add  al, 10h                 ;   16–47
00019C5F  mov  ah, al
00019C61  mov  [si+8], ax              ; ★ +0x08 ＝ Y、+0x09 ＝ 上一格 Y（同值）
00019C64  mov  [si+11h], al
00019C67  mov  ax, 101h                ; ★ 側 0 的 X ＝ 1
00019C6A  xor  di, di
00019C6C  cmp  si, 600h / jb loc_19C7B
00019C72  mov  di, 20h                 ;   側 1 的摘要在 +0x20
00019C75  sub  bx, 18h
00019C78  mov  ax, 3E3Eh               ; ★ 側 1 的 X ＝ 0x3E ＝ 62
loc_19C7B:
00019C7B  mov  [si+6], ax              ; ★ +0x06 ＝ X、+0x07 ＝ 上一格 X（同值）
00019C7E  mov  [si+10h], al
00019C81  cmp  byte es:[bx+di+9], 0    ; 這一隊還有沒有人可派
00019C86  jnz  → 有
00019C88  mov  byte ptr [si], 0        ;   沒有 ⇒ 這一格空著
00019C8B  jmp  → 收尾
有:
00019C8D  dec  word es:[di+4]          ;   側的總兵力 −1
00019C91  dec  byte es:[bx+di+9]       ;   這一隊剩餘 −1
00019C95  mov  byte ptr [si], 80h      ;   旗標：這個兵存在
00019C98  al = [si+6] / ah = [si+8]    ;   由 X、Y 算顯示格索引
00019CA8  mov  [si+0Ch], ax / [si+0Eh], ax
```

三件事因此定案：

| 事實 | 憑什麼 |
|---|---|
| **X 寫死在邊界**：側 0 ＝ 1、側 1 ＝ 62 | 兩個立即值 `0101h`／`3E3Eh`，高低 byte 相同是因為「現在」與「上一格」一起寫 |
| **Y ＝ 亂數 `& 0x1F` ＋ 0x10 ⇒ 16–47** | `sub_1ECE0` ＋ 兩道立即值 |
| **不查佔用** | 整支沒有任何「那一格有人嗎」的判斷 |

## 3. 執行期量到的

`SAVE-B.DAT` 的攻城戰（[`../playtest/72`](../playtest/72-same-battle-parity.md)），節拍 0：

| 側 | X | Y |
|---|---|---|
| 0（玩家／守方）| **全部 1** | 16–47 |
| 1（攻方）| **全部 62** | 17–47 |

側 0 第 1 隊有**三個兵在同一格 `(1,25)`** ✔ 與「不查佔用」相符。
到第 9 個節拍已經散開到 `X 1..5` ／ `58..62`——**他們是走進去的**。

## 4. remake 的落差

remake 的 `Place()` 直接把每個兵放到**陣形位置**，所以逐兵座標
**0/48 相同**（[`../playtest/73`](../playtest/73-opening-deployment-parity.md)）。

⚠ **Y 是亂數，所以逐兵座標永遠不可能全等。** 對得起來的判準要改成：
**X 全部等於 1／62、Y 落在 16–47、而且允許重複**。
