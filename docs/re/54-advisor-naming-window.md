選字區的底框 336×128 只是底；實際畫的是 **16 欄 × 6 列、格距 20 px**、起點 (210,238)
（`sub_1928A`／`sub_190C0`，[`../formats/10`](../formats/10-end-s15-namechars.md) §3）。

`0x21` 重來＝退一格、`0x22` 繼續＝跳一格（[`../spec/104`](../spec/104-advisor-naming-window.md) §1）。

## 3. ⭐ op `08` 的屬性低 byte 不是固定的

聲母列那一筆是 `0F01`，其餘十個場景的字串都是 `0F03`。
[`48`](48-window-display-list.md) §7 原本記「低 byte 固定 `0x03`，語意未讀」
——**那是取樣不足**：九個場景剛好都用同一個值。

聲母列的內容是 `cs:1871` 的 42 bytes：

```
　ㄅ　ㄈ　ㄋ　ㄍ　ㄐ　ㄑ　ㄓ　ㄕ　ㄙ　ㄨ　
```

十個聲母，字與字之間插一個全形空格。低 byte 的兩個值目前只能說
「`03` 是一般字串、`01` 用在這一筆」，語意仍未讀。
