## 1. 視窗與靜態層

`sub_16DFD` 開頭兩句就把整個版面定死：

```asm
al = 3Dh / dx = 9 / bx = 5 / cx = 0C0Fh
sub_1895D                       ; 框 (144, 112) 240×192
al = 5 / dx = 98h / bx = 78h
sub_10337                       ; 顯示清單場景 5，原點 (152, 120)
```

`sub_1895D` 的單位是 16 px 粗格且 Y 自動加 2（[`46`](46-strategy-chrome-cell-layer.md) §2）：
X ＝ 9×16 ＝ 144、Y ＝ (5+2)×16 ＝ 112、寬 15×16 ＝ 240、高 12×16 ＝ 192。

場景 5 的內容（座標已換成畫面絕對座標）：

| 元件 | 座標 | op |
|---|---|---|
| 總兵力／士氣值的值框 | (240, 152) 112×32 | 03 |
| 六個槽的框 | (160, 192) 112×96 | 03 |
| 預備兵數的值框 | (304, 216) 64×48 | 03 |
| 確定鈕的底 | (280, 272) 88×16 | 03 |
| 確定鈕的立體邊 | (279, 271) arg `00D8 00A8` | 04（低 byte 畫上邊與左邊、高 byte 畫下邊與右邊，[`48`](48-window-display-list.md) §2）|
| 「將軍」 | (248, 128) | 08，色 `0x0F` |
| 「總兵力」「士氣值」 | (248, 152)／(248, 168) | 08，色 `0x0F` |
| 「主將」…「右備」 | (160, 192 + 16k) | 08，色 `0x0F` |
| 「預備兵數」 | (280, 192) | 08，色 `0x09` |
| 「確 定」 | (304, 272) | 08，色 `0x00` |
| 兵種圖示 ×3 | (280, 216/232/248) 24×16 | 09，位移 `12C0`／`1380`／`1440` |

### 1.1 那三張圖示就是財政視窗的紅色那一組

op `09` 的位移要加 `0x9A0` 才是 `ICONGRF` 段 3 的位移（§6.1）：
`12C0`／`1380`／`1440` → 段 3 的 **`0x1C60`／`0x1D20`／`0x1DE0`**。

而財政視窗的紅色圖示欄是段 3 `0x1BA0` 起、間隔 `0xC0`、四張
（[`48`](48-window-display-list.md) §8）——`0x1BA0`／`0x1C60`／`0x1D20`／`0x1DE0`。
**編成畫面用的正是那一組的第 2、3、4 張**，也就是馬／弓／步，
第一張天秤（稅率）在這裡用不到。兩個視窗各自解出來的位移互相對上。

## 2. 動態層之一：`sub_16D6F`（預備兵與總兵力）

`sub_1062F(ax = 值, bx = 顏色<<8 ｜ 位數, di = VRAM 位移)`。
`di` 一列 80 byte，除得的餘數 ×8 是 X。

```asm
si = di                          ; di ＝ 勢力的預備兵三欄
cx = 3 / di = 43A7h
loop:
  ax = [si] × 0Ah                ; ← 點 → 人，乘 10
  bx = 906h                      ; 色 9，6 位
  sub_1062F
  si += 2 / di += 500h           ; ＋16 列
pop si                           ; 取回軍團記錄
ax = [si+4] × 0Ah                ; ← 軍團 +0x04 總兵力
bx = 0F04h / di = 2FA7h          ; 色 F，4 位
sub_1062F
```

| 值 | `di` | 座標 | 位數 | 色 |
|---|---|---|---:|---|
| 預備兵：騎馬／弓兵／步兵 | `43A7`／`48A7`／`4DA7` | (312, 216／232／248) | 6 | `0x09` |
| 總兵力 | `2FA7` | (312, 152) | 4 | `0x0F` |

三個預備兵數就落在 §1 那三張兵種圖示（280, 216/232/248）的右邊，
框 (304,216) 64×48 正好包住三列。

**兩處都乘 10**——與[`../spec/21`](../spec/21-corps-formation-reserves.md) §1
的「一點 ＝ 10 人」同一條換算，這是它的第三個獨立來源。

### 2.1 數字是半形，8 px 一位

`di` 是**起點**不是右端。總兵力 4 位從 x=312 起，若一位 16 px 會畫到 376
再到 384，貼著視窗右緣；預備兵 6 位會畫到 408，**超出視窗 24 px**。
一位 8 px 則是 312–360，落在值框 (304,216) 64×48 之內。
**框寬直接決定了字寬**，不必另外找繪製常式。

## 3. 動態層之二：`sub_16DA8`（六個槽）

```asm
si += 28h                        ; → 六個槽，每槽 4 bytes
di = 3C1Dh
ds = cs:word_10D50               ; 圖庫段
cx = 6
loop:
  ah = es:[si+2] / al = 0 / dec ah        ; ax = (兵種 − 1) << 8
  ax >>= 1 / si = ax / ax >>= 1 / si += ax ; si = (兵種 − 1) × 192
  si += 15C0h
  bx = di − 4 / ax = 1003h
  sub_1F9B0                                ; ← 貼兵種圖示
  al = es:[si+1] × 0Ah / dx = 0            ; ← 槽的兵力，乘 10
  bx = 904h                                ; 色 9，4 位
  sub_1062F
  si += 4 / di += 500h
```

`(兵種−1) × 192` 就是 `0xC0` ＝ 一張 24×16 的 4bpp 圖，與 §1.1 同一個間隔。

| 兵種 | 圖庫位移 | 段 3 位移 |
|---:|---|---|
| 1 騎馬 | `15C0` | `0x1F60` |
| 2 弓兵 | `1680` | `0x2020` |
| 3 步兵 | `1740` | `0x20E0` |
| 4 空槽 | `1800` | `0x21A0` |

財政的**綠色**圖示欄是段 3 `0x1EA0` 起四張——`0x1EA0`／`0x1F60`／`0x2020`／`0x20E0`。
所以**六個槽用的是綠色那一組的第 2、3、4 張**，
而**兵種 4（空槽）落在那一組的後面一張 `0x21A0`**，是這兩個視窗都沒有用過的新圖。

那張圖解得開，與綠組最後一張不同，內容是 **384 個像素全 0**——
原版在空槽那一格貼一張全黑圖，把前一張擦掉。⚠ 「全黑」與「位移落在段尾之外」
在解碼結果上長得一樣，分辨的方法是看它後面還有沒有內容（`TestDOSVEmptySlotIcon`）。

座標：`di = 3C1Dh` → (232, 192)，`bx = di − 4` → (200, 192)，每列 `+0x500` ＝ 16 列。

| 元件 | 座標 |
|---|---|
| 兵種圖示 | (200, 192 + 16k) 24×16 |
| 槽的兵力（4 位，色 `0x09`）| (232, 192 + 16k) |

配上 §1 的標籤 (160, 192+16k)，一列就是**標籤 → 圖示 → 數字**三段，
整列落在框 (160,192) 112×96 之內。

## 4. 剩下三個顯示值

`sub_16DFD` 中段還畫三樣東西：

```asm
al = [si+4241h] / bx = 2593h
sub_107D2                        ; 武將頭像 → (152, 120)
dx = 128h / bx = 80h / ax = 0F03h / si += 4242h
sub_106FD                        ; 武將名 → (296, 128)
al = [di+19h] / bx = 0F03h / di = 34A8h
sub_1062F                        ; 士氣值 → (320, 168)，3 位，色 0F
```

`di` 是勢力記錄 ＋ 4（預備兵三欄的位址），所以 `[di+19h]` ＝ **勢力 `+0x1D`**
——[`../formats/08`](../formats/08-sinario-save.md) 記的士氣基準值（四個劇本都是 200）。
**編成畫面顯示的士氣值是勢力層級的，不是這支軍團的。**
軍團 `+0x06` 的士氣要等 `sub_16F26` 建立軍團時才從這裡複製過去，
所以編成當下顯示的就是「建出來會是多少」。

## 5. 熱區

```asm
al = 3Eh / bx = 0C0h / cx = 6
loop:
  dx = 0C8h / cx = 203h
  sub_1E3D7                      ; (200, 192 + 16k) 24×16
  al++ / bx += 10h
dx = 118h / bx = 110h / cx = 20Bh
sub_1E3D7                        ; 熱區 0x44 (280, 272) 88×16
```

| 熱區 | 位置 | 作用 |
|---:|---|---|
| `0x3E`–`0x43` | (200, 192 + 16k) 24×16 | 六個槽，點一下兵種 `+1` 循環（[`30`](30-corps-formation-ui.md) §3）|
| `0x44` | (280, 272) 88×16 | 確定 |

⭐ **六個槽的熱區與兵種圖示逐格重合**——與財政視窗「可點的就是圖示」
同一種設計（[`../spec/14`](../spec/14-finance-window.md) §2）。
標籤與數字都不是可點區域。
確定鈕的熱區也與 §1 那個 88×16 的底框逐格重合。
