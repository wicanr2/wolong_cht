## 影片幾何根因與修正

舊合成把原版 4:3 容器與 remake 640×400 分別以長邊塞進 1280×720：原版約為
960×720，remake 為 1152×720，視覺上必然相差約 20%。新管線先把原版正規化為
640×480，再裁出垂直置中的 640×400 framebuffer；兩側之後共用相同最近鄰縮放。

remake 本身另有一個獨立錯誤：layout 宣告戰場 `480×368`，但離屏投影畫布是
`496×384`，右、下各 16 px 最後由側欄與底列覆蓋。本輪將 buffer 改為原生
`240×184`，兩倍放大後精確等於 layout 的 `480×368`；原版 31×24 欄列邊界測試
仍保留，由可見 viewport 負責裁切。

## 尚未完成的戰術 parity

目前推廣片兩段戰術畫面不是同一戰況；remake 段是明確標示的攻城 fixture，只能
驗固定骨架，不能當同狀態逐像素證據。從未縮放畫面仍可確認下列缺口：

- 原版雙 TALK 的 payload、肖像、文字 baseline 與出現時序尚未在同一戰況對拍。
- 原版右欄完整狀態資訊、旗標、軍名、命令 glyph 與裝飾仍未逐區等價。
- 原版底列按鈕 glyph、選取狀態與 remake 文字／簡化圖示仍有差異。
- 地形、部隊編成、鏡頭中心、動畫 frame 與戰況不同，不能用目前推廣片判定物件
  排序、遮擋、投射物與動畫時序 parity。

下一個有效驗收不是繼續改影片，而是建立同攻城節點、同攻守方、同編成、同命令、
同鏡頭與同 frame 的原版／remake 640×400 capture pair，再逐區輸出差分圖。
