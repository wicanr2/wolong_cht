## 2. ⭐ 為什麼要剪掉內部的卡

三支各自有開場卡與結尾卡。直接串接的話，主預告的結尾卡（65–72）
緊接著 DOS/V 對照片的開場卡（00–04），**中段會出現十一秒的卡**——
看起來像三支片黏在一起，而不是一支片。

所以只留一組頭尾：主預告的標題卡開場、手機片的「原版資料請自備」收尾，
中間兩個接點各裁掉一組卡。手機片自己的標題卡留著，當第三章的章名卡。

剪點全部出自各片**已經記錄在文件裡的分鏡表**，不是目測。
目測的剪點會把內容切掉半句，而且下一次重剪要再猜一次
（同一條理由讓 `tools/promo_stills.sh` 與 `tools/promo_live_capture.sh` 存在）。

抽樣驗過兩個接點：64.5 秒仍是主預告的進言畫面、65.5 秒已是 DOS/V 的
「開新遊戲」並排、127 秒是 DOS/V 的 remake 攻城、129 秒是手機片的標題卡。

## 3. 配樂

⭐ 聲音來源是 remake 自己的 **OPL3 合成**（`tools/bgm2ogg.sh` 從使用者自備的
`BGM.DAT` 算出來的，[`../spec/29`](../spec/29-audio.md)）——**不是從原版錄音
取樣**，也不是把 `BGM.DAT` 放進影片。但它演奏的是原版的曲子，所以這條音軌是
**原版衍生物**：只用在推廣片，**不進任何遊戲包**，也不宣稱是本專案的創作。

曲目照場景挑（[`../re/58`](../re/58-bgm-scene-mapping.md) 的曲表：
2 春／3 夏／4 秋／5 冬 是大地圖，9 平原野戰、10 山地林地水域 是戰場）：

| 時間 | 曲 | 為什麼 |
|---|---|---|
| 000–065 | 沿用 `original-72.wav` 的前 65 秒（曲 2 → 曲 9 → 曲 2）| 它已經對齊主預告自己的分鏡，重接反而會錯開 |
| 065–105 | 曲 5（冬・大地圖）| DOS/V 段的政略部分：開新遊戲、編成、行軍 |
| 105–128 | 曲 10（戰場）| DOS/V 段從片內 44 秒起全是戰鬥 |
| 128–176 | 曲 3（夏・大地圖）| 手機段 |

交界用 1 秒 `acrossfade`。**`acrossfade` 會把兩段重疊 1 秒**，所以每一段要
多剪 1 秒去補；不補的話總長會少 3 秒，而症狀是最後一段被切掉尾巴。

⚠ **DOS/V 對照片那條 DOSBox-X 實錄的原版 AdLib 音軌被換掉了。**
那條是原版實機的聲音，資訊量比合成的高；換掉是為了全片一致
（使用者裁定 2026-08-30：全片用原版 ogg）。原本那條仍在
`workplace/promo/.../original-audio/`，單支的 `dosv-realmachine.mp4` 也沒動。

## 4. 發行界線

- 發行目錄 `dist-all/promo/` **只有這一支**。三支素材片與兩支研究用對照片
  （`classic-revival`、`yt-comparison`）留在 `dist/promo/`，製作紀錄與重錄
  命令都還在，隨時可重生——**只是不進發行**。
- 清單寫在 `tools/release_all_fs.py` 的 `PROMO_FILES`，改片要改那一行。
- 片中的畫面除了標明的原版並排段之外，全部是 remake 自己畫的。
  **原版的 `BGM.DAT`／`SOUND.DAT`／執行檔本身沒有進發行素材。**

## 5. 重跑

```sh
tools/promo_combined.sh                 # → dist/promo/wolong-remake-promo.mp4
```

⚠ **輸出要寫到 `dist/promo/`，不是 `dist-all/promo/`。**
`release_all_fs.py` 的 `promo_source()` 先找 `dist/promo/`，只寫後者的話
下一次打包會用舊片蓋掉新片，而 manifest 與雜湊全部正常
（[`README.md`](README.md) 的同一條警告，2026-08-26 踩過）。

前置：三支素材片要在 `dist/promo/`（重錄見各自的紀錄）、
`workplace/audio/bgm-*.ogg` 要在（`tools/bgm2ogg.sh`）、
`workplace/promo/score/original-72.wav` 要在（`tools/promo_score_original.sh`）。
