# 99 — 四槽視窗：本體 95 px（只剩游標），抓到四個缺陷

**狀態：通過。** 系統選單第 0 列開的「ＳＡＶＥ　ＤＡＴＡ」四槽視窗，
本體 `(96,80,304×240)` 逐像素比對只剩 **95 px ＝ 原版自己畫的滑鼠游標**。
[`../spec/25`](../spec/25-slot-select-window.md) 先前只有「靜態：座標出自機器碼」，
這是它第一次有原版擷取。

- 日期：2026-09-06
- 規格：[`../spec/25`](../spec/25-slot-select-window.md) §3.1、
  [`../re/52`](../re/52-slot-select-window.md) §4
- 原版側：`…;runto:11CD0;sclick:448,15;steps:400000;stap:376,160;
  steps:900000;shot:orig-save`
  ⚠ **要點值格不是標籤**：熱區在右邊那個 `ＯＫ` 格（x 352–400），
  點左邊的「資料儲存」四個字沒有反應。
- remake 側：`-open-save write -cam 0,0
  -fixture-when clock:196/4/16/10 -shot-when clock:196/4/16/10`
  （`-open-save` 本輪新增）

## 2. ⭐ 原版沒有「空槽」這個分支

原版擷取顯示空槽畫的是**一整排「－」** ＋ **`0年 0月 0日`**，
不是留白也不是另一句話。那排破折號**就是檔案裡 `+0x40` 的字串**
（空槽標記 `0xA1D0` ＝「－」，[`../spec/25`](../spec/25-slot-select-window.md) §2）——
所以原版的畫法是「名稱欄照畫 `+0x40`、日期欄照畫三個數字」，沒有分支。

remake 先前：**儲存模式根本沒去看槽**（只有讀取模式 `inspectLauncherSlots`），
四格全部顯示紅字「空白槽位」——**要覆蓋哪一格看不到**。

⚠ 「可不可以選」是另一回事：讀取與新遊戲仍然擋空槽，那道判斷走 `Available`。

## 3. ⭐ 日期欄是黑字，`docs/re/52` 的顏色欄把兩個半位元組讀反了

原版 `sub_1062F(bx = 5003h)`：**`bh = 50h` ＝ 背景 5 ／前景 0**，
`bl = 3` 是位數。[`../re/52`](../re/52-slot-select-window.md) §4 記成「色 `0x05`」，
而色 5 正是那個綠底——照著做會把數字畫成隱形的。

原版擷取量到那一格只有兩種顏色：綠底 `(81,146,65)` 與**黑字** `(0,0,0)`。
remake 先前把標籤畫成白的、數字用色 5（等於沒畫）。

⭐ **屬性是「背景 4 位︰前景 4 位」**（[`../re/28`](../re/28-text-number-rendering.md) §2.1），
抄的時候很容易寫成反的，而**寫反了在別處未必看得出來**——
只有背景剛好等於前景那一次才會整個消失。

## 4. 選中的那一列在原版沒有標示

原版是直接點日期欄決定的，沒有游標狀態。remake 多了鍵盤選槽所以要標，
但**沒用過鍵盤就不標**——與一覽表的 `listTouched` 同一種作法。

## 5. 名稱欄的可用寬

空槽那排「－」原版是 16 個（畫滿 256 px），remake 少畫一個：
可用寬寫成 `saveNameBoxW − 16`。
