## 修正及正常操作

桌面捕捉模式接收相對滑鼠位移，以畫面游標的越界量移動相機。
相機保存格座標及像素餘數；地圖和其附著圖形一起位移，格對齊入口清除餘數。
點選仍依原版將相機與畫面座標分別取整，餘數不混入點選公式。
游標使用既有原版箭頭素材；清單等模態路徑保留原本的地圖阻擋。

`workplace/map-scroll-20260908/candidate/` 保存正常首頁讀檔後的實跑：

- 外推、停手、反向、方向鍵：地圖隨連續位移捲動，停手不繼續捲。
- 行軍選點：指令 → 軍團 → 行軍指示 → 兩段選軍團 → 向右再向左外推 → 點陝，
  `march/march-target.png` 進入「戰鬥指揮／委任」選單。
- 失焦：切出、移動外部游標、切回；修正後地圖 `(32,64,560,240)` 區域差異 0 像素。

第一次以單次大幅搬移游標的腳本被 Xvfb 螢幕邊界截斷，不能當作產品缺陷。
改為 XTest 連續小位移後，相對原始座標可超過 639，外推流程正常。
第一次焦點測試則確實抓到產品缺陷：失焦期間未更新，返回後補算外部位移。
修正為失焦仍執行輸入生命週期，釋放捕捉後立即返回，世界維持暫停。
失敗證據保留於 `candidate/focus-failure/`；`v.1.0.10-20260908` 不作完成交付。
