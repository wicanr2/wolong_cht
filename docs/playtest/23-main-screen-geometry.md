## 1. 原版主畫面預設長什麼樣

實跑第一次看到的畫面推翻了一個一直沒被質疑的假設：
**原版預設不顯示命令列與右欄**。

```
196年 4月 1日、曹操
┌──────────────────────────────────────────┐
│ 橫幅 640×32：臥竜伝 ＋ 龍 ＋ 五格開關 ＋ 日期        │
├──────────────────────────────────────────┤
│                                          │
│              大地圖 640×368                │
│                                          │
│ ┌─────────────┐                          │
│ │ 據點情報：許昌 │  ← 選中首都時出現         │
│ └─────────────┘                          │
└──────────────────────────────────────────┘
```

命令／自勢力情報／縮小地圖／系統是**四個可以逐個開關的視窗**
（說明書 3.1、[`../re/47`](../re/47-main-screen-window-registry.md)），
說明書那張主畫面圖是「四個都開著」的狀態。
remake 目前固定顯示其中三個，這是**未實作的開關**，不是版面錯誤
（[`../spec/12`](../spec/12-strategy-chrome.md) §7）。

## 2. 四項常數換掉了

| 項目 | 舊值（影片估）| 新值（機器碼）| 出處 |
|---|---:|---:|---|
| 命令列第一個詞的 X | 64 | **32** | `sub_106F5(dx=8)` ＋ 開頭空白 24 |
| 縮小地圖視窗高 | 152 | **160** | `sub_1895D(cx=0x0A0D)` |
| 自勢力情報視窗 Y／高 | 176／224 | **192／208** | `sub_1895D(cx=0x0D0D)` |
| 系統視窗 Y／高 | 114／194 | **112／192** | `sub_1895D(bx=5, cx=0x0C0D)` |

命令列的命中判定也一併改成原版的 `索引 ＝ (x − 24) ÷ 48`：
八格之間**沒有間隙**，先前每格右緣留的 2 px 死區是自己加的。

三條算術檢查同時成立，所以這組值不是各自湊出來的：

- 右欄三段 `32 + 160 + 208 = 400`，鋪滿畫面高度
- 命令列字串尾端 `8 + 24 + 8×32 + 7×16 + 24 = 424 < 432`（框寬）
- 熱區 `(24, 40, 384, 16)` 的左右界與 `sub_161CA` 的 `x < 24`／`x ≥ 408` 一致

## 3. 對拍結果

只有 `banner` 是這一輪可比的區——原版側四個視窗都關著，
其餘四區在原版那邊是地圖像素，比出來的數字沒有意義。

| 區 | 不同像素 | 佔比 | 判定 | 說明 |
|---|---:|---:|---|---|
| `banner` | 10161 / 20480 | 49.61% | FAIL | 見下 |
| `command` | 13619 / 13824 | 98.52% | — | 原版側是地圖 |
| `map` | 140127 / 145152 | 96.54% | — | 相機位置不同 |
| `minimap` | 33145 / 33280 | 99.59% | — | 原版側是地圖 |
| `faction` | 42188 / 43264 | 97.51% | — | 原版側是地圖 |

### 3.1 ⭐ 橫幅：幾何對齊，差的是顏色

`tools/parity_offset.py` 把 −4…+4 的整體位移全掃一遍：

```
最小不同比例 49.61% 落在 dx=+0 dy=+0
鄰格（±1）都在 64–72%
```

**(0,0) 是一個明顯的谷**，所以橫幅的位置與大小是對的。
剩下的 49.6% 不是版面問題：原版側是 **PC-98 類比 RGB**，
remake 對的是松崗 DOS/V 的調色盤，兩者本來就不同色；
龍那一段又是大面積 dither，一個色階差就整片不同。

> 這正是位移掃描要解決的事：**逐區差分只回答「差多少」，
> 不回答「是不是整片平移」**，而這兩件事的處置一個是改常數、
> 一個是換素材。

## 4. 缺什麼

| 缺口 | 現況 |
|---|---|
| 原版「四窗全開」的截圖 | PC-98 上左鍵點那四個開關**沒有反應**（[`../re/47`](../re/47-main-screen-window-registry.md) §6），原因未定 |
| 松崗 DOS/V 側的主畫面 | 開新遊戲流程停在「決定」按鈕不回應（`tools/dosv_live_capture.sh`）。密碼頁不是障礙（[`18`](18-dosv-password-verification.md)）|
| 同版本同調色盤的對拍 | 上面兩項任一個通了就能做。**在那之前 `banner` 的 49.6% 不代表 remake 有錯** |
| 各視窗內部排版 | 頭像、信賴度列、資金／預備兵三行仍是影片估值，沒有機器碼證據 |
