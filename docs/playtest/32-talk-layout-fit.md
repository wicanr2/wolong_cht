## 3. 這個數字要釘住

測試把 `5` 寫成門檻：**超過就失敗**。校訂讓某一則變長時，
這個數字會漲，而那正是要被看見的訊號——
不然「排版有沒有爆框」每次都要重新人工看一遍。
