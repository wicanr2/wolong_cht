# 24 — 四個常駐視窗的開關：實作驗收

**狀態：開關可用，四窗全開與全關兩張截圖都拍到了。右欄的四條邊與原版
參考影片逐條對上（y = 168／184／192／199）。仍未對過的是各視窗**內部**
的像素與原版執行期畫面。**

- 日期：2026-08-15

- 出處：[`../re/47`](../re/47-main-screen-window-registry.md)

## 1. 改了什麼

| 項目 | 之前 | 現在 |
|---|---|---|
| 大地圖 | (0, 64, 432, 336) ＝ 27×21 格 | **(0, 32, 640, 368) ＝ 40×23 格** |
| 四個視窗 | 固定顯示三個 | 疊在地圖上，左鍵開右鍵關 |
| 系統視窗 | 有視窗但不影響時間 | 開著時**時間停止**（說明書 3.1）|

地圖格數是原版數值：`sub_1D615` 的迴圈 `cx=0x28 / dx=0x17`。
**這不只是版面調整**——先前關掉右欄會露出空白，因為地圖根本沒畫到那裡。

## 2. 邊線對照

參考幀是壓縮過的影片，逐像素比沒有意義（每一區都會是 ~100%）。
改量**水平邊線的位置**：那是壓縮壞不掉的結構訊號
（`tools/parity_edges.py`，取右欄 y 160–208 這一段）。

| 邊 | 原版幀 | remake | 是什麼 |
|---:|---:|---:|---|
| 168 | 167–171 | 167–168 | 縮小地圖下方的勢力篩選列上緣 |
| 184 | 183 | 186 | 縮小地圖視窗的下框上緣 |
| 192 | 191 | 191–192 | 兩個視窗的交界 |
| 199 | 199–202 | 199 | 自勢力情報視窗的內框上緣 |

同一段掃描在整張畫面上也對得起來：橫幅底 y=32、命令列文字列 y=40、
命令視窗底 y=64、右欄左邊界 x≈434–442（框線是 8 px 寬，所以是一段不是一條）。
