## 3. ⭐ 外框與底紋也吃調色盤

`chrome.Load(lib, bank)` 是**開局時載一次**的——換季不重載、換畫面模式
更不重載。換季只動色號 14（[`../formats/02`](../formats/02-brg-palette.md) §4）
所以看不出來，**換畫面模式一眼就看得出來**：地圖整片變黃了，
視窗還是藍底紅框。

修法是記住「現在的外框是用哪一組畫的」（`chromeBank`），
`Update` 裡比一次，不同就重畫。⭐ **比的是 bank 不是旗標**，
所以順帶把換季也涵蓋了——那是一個先前沒有人發現的缺口，
因為它的症狀被「四季只差一個顏色」蓋住了。

## 4. ⭐ bank 就是調色盤，不是美術

`TileSet.RenderRGBA(data, index, pal, bank)` 的 `bank` 只餵給 `pal.Bank(bank)`；
圖塊資料是同一份。所以整個功能就是**把所有取 bank 的地方換成一支
`paletteBank()`**（季節 + 4×液晶），一行圖形程式都沒有動。

⚠ `Clock.Season()` 有兩種用途——調色盤 bank 與**素材頁**（肖像的四季版本、
據點景觀圖）。這一輪只換了前者，14 個呼叫點逐一確認過都是前者。

## 5. ⭐ 肖像也吃 bank，而 remake 已經對了

切到液晶之後開武將一覽、點第一列（曹操的肖像 ＋ 軍師的肖像同時在畫面上）：

| 區 | 不同像素 |
|---|---:|
| 武將肖像 (168,168,64×64) | **0 / 4096** |
| 軍師肖像 (8,328,64×64) | **0 / 4096** |
| 清單視窗 (32,88,352×176) | **0 / 61952** |

原版側 `…;sclick:448,15;steps:400000;stap:376,184;steps:400000;rclick:448,15;
steps:200000;sclick:352,15;stap:336,47;…;shot:lcd-gen1`；
remake 側 `-open-list -list-pick-row 0 -video-lcd`。

肖像在 16 色下用的是自然色（膚色 `(243,211,146)`、棕 `(130,65,32)`），
液晶下換成純飽和色（`(0,243,243)`／`(243,0,243)`／`(243,243,0)`）——
**同一份圖形資料、不同調色盤組**，與地圖是同一個機制。

⇒ `paletteBank()` 一支收掉所有取 bank 的地方（[`../spec/152`](../spec/152-video-mode-lcd-palette.md) §2）
本來就涵蓋了肖像，不必另外處理。

⚠ 這一節只證明**顏色**跟著 bank 換。「素材頁的四季」（肖像有沒有四季
版本的**圖**）是另一件事，這裡沒有動到。
