## 3. ⭐ `sub_14194` 的第三個呼叫點有條件分支

三個呼叫點在同一支函式裡，次數卻不同：

```
141D8  6126
141F1  6126
14216  5584      ← 少 542 次
```

前兩個一定成對出現，第三個**不是每次都取**。remake 若在同一支規則裡
無條件取三個數，序列會在第一次跳過的地方就岔開，而且之後**每一拍都錯**。
這是目前最具體的一個對齊候選。

## 4. 這一份沒有涵蓋的

觀察窗是劉備不作為的**閒置期**，這個月裡沒有攻城戰。
所以清單裡看不到攻城結算、撤退與殲滅的消費端——
而那正是人工試玩觀察到差距的地方（[`../spec/161`](../spec/161-liubei-idle-longrun-parity.md) §1）。
要拿到那一段，觀察窗得推到第一場攻城，或用 `siege:攻方,據點` 直接開一場
（[`../spec/131`](../spec/131-dosgolem-oracle.md) §2）。
