# 25 — 音訊擷取的可行性：DOSBox 錄得到，鏈路已打通

**狀態：可行性 confirmed。開場動畫的 15 秒錄音有內容（RMS 424），
轉成 ogg 再解回來仍是 RMS 415。⭐ 但這只證明「錄得到」——
**逐曲觸發還沒有**（§4）。**

- 日期：2026-08-15
- 範圍：松崗 DOS/V 版，DOSBox 0.74（`dosbox-run:latest`）
- 實驗腳本：一次性，未進版控（結論在這裡，正式工具見 §5）

## 1. 為什麼要先做這個實驗

`BGM.DAT` 的**聲軌事件編碼完全未解**（[`../re/23`](../re/23-bgm-resource-format.md)）
——音高、長度、迴圈、包絡都還沒讀。所以「解析格式再合成音檔」這條路走不通。

剩下的路是**跑原版錄音**。但那條路有三個各自會失敗的環節，
而且每一個失敗起來都像成功：

| 環節 | 失敗時看起來像什麼 |
|---|---|
| 遊戲要走到有音樂的地方 | 錄到檔案，但全是靜音 |
| DOSBox 要真的在混音 | 同上 |
| 錄音要正常收尾 | 檔案存在但檔頭沒寫完 |

所以先做最小實驗，量到訊號再談實作。

## 2. 結果

| 量測 | 值 |
|---|---|
| 錄音長度 | 14.9 秒（44.1 kHz 立體聲）|
| 檔名 | `d7open  _000.wav` ——**DOSBox 用當時的執行檔名命名**，所以檔名本身就是「錄到哪一支」的證據 |
| 分十段的 RMS | 50 / 443 / 419 / 414 / 433 / 416 / 424 / 468 / 480 / 433 |
| 峰值 | 1,158–1,538（16 bit 滿刻度 32,767，**音量只有 4.7%**）|
| ogg（libvorbis `-q:a 5`）| 276 KB，解回來 RMS 415、峰值 1,556 |

**分段量 RMS 是必要的**：只錄到片頭的話後段會是 0，而總 RMS 看不出來。
第 1 段的 50 是淡入，其餘穩定在 414–480 ＝ 整段都有音樂。

## 3. ⭐ 第一次失敗的樣子

第一次跑錄到 2.3 MB 的 WAV，長度也對（13.1 秒）——**但十段全是 0.0**。

兩條線索指出原因：

1. 檔名是 `ynfont  _000.wav`，而 `YNFONT.EXE` 是字型 TSR，不是遊戲本體。
2. 截圖停在**密碼輸入頁**。

原因是我用 `Return` 想過密碼頁，而那一頁要**點「確定」按鈕**
（`CLAUDE.md` §4.0 說的是「四格留白直接按確定」，那是滑鼠）。

⚠ **滑鼠不能加 `--window`**：`xdotool click --window` 送的是合成事件，
DOSBox 收不到；不加才走 XTEST 直接進 X server 的輸入佇列。
（同一條坑在 `~/.claude/knowledge-base/retro/megadrive-vgm-music-extraction.md`
記過，那邊是手把按鍵。）

「有檔案、長度正確、全靜音」——**這個組合正是要靠分段 RMS 才抓得到的**。

## 4. 未解

這個實驗**沒有**證明下面這些事。

| 項目 | 現況 |
|---|---|
| **逐曲觸發** | 只錄到開場動畫（`D7OPEN.EXE` 自己會播）。11 首要逐首、可重現地觸發，得先解出 `YNSOUND.COM` 的播放 command——[`../re/17`](../re/17-dosv-audio-tsr.md) §2 只定案了 `AH=0x05`（效果）、`0x06`／`0x07`（載入資源）、`0x0A`（查旗標），**播放音樂那一個還沒有證據** |
| **音效** | 戰術的三個 effect code 已知（`re/17` §3），但沒錄過 |
| **音量** | 峰值只有滿刻度的 4.7%。是 OPL 的音量設定還是遊戲本來就這樣，沒查 |
| **音源正確性** | DOSBox 用 `sbtype=sb16`／`oplmode=auto` 模擬，與真實硬體的音色差異沒有對照組 |

## 5. 重跑

實驗腳本是一次性的，正式工具還沒寫（`docs/spec/29` 是 DRAFT）。
關鍵設定：

```conf
[dosbox]
captures=<輸出目錄>
[mixer]
nosound=false
rate=44100
[sblaster]
sbtype=sb16
oplmode=auto
oplrate=44100
```

環境要 `SDL_AUDIODRIVER=dummy`（headless 沒有音效裝置，但 DOSBox 的
混音器照跑，錄的是混音輸出不是裝置輸出）。

錄音開關是 **`ctrl+F6`**，**收尾一定要再按一次**——直接關 DOSBox
會讓 WAV 的檔頭沒寫完。

轉檔用 `linuxserver/ffmpeg`：`-c:a libvorbis -q:a 5`。

## 6. 權利邊界

WAV 與 ogg 都是**原版衍生物**：`workplace/` 已在 `.gitignore` 裡，
**不進版控、不進發行包**（`CLAUDE.md` §9）。公開的只能是「怎麼從自己
合法持有的原版產生這些檔案」的腳本與說明。
