# 72 — 兩邊第一次開同一場仗：九區裡七區 0 px

**狀態：通過。** 同一份 `SAVE-B.DAT`、同兩支軍團、同一座城，
原版與 remake 各自開出**同一場攻城戰**逐區比：
**七區逐像素相同**，`field` 0.10%（180 px），`sb-minimap` 2.50%。

⭐ 這是這個專案第一次**兩邊開的是同一場**。先前戰場那一組的殘差
（[`51`](51-siege-deadlock.md)：`field` 0.86%）成因就是「不是同一場」，
現在那個變因拿掉了。

- 日期：2026-09-05
- 規格：[`../spec/91`](../spec/91-tactical-parity.md)（九分區）、
  [`../spec/90`](../spec/90-same-state-parity.md) §2.3（`-siege-corps`）
- 原版側：dosgolem 的 **`siege:35,82`**（見 §1）→ `runto:11B5A` → `steps:6000000`
  → `workplace/dosgolem/siege/s1.png`
- remake 側：`tools/parity_shot.sh out.png -direct -scenario 0 -player 0 -seed 7
  -save-file <SAVE-B.DAT> -load-slot 0 -open-siege -siege-corps 35,39
  -siege-node 82 -battle-steps 0 -audio workplace/audio -shot-frames 1`
- 那一場：**呂布軍（#35）攻許昌（82），夏侯惇軍（#39）守，玩家是守方**

## 1. ⭐ 怎麼讓原版開一場指定的仗

先前只能**等 AI 打過來**——4.57 億道指令、35 個遊戲日，而且打哪一場不由人。
現在直接叫原版自己那一支：

```
sub_14ADE(si ＝ 攻方軍團記錄, di ＝ 據點記錄)
```

它自己會做完其餘的事：清「被擋住」位元、寫 `word_10D32`（據點）、
`byte_10D34`（**戰場編號 ＝ 據點編號**）、`byte_10D35`（旋轉旗標）、
配 256 byte 的堆疊暫存區、用 `sub_14C72` 依**位置與勢力**挑出守方軍團，
再走 `sub_14ED7`。**守方不必指定。**

`tools/dosgolem.sh` 的新動作：

```
siege:35,82        # 軍團 35 打據點 82
```

成本從 **4.57 億道指令降到 4,380 萬**（約 4 分鐘），而且要打哪一場自己挑。

### 1.1 兩個踩過的坑，兩個都是靜默的

| 坑 | 症狀 | 為什麼 |
|---|---|---|
| **段用了正規化的段** | 原版判定「兩邊都不是玩家」直接自動判定，戰術畫面不開 | `IDA(linear)` 回的是 `線性 >> 4` 的段。跳進去之後常式裡每一個 `cs:byte_10CFF` 這種**絕對定址**全部偏掉——讀到的是另一塊記憶體，**而且不會報錯**。要用**程式自己現在的 CS**（`oracle.IDAIn`）|
| **從任意一點叫下去** | 畫出一個內容是雜訊的訊息框然後卡住 | `steps` 停在哪就叫哪，有可能停在某支繪圖常式中間。改成先跑到 `sub_1E453`（命中測試，主迴圈每一圈都會進）再叫——**進到那裡就表示遊戲正閒著等輸入** |

⭐ 第二個修法順帶把堆疊平衡也解決了：假返回位址用 `sub_14ADE` 自己的 `retn`，
它會再彈一次——彈掉的正好是 `sub_1E453` 的返回位址，
於是遊戲回到閒置迴圈，像那一圈的命中測試回來了一樣。

⚠ 開戰訊息（TALK #1B「呂布的兵馬，向許昌進攻過來了！！」）**會自己過**，
不必點——實測約 2,600 萬道指令。點它反而會拿到「畫面沒變」的錯誤。

⭐ **`sb-enemy` 與 `sb-self` 這次是 0 px**——那兩格印的是雙方主將名與兩條
計量條，先前一直有殘差是因為兩邊打的不是同一場。

`field` 那 180 px 就是 [`40`](40-tactical-parity.md) §8–§10 列的「原理上消不掉」那幾樣：
**原版畫的滑鼠游標**（差分圖上那支紅色箭頭）與**旗的揮舞相位**（兩邊各自擲骰）。

⭐ **取樣點不敏感**：remake 側 `-battle-steps` 掃 0／4／6／12／16 都是同樣的
180 px（9 是 300 px）。與 [`70`](70-dosgolem-tactical-commands.md) §3 量到的
「原版前 45 個節拍兩軍幾乎不動」一致——**開場那一段是穩定的取樣窗**。

## 3. ⚠ 小地圖挖出一個新的差異

`sb-minimap` 那 512 px **不是**地形也不是陣線——地形與那條黃線逐點相同。
差的是**部隊點**：原版的點分成兩排、位置不規則，remake 的是一排規則的點。

⭐ **小地圖是唯一看得到整個戰場的一區**。`field` 只畫得下鏡頭裡那一塊，
所以「鏡頭外的部隊擺在哪裡不一樣」這件事，**只有小地圖看得見**——
`field` 0.10% 與 `sb-minimap` 2.50% 不矛盾，它們看的不是同一批部隊。

⚠ 這也是為什麼不能把小地圖當成「附屬的小圖」略過。
