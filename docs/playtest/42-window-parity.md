## 1. 怎麼拍到的

第一趟 timeline（開機 → 大地圖 → 存檔定位 → 系統選單 → 財政 → 數值器）：

```
wait:130;（NEW GAME 四步）;click:0,0;click:37,0;press;   ← 鏡頭歸零、開命令視窗
click:46,0;press;…;savefile:SAVE.DAT                     ← 存檔定位（196年4月6日）
click:15,5;press → 財政（指令列 #2，遊戲 x 120–160 ⇒ 主機 x ≈ 15）
click:268,202;press → 次月稅率的綠格（模態視窗內是視窗座標，y×1.2）
```

第二趟只做「編成」：進大地圖後**立刻**點（`click:20,5`，已驗證座標），
搶在事件訊息之前——第一趟的武將一覽與編成就是被
荀彧進言／陳留求援兩則訊息吃掉點擊而失敗的（`40` §1.3 的同一個坑）。

指令列的主機 x 就是遊戲 x ÷ 9.6：進言 #0 ⇒ 5、財政 #2 ⇒ 15、編成 #3 ⇒ 20
（已實測命中）。四類視窗開著時原版時間都停（說明書 3.1），
本身就是合格的對拍狀態。

## 3. 數值輸入器：1.06%，剩游標位置

`--rect 288,176,112,80`（存還原區）。修掉兩項之後從 32.63% 收斂：

| 修掉的 | 證據 |
|---|---|
| **外框**：原版在 96×64 資源外面還有一圈標準視窗框（112×80，內部 96×64 剛好被資源蓋滿），remake 原本讓資源直接浮在地圖上 | `p6-amount.png`：紅紋上下邊 ＋ 黃柱兩側 |
| **值列不補零**：值 0 畫成單一「0」右靠在六格欄位最右（8×16 字模、白、topY ＝ 錨點 Y），remake 原本畫「000000」 | `p6-amount.png` 墨水 x 337..342、y 185..198 |

剩餘 95 px 是 **remake 的游標**：原版那一刻游標停在財政視窗的綠格上
（存還原區外），remake 的鍵盤 fallback 把箭頭畫在「0」格。游標位置是
狀態不是版面（`spec/90` §4.1 同類），不列缺陷。
按鍵圖（7–9、取消／最大／決定）與格線在第一輪就逐像素一致。

## 5. 進言五項選單：輸入模型拍不到

INT 33 的 `AX=5` 回的是**當下按鍵狀態**不是計數，`clickat` 按住 0.12 秒，
剛開起來的選單再 poll 一次就看到「按著」，用當時游標位置選列——框外游標
被 `sub_193E9` 夾到列 0，所以**點開進言的同一下就選了「敵對提案」**
（`40` §1.2 的已知限制）。副產品：拍到了**交戰提案的目標勢力一覽**
（`parity-windows/p4-advise.png`，`orig-w3-target.png`），
remake 沒有對應的 fixture 旗標，這一格留給下一輪。
