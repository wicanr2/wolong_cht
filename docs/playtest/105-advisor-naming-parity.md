## 2. 五個缺陷

### 2.1 ⭐⭐ 選字表的底色與字色**整組反了**——同一種錯誤第二次

`sub_1928A` 畫本頁 96 個字時 `mov ax, 9000h`，`ah = 90h`
＝ **背景 9（米色）／前景 0（黑）**。remake 讀成「前景 9」，
於是整張選字表是**黑底米字**——43,008 px 全差，而肉眼幾乎看不出來
（字的形狀與位置都對）。

⚠ 這與 [`../re/52`](../re/52-slot-select-window.md) §4 的四槽視窗日期欄
**完全同型**（`CONTEXT.md` §6 記過一次）。
**屬性的兩個半位元組是「背景︰前景」，不是相反。**

### 2.2 聲母列沒有底

原版那一條是 (200, 216, 336, 16) 的黑底；remake 只畫字，
於是**露出視窗的藍底龍紋**。⚠ 熱區 `0x25` 是 216 起（第一格空白點不到），
**繪製範圍比熱區往左多 16 px**——照熱區填會少一格。

### 2.3 按鈕文字是置中的，不是固定內縮

三個按鈕量出來的文字左緣是 360／416／**480**：
「重來」「繼續」寬 48 ⇒ +8，「確定」寬 64 ⇒ **+16**。
remake 一律 +8，「確定」因此偏左 8 px。

### 2.4 六格底線少一格

`sub_19223` 的 `sub_1F1A3(si = dx + 0Eh)` 是「從 x 畫到 x+14，**含端點**」
⇒ 15 px。remake 寫 `namingCellW-2` ＝ 14，六格各差 1 px。

### 2.5 「別　號」標籤畫在視窗外

`namingLabelAliasX` 是 **144**，而視窗從 x ＝ 192 起——標籤落在框外的地圖上。
原版是 432（六格 `dx = 1C0h` ＝ 448 的左緣 −16）。

## 3. 剩下的 95 px

x 350–363、y 255–268 ＝ 原版自己畫的滑鼠游標，停在剛點過的「自定」
按鈕位置。旗標語意見 [`../re/88`](../re/88-mouse-cursor-visibility.md)。
