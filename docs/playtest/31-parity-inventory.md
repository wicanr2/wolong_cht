[`27`](27-original-video-frame-parity.md)，這一份把**還沒對上的東西**
逐畫面列出來，每一項標明證據等級與下手點。

- 日期：2026-08-16
- 原版側：`workplace/promo-live/original-video/original.mp4`
  的第 4／6／11／17／21 張抽樣影格（每 15 秒一張，抽法見

## 2. ⭐ 一覽表的欄位：原版的表頭就在 `KI.EXE` 裡

| 表 | 原版表頭（`KI.EXE` 位移）| remake 現況 |
|---|---|---|
| 武將 | `武將名　武術 統率 政治　　勢力　　　身分`（`0x7758`）| 武將名 武術 統率 政治 **評價** |
| 據點 | `據點名　生產力　上昇率　防災　城兵　內政官`（`0x7578`）| 據點 距離 所屬 城兵 |
| 軍團 | `武將名　總兵數　士氣值 現在位置 目標據點`（`0x72FC`）| 大將 兵力 士氣 所在 目標 |
| 勢力 | 欄位對應見 [`../re/27`](../re/27-list-row-fields.md) §2 | 未逐欄比對 |

⚠ **「評價」是 remake 加的**（說明書 10.5 的戰力概念），原版沒有這一欄。
反過來原版有的 **勢力／身分** remake 沒有。

四張表的欄位、格式（總兵數與城兵 **×10**、上昇率 **先減 100**、
士氣 < 100 換色、委任標記）在 [`../re/27`](../re/27-list-row-fields.md)
都已經解出來——**這一項是「照著做」不是「還要解」**。

## 5. 建議的順序

1. **攻方不前進**（規則層，攻城可玩與否的門檻）
2. **一覽表照 `docs/re/27` 重做**（四張表；RE 已完成，純實作）
3. **編成畫面補肖像 ＋ 拿掉鍵盤提示塊**（小）
4. 底列命令圖示（要先找載入端）
5. 視窗底紋（要先在 `ICONGRF` 裡定位）
6. M7 文意層、M8 實機驗收（人工，長）
