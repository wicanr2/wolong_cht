## 1. 為什麼野戰難、這一輪怎麼繞

野戰要**兩支軍團在野外同格**。用滑鼠時間線在原版裡編軍團＋下行軍令，
連續六趟卡在三件事：

1. **選單第二列點不到**（`40` §1.2 的輸入模型限制）——「軍團 → 行軍指示」
   在第二列。`tap:`（瞬按 30 ms，本輪加進 `dosv_live_capture.sh`）仍趕不上
   選單的第一次 poll。KI.EXE **全庫零次 `int 16h`**，鍵盤路線也不存在。
2. 位置確認的軍團選取是**地圖游標流程**，目標格多半在畫面外。
3. 每一步操作時間都在走，4月8日 的事件訊息鏈會把後續點擊整串吃掉。

繞法：**不操作 UI，直接改存檔**。存檔格式已全解（`formats/08`），
把一支軍團擺到 AI 軍團的行進路徑上，原版從標題畫面 LOAD DATA 讀入，
幾個遊戲時辰後自然遭遇。

## 2. 改造存檔的配方

基底：`parity-battle4/SAVE-B.DAT`（196年4月16日，呂布軍團 35 正沿
y=108 的路從 (254,109) 西行往陳留，`tools/…/fieldtrace` 用 remake 的
行軍層印出它未來每一格與到達 tick）。

改軍團 39（夏侯惇）的 64 B 記錄（區塊 `+0x22C0 + 39×64`）：

| 欄位 | 值 | 為什麼 |
|---|---|---|
| `+0x0E/0x10/0x12` 現在 | node 470×8、(248,108) | 呂布路徑上、他 130 tick 後踩到的格 |
| `+0x14/…/0x20` 目標 | 陳留（76） | **目標必須是據點**——目標＝自己（野外格）時原版把它當非法狀態，軍團變幽靈 |
| `+0x08` 朝向 | 0（西） | 合法行軍狀態 |
| `+0x0B`／`+0x1E` 計時器／間隔 | 200／200 | 龜速：實質站著等，但狀態是「行軍中」 |
| `+0x00` | `\|= 2` | 「下一步要重算」——原版讀檔後自己重查道路表，路徑狀態必自洽 |
| **`+0x1A`/`+0x1C`** 佔用圖快取 | X=248、段=舊值+(108−114)×24 | ⭐ **不改就是幽靈**（§3）|

## 3. ⭐ 佔用圖快取欄是讀檔後接觸判定的一部分

第一版只改座標，原版讀檔後**呂布直接穿過夏侯惇**（`parity-field11/12`
的影片），遭遇不觸發。原版的接觸判定讀**單位佔用圖**
（`sub_12708` 的 `cmp byte ptr [di],0`），而讀檔後重建佔用圖用的是
軍團記錄裡的**快取欄 `+0x1A`/`+0x1C`**（`sub_16F86` 寫入：
X ＝ 段內位移、段 ＝ `word_19872` ＋ Y×24），不是從座標重算——
快取指著舊位置，佔用就登記在舊位置，新位置是空格。
**改存檔搬軍團，這兩欄一定要跟著搬**（段基底逐次執行相同，
差分 `(newY−oldY)×24` 就可以算）。推論等級：強證據
（兩組對照實驗：不改→穿過、改→遭遇；機器碼位址見 `re/08` §5–§6）。

## 4. 原版側的 timeline

```
WOLONG_DOSV_SEED_SAVE=SAVE-FIELD.DAT tools/dosv_capture.sh parity-field14 \
 "wait:130;click:320,245;wait:3;      ← NEW GAME 答 NO（NO 在 (320,238)）
  click:318,186;wait:1;press;wait:2;  ← LOAD DATA 槽 1（熱區在日期鈕，game y≈144–160）
  press;wait:1;rclick:318,186;wait:1;rclick:318,186;  ← 關掉讀檔後的據點情報框
  wait:16;shot:b0;…"                  ← 遭遇約在解凍後 3 秒，戰場 15 秒內開
```

- `WOLONG_DOSV_SEED_SAVE`（本輪加進兩支 capture 腳本）把輸出目錄裡的
  檔案預置成遊戲目錄的 `SAVE.DAT`。
- LOAD DATA 的槽也是標準熱區（`sub_18B7C` → `sub_1E453` 回 `0x20+槽`），
  第一輪點不到是 y 落在熱區下緣外——**熱區是日期鈕那 16 px 高**。
- 流程：軍師報「夏侯惇大人的兵馬，遇上呂布　的兵馬了！！」→ 戰場淡入。
- ⚠ **像素對拍不能用 `grab-start:` 的 mp4**——H.264 失真，逐區 diff 全部
  99%。影片只拿來定時序，比對一律 `shot:` 的 PNG。

## 5.1 應戰全程的實機錄影（2026-08-25，`parity-duel1`）

- d2：呂布挑戰喊話掛著，**大將已騎到半路**——就位是寫目標騎過去，
  沒有任何瞬移。

- d7：對打段，兩騎被同一個隨機目標牽著在中場繞場互追；
  **兩軍全程靜止**（腳本在 `sub_1A1C5` 返回前一步都不跑）。
- d9：決著（夏侯惇 0x1CC「手下們上吧」／呂布 0x1CD），
  此刻兩軍才開始出現在畫面邊緣。
