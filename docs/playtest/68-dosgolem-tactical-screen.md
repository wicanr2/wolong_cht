# 68 — dosgolem 開出戰術畫面：不隨戰況變的九分之四逐像素相同

**狀態：通過。** 不經過 DOSBox、不經過 X，`KI.EXE` 在 dosgolem 裡跑到
**許昌攻防戰的戰術畫面**（196年5月26日，呂布軍攻、夏侯淵軍守）。
拿它跟 DOSBox-X 的原版擷取（196年5月20日，張遼軍攻、夏侯惇軍守）逐區比：
**四個不隨戰況變的區全部 0 px**，會變的四個區差在正確的位置。

⭐ 兩張是**不同的兩場仗**，所以「哪些區該相同」事先就算得出來——
這比同一場仗比 0 px 更能分辨「畫得對」與「剛好一樣」。

- 日期：2026-09-05
- 規格：[`../spec/91`](../spec/91-tactical-parity.md)（九分區）、
  [`../spec/131`](../spec/131-dosgolem-oracle.md)（dosgolem oracle）
- DOSBox-X 側：`workplace/promo-live/probe-march/e10.png`，
  `tools/parity_crop.py` 裁成 640×400
- dosgolem 側：`workplace/dosgolem/battle/j3-battle.png`
- 比對：`tools/parity_diff.py --regions tactical`

## 1. 怎麼走到的

```
wait                    開機
click:320,200           NEW GAME → NO（＝ LOAD DATA）
click:300,151           存檔格 1
until:196/4/20          對齊日期
sclick:352,15           橫幅第一個圖示 → 開指令列
stap:192,47             「編成」→ 武將一覽
tap:150,112 ×2          反白第一列，再點同一列 → 編成面板
tap:324,279             「確定」→ 夏侯淵軍成軍，駐在許昌
tap:320,200             關掉對話
rclick:320,200 ×2       離開編成
runto:11B5A,600000000   ← 跑到程式走進戰術畫面
steps:6000000 / shot
```

⭐ **取樣點寫成「事件」不是「秒數」。** 即時制的難處在
「不知道要等幾天」，但知道開戰一定會走到 `sub_11B5A`
（[`../re/09`](../re/09-combat.md) §2）。`runto:` 就是為了這個加的。
實際等了 **4.57 億道指令 ＝ 35 個遊戲日**（4月21日 → 5月26日）。

⚠ **不要下行軍指示。** 讓軍團留在首都，等 AI 打過來——
與 [`40`](40-tactical-parity.md) §1 的原版作法同一條。實測下令攻宛之後
跑了 108 個遊戲日都沒有開戰（記在 [`../re/85`](../re/85-march-target-hit-test.md) §5）。

⚠ **軍團一定要有。** 玩家守方而城裡沒有軍團時原版**不進戰術畫面**
（`cmp bx, 4200h`，[`../re/09`](../re/09-combat.md) §2）。實跑攔到兩次
這種自動判定，`sub_15130` 的呼叫端正是 `0x14EFB` 那一支。

## 2. 結果

| 區 | 不同像素 | 佔比 | 判定 | 該不該一樣 |
|---|---:|---:|---|---|
| `field` | 7,775 / 176,640 | 4.40% | FAIL | ❌ 兩軍位置不同 |
| `bottom` | 2 / 15,360 | 0.01% | NEAR | ⭕ 六格編成圖示 |
| `sb-title` | **0** | **0.00%** | **PASS** | ⭕ 「許昌　作戰／曹操　對呂布」——**兩場的攻方勢力都是呂布** |
| `sb-enemy` | 192 / 5,120 | 3.75% | FAIL | ❌ 呂布軍 vs 張遼軍 |
| `sb-minimap` | 584 / 20,480 | 2.85% | FAIL | ❌ 兩軍的點 |
| `sb-self` | 118 / 6,400 | 1.84% | FAIL | ❌ 夏侯**淵**軍 vs 夏侯**惇**軍 |
| `sb-formation` | **0** | **0.00%** | **PASS** | ⭕ 十六個陣形（純美術）|
| `sb-command` | **0** | **0.00%** | **PASS** | ⭕ 六列指令（純美術）|
| `sb-arrow` | **0** | **0.00%** | **PASS** | ⭕ `▶▶` 列（純美術）|

⭐ **`field` 那 4.40% 全部是兵。** 差分圖上城牆、屋舍、河、橋、草地
一點紅色都沒有——45 度視角的地形、圖塊拼接、遮擋順序在 dosgolem 這一側
與 DOSBox 逐點相同。紅的只有右上角攻方那一整排、橋邊幾支、以及游標。

⭐ **`sb-self` 的 118 px 只差一個字**：夏侯淵／夏侯惇的第三個字。
`sb-title` 之所以 0 px，是因為兩場的攻方**勢力**都是呂布——
張遼是呂布的武將。這一格印勢力，`sb-enemy` 才印軍團主將。

## 3. 這一輪驗到了什麼

`field` 的地形、四個純美術區、`bottom` 的編成圖示——這些是
**圖庫解碼、45 度投影、側欄版面與字型**在戰術畫面這一層的全部輸出。
它們與 DOSBox 逐點相同，等於把 dosgolem 的戰術畫面整層驗過。

⚠ **這不是 remake 的對拍。** remake 那一側仍以
[`40`](40-tactical-parity.md)／[`49`](49-parity-retest-20260827.md) 為準。
這一份加的是「原版側的戰術畫面現在拍得出來，而且不必 DOSBox」——
接下來 remake 要對的原版擷取可以直接由 dosgolem 產，
取樣點寫成 `runto:` 的事件，可重現。
