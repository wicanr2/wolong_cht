### 1.1 主畫面那 101 px 是同一個圖塊的相位差

差異落在 x 320–335、y 208–223 —— **正好一個 16×16 的格子**，在地圖正中央。
把兩邊那一格印成點陣圖，是**同一種格子紋樣**，只是 remake 的往下錯開
一到兩列：

```
原版    remake
######################  ##############.#
#+#+++###+#+++##        ##...........##.
#+#+++###+#+++##        #..+++###+#++.#.
```

⇒ 不是畫錯圖塊，是**取樣的相位**（或那一格的動畫階段）差一點。

## 2. 都不是這一輪造成的

`git checkout c2c3522 -- internal cmd` 重截，再比同一張原版圖：

| 組 | 這一輪的程式碼 | `c2c3522`（這一輪之前）|
|---|---|---|
| 主畫面 `map` | 101 px | **101 px** |
| 野戰 `field` | 190 px | **190 px** |
| 野戰 `sb-minimap` | 128 px | **128 px** |

⇒ 落差是 2026-09-02 之後某一輪引入的。那段期間的每一輪都在改規則層
（行軍、戰鬥、AI、月結），**沒有一輪回頭重跑畫面對拍**。

⭐ 這正是 `CLAUDE.md` §10 那條「測試綠不等於原版 parity」的另一面：
**規則對拍綠了，不代表畫面對拍還綠**——兩者是兩套證據，而規則層的
每一次改動都可能動到畫面。

## 3. 攻城那一組重跑不出來

[`58`](58-parity-retest-20260902.md) §1.2 的三個取樣點寫的是
`-battle-steps 160/240/300`，原版側只寫「`workplace/promo-live/parity-battle4/`」
——**沒說哪一張 PNG 對應哪一拍**。

那個目錄有 `t1`–`t16` 十六張圖，但**取樣點對不回遊戲時刻**：
`capture-metadata.txt` 的時間軸是 `wait:6;shot:t1;wait:6;shot:t2;…`，
`wait` 是**牆上秒數**，而這一款是即時制——同一串 `wait` 每次停在不同的
遊戲日期（`CLAUDE.md` §3.1）。**不是檔案不見，是取樣點不可重建。**

⭐ 攻城**另有一組對得起來的**：[`72`](72-same-battle-parity.md) 的
dosgolem `siege:35,82`，已收進 [`121`](121-screen-parity-gate.md) 的閘。

⇒ **對拍紀錄要寫得能重跑**：原版圖的路徑、取樣點、命令三者要同時在場。
這一條已經是 `tools/stale_scan.py` 在擋的那一類（對拍紀錄的 `remake 側`
漏了受控存檔），只是它擋不到「原版側漏了是哪一張圖」。

## 4. ⭐ 根因：截圖裡多畫了桌面模式的游標

`git bisect run`（8 步，`good` 判準是主畫面 `map` ＝ 0 px）指到
**`ef666c5`「完成桌面操作修正、呂布 AI 根因與 v.1.0.18 發行準備」**
（2026-09-08，111 個檔案）。那一批把 `drawMouseCursor` 從
「只在 `-cursor X,Y` 指定時才畫」改成「桌面捕捉模式也畫」，
還讓 `drawMapPickCursor` 在游標所在那一格畫一個 **16×16 的白黑框**。

⇒ 主畫面那 101 px 就是那個框（顏色只有白 `(243,243,243)` 與黑，
位置 x 320–335、y 208–223 正好一格）；野戰多出來的 95 px 是那個箭頭。

修掉之後（[`../spec/197`](../spec/197-shot-mode-draws-no-desktop-cursor.md)）：

- 主畫面 **五區全 PASS** ＝ 256,000 個像素一個不差
- 野戰 `field` **95 px**，與 [`58`](58-parity-retest-20260902.md) 同值
  （那是原版錄影裡的滑鼠游標，消不掉）

## 5. 還沒解決的

- **野戰 `sb-minimap` 128 px（FAIL）**，文件記的是 32 px。差異點的顏色是
  地形米色、敵方紅點與我方藍點——**部隊點的位置差**，而同一張的
  `field` 區只差原版游標。這一個不是夾具問題。
- **攻城那一組重跑不出來**（§3）。
- 主畫面與野戰之外的對拍組還沒逐一重量。
