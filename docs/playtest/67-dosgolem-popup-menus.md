## 1. 腳本（三張只差一個 x）

```
wait                 開機
click:320,200        NEW GAME → NO（＝ LOAD DATA）
click:300,151        存檔格 1
until:196/4/20       ← 對齊到原版擷取的那一天
sclick:352,15        橫幅第一個圖示 → 開指令列
stap:288,47          指令列第 6 格「據點」（人事 96、軍團 240）
steps:300000
```

| 指令 | 指令列 x |
|---|---|
| 進言 24..71｜人事 72..119｜財政 120..167｜編成 168..215 | |
| 軍團 216..263｜據點 264..311｜武將 312..359｜勢力 360..407 | 八格各 48 px，起點 24 |

格寬與起點是從**熱區圖**讀出來的（`#12 x 24..407 y 40..55`），不是量的。

⚠ **彈出選單一定要用 `stap`（瞬按），不能用 `click`。** 長按會在選單開起來的
那一瞬間被下一次 `AX=5` 輪詢看到，用當時的游標位置立刻選走第一列——
與 [`54`](54-menu-second-row-tap.md) 記的是同一件事。

## 3. ⭐ 日期對齊：把 110 px 變成 0

同一組比對，只改日期對齊點：

| 對齊到 | `banner` |
|---|---:|
| 不對齊（載入即開，4月16日）| 110 px |
| `until:196/4/18` | 52 px |
| `until:196/4/19` | 55 px |
| **`until:196/4/20`** | **0 px** |

⭐ 選單開著時遊戲時鐘停住（`until:196/4/20` 之後開選單，截圖時仍是 4月20日
19時），所以「先跑到某一天再開選單」是可重現的。

## 4. 這一輪沒有抓到新缺陷

三張走同一支 `popupMenu`（[`../spec/126`](../spec/126-command-popup-menus.md)），
而位置與字數是各自的立即值。這一次比的是**原版對原版**
（dosgolem 跑的就是 `KI.EXE`），所以 0 px 驗的是 dosgolem 這一層——
繪圖、字型、熱區、輸入與時鐘全部對得上，才有可能三張都零。

**remake 那一側的比對仍以 [`60`](60-corps-menu-parity.md)／[`61`](61-city-personnel-menu-parity.md) 為準**，
這一份加的是「原版側的取樣可以做到多準」。
