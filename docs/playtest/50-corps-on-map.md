# 50 — 軍團在大地圖上：兩個缺口，逐像素對上

**狀態：許昌那一格（含周邊 56×56）與原版逐像素相同。**
兩個缺口都在 remake 這一側：剛編成的軍團朝向是 Go 的零值 0（＝朝 X 減走），
以及軍團站在首都中心格時 remake 仍然疊首都那一張。

- 日期：2026-08-27
- 規格：[`../spec/74`](../spec/74-corps-on-world-map.md)（§3 圖塊算式、§4.05 取捨、§4.1 驗收路徑）
- 原版側：`workplace/promo-live/parity-probe/p2-ok2.png`（開局，沒有軍團）與
  `workplace/promo-live/probe-march/e5.png`（196年4月15日，曹操剛編成一支軍團）
- remake 側：`tools/parity_shot.sh out.png -direct -scenario 0 -player 0 -seed 7
  -corps-on-map [-march-to 72] -shot-frames N`

## 1. 為什麼要重驗

`spec/74` 的驗證欄寫的是「編成一支軍團 → 截圖，首都那一格要多出軍團圖塊」，
而那一格**真的多了 122 px**——看起來就像做完了。

⚠ **「有變」不等於「畫對了」。** 拿原版同狀態的截圖對過才知道，
那 122 px 有 171 px 是錯的。

## 2. 對齊

兩邊的鏡頭不同，先用一塊 120×100 的樣板在原版側掃出位移：
remake 的 (260,180) 對到原版的 (276,68)。對齊之後**首都周邊 56×56
只有中心那一格不同**，其餘 0 px——位移是對的，差異是真的。

| 比什麼 | 不同像素 |
|---|---:|
| 首都周邊 56×56（未修）| 171 / 3136 |
| 其中中心那一格 16×16 | 171 / 256 |

## 3. 缺口一：剛編成的軍團朝向是 0，不是「靜止」

`CorpsTile(faction, heading) = faction*5 + heading`，朝向 4 是靜止
（[`../spec/74`](../spec/74-corps-on-world-map.md) §3）。而 `FormCorps` 沒有設
`Heading`，Go 的零值 0 是「朝 X 減的方向走」——大地圖上畫的是側面行進的圖塊。

改成 `HeadingStill` 之後那一格從 171 px 降到 40 px。

> **教訓寫成規則**：`CLAUDE.md` §7 第 11 條（原版的哨兵值不等於 Go 的零值）
> **對「有意義的零」同樣成立**。這裡的 0 不是哨兵值，是一個**合法而錯誤**的方向——
> 比哨兵值更難發現，因為它畫得出東西來。

## 4. 缺口二：軍團站在首都中心格時，首都疊圖不畫

剩下的 40 px 全在圖塊的外圈——軍團圖塊在那一圈是透明的，
所以露的是底下哪一層。窮舉那一格的所有組合（首都疊圖 開／關 × MCH 圖塊 0–255，
共 512 種），**只有一種是 0 px**：

| 組合 | 不同像素 |
|---|---:|
| **據點中心（自勢力）＋ MCH 4，不疊首都** | **0** |
| 據點中心 ＋ 首都疊圖 ＋ MCH 4 | 40 |
| 據點中心 ＋ 首都疊圖，無軍團 | 195 |
| 據點中心，無首都疊圖、無軍團 | 162 |

⚠ **首都疊圖本身沒問題。** 開局主畫面（沒有軍團）五區逐像素相同，
這一輪重驗仍是 0 px。兩個都對，錯的是**同一格同時有兩者**時的取捨。

機制沒讀出來——`sub_1D4C7` 的顯示表是後推的疊在前面的
（[`../re/72`](../re/72-world-map-display-list.md) §3），照那個模型兩層都該畫。
所以這一條的推論等級是**強證據（實機逐像素 0 差）**，不是 confirmed。

## 5. 結果

| 局面 | 比什麼 | 結果 |
|---|---|---|
| 開局，沒有軍團 | 五區 vs `p2-ok2.png` | **全 0 px**（沒有回歸）|
| 軍團站在首都裡 | 首都周邊 56×56 vs `e5.png` | **0 px** |
| 軍團在路上 | `-march-to 72 -shot-frames 80` | 軍團出現在 (274,144)–(287,159)，紅色凸字形，離開首都；首都那一格回到原本的首都疊圖 |

「軍團在路上」原版沒有對應的擷取——那一輪的腳本沒有下行軍指示
（[`40`](40-tactical-parity.md) §1 是「編成之後等 AI 來打」）。
所以這一格只有 remake 側的實跑，**不是對拍**。
