# 38 — 三個視窗開著時的對拍：三個視窗區逐像素相同

**狀態：通過。** 命令列、自勢力情報、縮小地圖**三區逐像素 PASS**；
大地圖只差一團天候物件，那是**狀態差**不是版面差。
⭐ **原版的主畫面收得到點擊**，先前記著「模擬器上點不到」是座標算錯。

- 日期：2026-08-17
- 規格：[`../spec/90`](../spec/90-same-state-parity.md)（管線）、
  [`../spec/54`](../spec/54-ui-colours-from-palette.md)（顏色）
- 原版側：`workplace/promo-live/parity-win/w3-all.png`（松崗 DOS/V，196年4月11日）
- remake 側：`tools/parity_shot.sh out.png -direct -scenario 0 -player 0
  -seed 7 -open-window -2 -cam 4,0 -shot-frames 1`

## 1. 怎麼把原版的視窗點開

進到大地圖之後 **INT 33 的範圍換成整個世界**（`sub_120D6` 設
`0..0x17FF × 0..0x101F`，也就是 6143×4127 ＝ 384×256 格的像素），
螢幕座標 ＝ 原始座標 − 鏡頭原點。所以：

1. 一個主機像素 ≈ **9.6 個遊戲像素**，32 px 的開關只有 3.3 個主機像素寬。
2. 鏡頭原點是滑鼠原點除以 16，**移動滑鼠就會捲動地圖**。

解法是**先把游標推到左上角**：`sub_11F7F` 把螢幕座標夾在 0–639／0–399，
夾住的同時把原點也拉過去，所以送 `click:0,0` 之後鏡頭幾乎歸零、
游標落在 (0, 0)。之後 x 就是可算的：遊戲座標 352 ⇒ 主機 x ≈ 37。

```
click:0,0                       ← 鏡頭歸零，游標到左上角
click:37,0;press                ← 命令
click:40,0;press                ← 自勢力情報
click:43,0;press                ← 縮小地圖
```

⭐ **`click` 之後要再 `press`**：`sub_11F7F` 對「座標和上次不同」那一次
只更新座標不分派（[`../re/47`](../re/47-main-screen-window-registry.md) §3.1），
所以移動 ＋ 按下不算點擊，要停住之後再按一次。

⚠ 這樣點完鏡頭就不在開局位置了。實際落點用
`tools/find_camera.py` 從截圖反推是 **(4, 0)**，remake 用 `-cam 4,0` 跟上。

## 3. 改出來的六件事

| 項目 | 原版 | remake（修前）|
|---|---|---|
| 命令列的底 | **純黑**（色 0）| 深藍 ＋ 龍紋 |
| 縮小地圖的視野框 | `ICONGRF` 段 3 `+0x8F0` 的 24×11 點陣 | `StrokeRect` 描的純白矩形 |
| 五個介面顏色 | 調色盤 8／9／5／0／15 | 手抄的 RGB，每個差 2–4 |
| 資金與預備兵的數字 | 原版字模（`ICONGRF` 段 3 `+0x840`）| 倚天 ASCII |
| 信賴度量條的槽 | 純黑 | 硬寫 `(24,24,32)` |
| 圖例上兩個君主名 | (480, 168)／(576, 168) | 464／560（差 16 px）|
| 圖例右格盯的勢力 | **勢力 0**，可以等於自己 | 跳過自勢力 |

⭐ **龍紋不是每個深藍視窗都有。** 自勢力情報有，命令列沒有。

⭐ **圖例右格開局盯的是勢力 0。** 原版沒有初始化 `cs:byte_198A7`，
資料段開機是 0，所以曹操局的實機截圖上**兩格都是「曹操」**。
擋自勢力的是選單（`sub_15AFC`），不是初值。
remake 先前一律跳過自勢力，於是連縮小地圖的據點標記顏色都跟著錯
（「盯著的勢力」那一類本來不該有人）。

## 4. 視野框也解掉了

框的位置量得很準（兩個不同鏡頭各量一次）：

| 鏡頭 | 白框的橫線 | `440 + camX/2` |
|---|---|---:|
| (4, 0) | y 40 與 49，x 441–457 | 442 |
| (214, 10) | y 45 與 54，x 546–562 | 547 |

⭐ 一致差 **−2 px ＝ −4 格**，而 4 正是
[`../spec/52`](../spec/52-main-screen-camera-and-banner-date.md) §4 那個
「機器碼寫 20、實機量到 16」的差——**兩件事是同一件**：
原版的鏡頭變數比畫面上 x=0 那一欄小 4。

框本身是**點陣**：`sub_196ED` 從 `ICONGRF` 段 3 `+0x8F0` 的 176 byte
讀出 24×11 的 4 bpp 小圖（白邊 ＋ 右下黑影），
規格與圖形見 [`../spec/55`](../spec/55-minimap-view-box.md)。
畫上去之後這一區歸零。

## 5. 未解

| 項目 | 現況 | 下手點 |

| 那 4 格從哪裡加的 | 兩處都量到 −4，機器碼裡還沒找到加它的那一行（`../spec/55` §5）| 讀 `sub_1D66A` 的畫面起點 |

| 四個視窗全開 | 這一輪只開了三個。第四個是**系統選單**，開著時原版**時間停止**，是另一種狀態 | 另外拍一張 |
