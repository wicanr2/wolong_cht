## 2. 兩種掛載方式，只有一種能跑

| 模式 | 結果 |
|---|---|
| `imgmount` 五片 `.fdi` ＋ `boot -l a` | ❌ 遊戲跳紅底「**ファイルが異常です。マウスをクリックしてください。**」 |
| **`mount c` 掛合併後的目錄** | ✅ 正常執行 |

原因在 E 片（MS-DOS 5.0 系統片）的 `AUTOEXEC.BAT`：

```
C:\
CD GARYO
YNSHELL
```

**原版本來就是要裝到硬碟跑的**，`HDINST.EXE`（D 片）負責安裝，
它的字串表就是要複製的檔案清單。遊戲預期所有檔案在同一顆硬碟上，
五片分開掛就跨片找不到檔。

`mount c` 掛合併目錄等價於「已經裝好」的狀態，而且**跳過 FGDOS**
（A／B 片的自製載入器，`FGDOS initial command executer Ver 1.01
Copyright(C)1992 by FUGA System`）與換片流程。

## 3. ⚠ 多片抽檔的合併陷阱（自己踩到並修好）

`tools/fdi_extract.py` 一開始把五片抽進同一個目錄，
**同名檔會被後面的片靜靜蓋掉**。

臥竜伝五片裡有 12 個檔跨片重複，其中 **11 個內容相同、1 個不同**：

| 檔案 | A 片 | B 片 |
|---|---:|---:|
| `YNSHELL.COM` | 2,699 B | 2,675 B |

B 片的版本蓋掉了 A 片的。**合併後的目錄因此不等於任何一片的真實內容。**

處置：

- `workplace/orig/pc98_discs/{A..E}/` —— **逐片抽出，權威來源**
- `workplace/orig/pc98/` —— 合併視圖，**A 片優先**（A 是主程式片）
- `fdi_extract.py` 現在遇到同名檔會比對內容，相同就跳過、不同就印
  `⚠ 已存在且**內容不同**（舊 N B），覆蓋`

> 這一類錯誤的特徵是**沒有症狀**：檔案數是對的、程式跑得起來、
> 兩版比對表也沒受影響（`dosv` 那邊叫 `YNVSHELL.COM`，名字不同）。
> 要不是為了跑遊戲去讀啟動流程，這個洞會一直在。

## 4. 開場過場（confirmed）

點滑鼠推進，敘述文逐段疊上背景圖：

```
官吏の腐敗と、黄巾の乱によって、時代は乱世へと急転する。
武と智を駆使して、英雄、英傑が、大地を駆け抜け、歴史をきざんで逝った
「三国志」の幕開けである。
その、権謀術数の嵐の中、知謀だけを武器とする、戦勝請負のプロがいた。
```

最後一句點出玩家的身分：**「只以智謀為武器、承包勝仗的專家」＝ 軍師**，
與說明書和維基說的「玩家扮演軍師不是君主」一致。

之後是幾張全畫面美術（諸葛亮持羽扇立於蜀軍旗下、戰場火光），
那批就是 `OPEN_S1..S6.DAT`——**兩版 byte-for-byte 相同**（`docs/re/01`），
所以這些畫面同時也是**驗證 `OPEN_S*.DAT` 解碼器的標準答案**。

### 排版事實

- 畫面 640×400，與反組譯讀出的列跨距 80 byte 一致。
- 敘述文在左半，背景圖在右半 → **文字與圖是分開繪製再合成的**，
  不是燒進圖裡。這與 `docs/reference/03` 從兩版 diff 推出的
  「開場沒有燒字」完全對上——**第一手畫面印證了第二手推論。**

## 5. 操作

遊戲吃滑鼠（`KI.EXE` 有 `ERROR: Mouse driver not install ?`，
PC-98 版另有 `YNMOUSE.COM`）。`tools/dosboxx.sh` 的 timeline 支援
`click:x,y`，用 `xdotool mousemove … click 1` 送。
