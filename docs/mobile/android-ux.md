# Android UX 規格

**狀態：規格已定，尚未實作。** 手機版**不照原版版面**，只共用規則層
（決定與理由見 [`android-plan.md`](android-plan.md) §1）。

- 日期：2026-08-20
- 前提：橫向、`minSdk 29`、只有 Docker 模擬器可驗

## 1. 設計前提

原版是 **640×400 的滑鼠式視窗 UI**：命令列一格 16×16、一覽表一列 16 px 高、
戰場的兵一格 16×16。這些熱區在 5 吋螢幕上約 2–3 mm，**手指按不準**。
所以手機版重畫版面，但有三條不能動：

| 不能動的 | 為什麼 |
|---|---|
| 規則層 | 時鐘、事件、數值、存檔格式一律共用；便利操作只能在輸入層做 |
| 原版美術 | 地圖圖塊、人物、戰場子圖塊、肖像全部沿用原版解碼結果 |
| 原版文字 | `TALK.DAT` 的 1,022 則與校訂表共用，不另寫手機文案 |

⭐ **重畫的是「怎麼擺、怎麼按」，不是「畫什麼」。**

## 2. 主畫面

```
┌──────────────────────────────────────────────┐
│ ☰  196年4月2日  午  ▶▶     資金 12,340  兵 8,200 │  56 dp 狀態列
├──────────────────────────────────────────────┤
│                                              │
│                                              │
│            大地圖（原版圖塊，可縮放拖曳）           │
│                                              │
│                        ╔════════╗            │
│                        ║ 選中的據點 ║            │  點一下→浮出小卡
│                        ╚════════╝            │
├──────────────────────────────────────────────┤
│  ⊕ 進言    ⊞ 一覽    ⚔ 軍團    ⚙ 系統          │  64 dp 指令列
└──────────────────────────────────────────────┘
```

| 區 | 高度 | 內容 |
|---|---|---|
| 狀態列 | 56 dp | 選單鍵、日期與時辰、速度、資金、預備兵。⚠ 全部是**唯讀顯示**，點資金不會開撥款 |
| 主區 | 其餘 | 大地圖或全螢幕 sheet |
| 指令列 | 64 dp | 四個主入口，各自 ≥ 48×48 dp |

安全區（瀏海、手勢列）由 Java 側取得後傳進 Go；**互動元件不得落在安全區外**。

## 3. 大地圖的操作

原版大地圖是 384×256 格、每格 16×16 px。手機上：

| 手勢 | 行為 |
|---|---|
| 單指拖曳 | 平移 |
| 雙指捏合 | 縮放，**只允許整數倍**（1×／2×／3×）——非整數會讓點陣圖糊掉 |
| 點一下據點 | 浮出資訊小卡（名稱、歸屬、生產力、城兵）＋ 該據點可做的事 |
| 點一下軍團 | 同上，小卡換成軍團欄位 |
| 點空白 | 收掉小卡 |
| 長按 | 不使用。⚠ 長按在 Android 上與系統手勢容易打架，而且 2026-08-11 的 `adb tap` 已經證明**瞬間 down/up 會跨幀**——長按當主要操作會讓驗收與實際手感不一致 |

⭐ **點選一律「先選中、再下令」兩段式**：第一段只改選取狀態、不動 `World`；
第二段才送指令。事件性的決定（外交、撥款）維持原版的確認框。

## 4. 指令列的四個入口

| 入口 | 開什麼 | 為什麼是主入口 |
|---|---|---|
| **進言** | 進言 sheet（八個指令）| 玩家是軍師，這是主要動作 |
| **一覽** | 四張表（武將／據點／勢力／軍團）分頁 | 原版四個一覽表，欄位照 `docs/spec/38` |
| **軍團** | 編成 → 行軍 | 兩個步驟接在一起，原版是分開的視窗 |
| **系統** | 速度、存檔、讀檔、離開 | 對應原版系統選單 |

sheet 一律**全螢幕**，不做浮動小視窗——手機上小視窗的關閉鍵太小。
Android 返回鍵：`關掉 sheet → 收掉小卡 → 離開確認`，**不直接結束**。

## 5. 戰場

戰場沿用原版的 45 度視角與子圖塊（那是資產不是版面），但控制重畫：

```
┌──────────────────────────────────────────────┐
│ 攻 張遼 8,200        vs        守 夏侯惇 6,400   │
├──────────────────────────────────────────────┤
│                                              │
│          45 度戰場（原版子圖塊，可縮放）           │
│                                              │
├──────────────────────────────────────────────┤
│ 左翼 左備 主將 前鋒 右備 右翼   ← 六格，點一格選一隊 │
├──────────────────────────────────────────────┤
│  陣形  突擊  城壁  弓  退卻  就位               │  六個命令
└──────────────────────────────────────────────┘
```

- 上排六格是**編成位置**（原版底列的空間排列：左翼 左備 主將 前鋒 右備 右翼）。
- 下排是六個戰術命令，對應原版的命令碼 0–5。
- ⚠ 即時制**不因為開著選單就暫停**——原版只有系統選單會停時間，
  手機版照這條走，不另外加暫停。

## 6. 文字

- 訊息框沿用 `TALK.DAT` 與現有的排版層（`internal/ui/textdraw`），
  1,022 則的行寬 guard 已經量過（[`../playtest/32`](../playtest/32-talk-layout-fit.md)）。
- 原版字型是 **16×15 點陣**；手機上只用**整數倍放大**，不做平滑。
  ⚠ 放大幾倍才讀得清楚**沒量過**，那是里程碑 C 的第一個要決定的數字。

## 7. 這些是 remake 差異

按 `CLAUDE.md` §1，外殼現代化要逐項標記：

| 差異 | 原版 |
|---|---|
| 版面重畫（狀態列／指令列／全螢幕 sheet）| 640×400 固定版面 ＋ 四個常駐視窗 |
| 地圖可縮放拖曳 | 固定 27×21 格視窗，靠點縮小地圖換位置 |
| 兩段式點選 | 原版滑鼠是點一下就送 |
| 戰場的六格與六命令固定在下方 | 原版在右側欄與底列 |
| 返回鍵 | 原版沒有這個鍵（ESC 取消、F10 離開）|

**桌面版一項都不動**——那是對拍基準。

## 8. 未解

| 項目 | 現況 |
|---|---|
| 點陣字在高 DPI 上要放大幾倍 | 沒量過（§6）|
| 小卡要放哪些欄位 | 原版一覽表的欄位已解（`docs/spec/38`），但手機小卡放不下全部，取捨還沒定 |
| 縮放的下限 | 整張大地圖 384×256 格全塞進手機會小到看不見，最小縮放級距還沒定 |
| 戰場的縮放 | 戰場 64×62 格，比大地圖小，可能不需要縮放；沒試過 |
