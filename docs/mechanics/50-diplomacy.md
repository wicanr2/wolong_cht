## 1. ⭐ 交友關係是六階，而且是單向的

> 勢力の一覧の中で、**親密、良好、普通、険悪、最悪、交戦**の6段階で表しています。
> この値は、**プレーヤーの君主から見た好友関係**のため、
> 必ずしも相手国から見た交友関係と一致しているとは限りません。

| 階 | 日文 | 中文 |
|---:|---|---|
| 1 | 親密 | 親密 |
| 2 | 良好 | 良好 |
| 3 | 普通 | 普通 |
| 4 | 険悪 | 險惡 |
| 5 | 最悪 | 最惡 |
| 6 | 交戦 | 交戰 |

**這是一個有向圖，不是無向圖。** A 對 B 的觀感與 B 對 A 的觀感是兩個獨立的值，
畫面上只看得到自家君主那一側。

> つまり、こちらが親しいと思っていても相手は必ずしもそう思っていないと言うことです。

remake 若把它做成雙向共用一個值，AI 的外交行為會變得可預測，
而原版刻意讓玩家**看不到對方怎麼想**。

## ⭐ 交友度的六個等級（confirmed）

勢力一覽的「外交」欄不印數字，印的是等級。換算在 `sub_17A7A`，
每次開那個一覽表都重算一次：

| 交友度 | 顯示 | 畫面 |
|---|---|---|
| 交戰中（最高位元未設）| **交戰** | 換色警示 |
| 0–19 | 最惡 | |
| 20–39 | 險惡 | |
| 40–59 | 普通 | |
| 60–79 | 良好 | |
| 80–100 | 親密 | |
| > 100 | `－－` | 自己那一格 |

**一級 20 分**。說服理由「交友關係惡い／良い」的門檻可以對照這組來讀
（`70-ai.md` §1.3）。玩家看得到的只有等級，看不到數值——
所以 remake 若要顯示原始交友度，那是 **remake 差異**。

證據與換算式見 [`../re/27-list-row-fields.md`](../re/27-list-row-fields.md) §4。

## 2. 怎麼提升

> この値は**外交官を派遣する**ことで上昇することができます。
> また、**交戦中であっても上昇は可能**です。
> つまり、**停戦前に好友値を上げておいて停戦すればすぐ攻められることを防ぐ**
> ことができます。
> ただし、交戦中は常に「交戦」と表示されるため**どの程度上昇したかは確認できません**。

| 規則 | 等級 |
|---|---|
| 派**外交官**駐該勢力可提升交友值 | 說明書 |
| **交戰中也能提升** | 說明書 |
| 交戰中畫面固定顯示「交戰」，**看不到實際值** | 說明書 |

### 這推導出一條完整的玩法

1. 打仗前先派外交官進去
2. 一邊打一邊養交友值（看不到，但確實在漲）
3. 停戰
4. 停戰後交友值已經夠高 → 對方不會馬上回頭再打

**「交戰」是顯示層的遮蔽，不是數值層的封頂。**
這種「機制在跑但介面故意不告訴你」的設計，
與君主好戰等級不顯示（`70-ai.md` §1.1）是同一套思路。

## 3. 外交官 vs 內政官

| 官職 | 派駐對象 | 用途 |
|---|---|---|
| **外交官** | **勢力** | 提升交友值；停戰提案與協力要請的前置條件 |
| **內政官** | **據點** | 內政（第 8 章，未讀） |

停戰提案與協力要請都要求「該勢力／協力國裡有我方外交官」，
所以外交官等於**外交行動的前置佈署**——不能臨時起意。

## 4. 三個外交指令

見 `10-strategy.md` §2。都要先通過君主的說服判定（`70-ai.md` §1）。

| 指令 | 前置 |
|---|---|
| 敵對提案 | — |
| 停戰提案 | 該勢力裡有我方外交官 |
| 協力要請 | 目標與自勢力交戰中；不可與協力勢力交戰中；協力國裡有我方外交官 |

> ここで成功しても、**外交が成功するとは限りません**（說明書 3.9）

**兩段判定**：先過自家君主（說服），再過對方勢力（外交本身）。
第二段的判定條件說明書沒寫 → 反組譯目標。

## 6. 信賴度與外交

> **停戦や協力外交などに成功すると大幅に上昇**します。（說明書 5.1）

外交成功是信賴度的主要來源。詳見 `80-victory.md` §1。

## 7. ⭐⭐ 外交是確定性的，不是機率性的

說明書 7.1 節，這是整份說明書裡最重要的一句：

> このゲームの外交は、優秀な武将に何回停戦させても
> **最初が失敗であれば、成功する事はありません**。
> つまり、**状況が変わらない限り成功はしない**わけです。
> これを成功させるには、以下に示す条件を満たさねばなりません。
> **条件さえ満たしていれば、外交官の能力に関係なく成功させることができます。**

| 規則 | 等級 |
|---|---|
| **條件滿足 → 必定成功**（與外交官能力無關） | 說明書 |
| **條件不滿足 → 重試永遠不會成功** | 說明書 |
| 外交官能力只影響「把局勢做出來」的效率與花費 | 說明書 |

**remake 不要在這裡擲骰子。** 外交是一道布林判定式，
玩家的工作是把條件湊出來，不是重試到成功。
這也解釋了為什麼玩家能規劃：局勢是可觀察的，結果就是可預測的。

## 8. 各外交指令的成立條件

### 停戰（說明書 7.3、10.1）

> **相手がこちらに侵攻してきている場合は停戦できません。**

```
停戰成立 ⟸ 對方沒有正在侵攻我方
```

> つまり、敵を疲弊させるか、**強大な勢力に協力してもらい、他に目を向けさせ**、
> また、交戦中でも外交官を派遣し、懐柔策を講じておかなければ拒否されてしまいます。

攻略章 10.1 給出標準流程：

> 通常停戦など**滅多に成功しません**。これは、領地を奪うために攻め込んでいるのに
> 停戦に応じるわけは無いからです。
> そこで、**他の勢力に協力してもらい、交戦中の勢力を攻めてもらいます**。
> **協力が成功すれば、交戦中の勢力の侵攻が停止し、このときに停戦外交をすれば
> 成功させることも可能です。**

```
協力外交成功 → 敵人轉向去打第三方 → 敵人「沒有正在侵攻我方」→ 停戰成立
```

**停戰不是直接求來的，是用協力外交造出來的。**
這是本作外交系統的招牌連招，remake 必須讓它成立。

### 協力（說明書 7.4、10.2）

> **協力勢力がどこにも攻め込んでいない状態**で、
> **協力勢力対自勢力の方が、協力勢力対侵攻勢力の方より交友関係がよい**場合に成功します。
> ただし、相手君主の性格によっては**かなり交友関係を良くしないと**応じてくれないこともあります。

```
協力成立 ⟸ 協力勢力沒有在侵攻任何人
          ∧ 交友(協力勢力 → 我方) > 交友(協力勢力 → 侵攻勢力) ＋ g(對方君主好戰等級)
```

⚠ 這裡的交友值是**協力勢力那一側看出去的**，而玩家看不到
（`§1` 交友關係是單向的）——所以這個判定式**玩家只能估**。

攻略章 10.2：

> 協力外交は比較的簡単です。**交友関係が良好であれば可能**です。
> ただし、都合の良いときだけ外交官を送って交友関係を良くしようとしても、
> 簡単に良くなるはずがありません。
> **おおよそ、半年から1年前ぐらいから準備する**ようにしてください。

| 事實 | 等級 |
|---|---|
| 交友關係達「**良好**」（六階中的第 2 階）大致就能協力 | 說明書 |
| 準備期 **半年～1 年** | 說明書 |
| **一旦惡化的交友關係要拉回來需 1～2 年**（7.2 節） | 說明書 |

**外交的時間尺度是「年」，不是「月」。** 這對 remake 的節奏設計是硬約束：
遊戲日推進速度必須讓一年之內能做完幾輪有意義的決策，
否則外交系統形同虛設。

## 9. 外交官怎麼運作

> 任命された外交官は**停戦や、協力などの外交を勝手にしてくれるわけではありません**。
> このゲームでの外交官の仕事は、**敵の勢力を懐柔し、交友度をあげること**です。

> 実際に外交官が懐柔を始めるのは**必要な金額を要求してきてから**となります。
> また、**金額を多く与えた方が無駄が少なくなります**が、一気に上がるわけではありません。

| 步驟 | 內容 |
|---|---|
| 1 | 任命外交官，派駐某勢力 |
| 2 | **外交官回報所需金額** |
| 3 | 玩家撥款；**給多一點浪費比較少**，但不會一次拉滿 |
| 4 | 交友值緩慢上升（月為單位） |

外交官的**政治**值越高，第 2 步要的錢越少（`60-personnel.md` §1）。
外交官**不會自己去談停戰或協力**——那是玩家透過進言下的指令。

## 9.5 ⭐ 外交官的實際效果（confirmed，`sub_13E8E`）

外交官的工作掛在**每小時**的世界更新上，不是月結
（這也是我先前在月結路徑裡找不到它的原因，`docs/re/08` §0）。
每個勢力大約每天輪到一次：

| 規則 | 值 |
|---|---|
| 動作機率 | **12.5%** |
| 經費消耗 | **23 − 政治** |
| 成功條件 | **`rand(0..15) ≤ 政治`** |
| 成功效果 | 交友度 **+1**，上限 **100** |
| 經費歸零 | 完全停工，要再開口要錢 |

**政治同時決定花費與效率。** 政治 15 的外交官每次花 8 點、必定成功；
政治 1 的每次花 22 點、成功率只有 2/16。
說明書 5.3 只講了「要的錢比較少」，機器碼顯示它也決定成功率。

### 交友度的儲存格式（confirmed）

**一個 byte：低 7 位是 0–100 的值，最高位元是「和平」**（1 ＝ 非交戰）。

⚠ 本文件先前把極性寫反。從資料驗出來的：四個劇本裡每一格的最高位元
都是 1，而且沒有任何勢力有侵攻目標——若 1 代表交戰，開局就是所有人互相宣戰。

極性定下來之後 `sub_1578F` 的要價基準也對上了：
和平 → 100，**交戰 → 125（打仗時外交官要更多錢）**。

矩陣本身在區塊 `+0x680`，用歷史事實驗過：
**劉備↔公孫瓚 100、孫策→劉表 20（父仇）、而劉表→孫策 55**——
最後這一組正好證明它是**有向的**。

已實作成 `internal/rules/diplomacy`。

六階的門檻是 `sub_17A7A` 的 `dh = 14h`——**一級 20 分**，
100 因為先 `dec al` 而落在「親密」，> 100 是自己那一格的 `－－`
（[`../re/27`](../re/27-list-row-fields.md) §4.1）。
算式只留一份：`diplomacy.DisplayIndex`，一覽表的顯示層直接呼叫它。

## 9.6 ⭐ 外交官也是情報站：沒派人就看不到別國遷都

別的勢力遷都時，`sub_133FD` 分兩條路（[`../re/69`](../re/69-t2-cross-reference.md) §2.4）：

```asm
cmp si, cs:word_10CFD / jnz .other     ; 是玩家自己的勢力嗎
…                                       ; 是 → 君主講 #518–520
.other:
mov ch, [si+2Ah]                        ; 派駐該勢力的外交官
cmp ch, 0FFh / jz retn                  ; ★ 沒有外交官 → 一句話都不報
…                                       ; 有 → #57 通報 ＋ #521–525 內容
```

`+0x2A` 就是外交官欄（[`../re/07`](../re/07-monthly-settlement.md)），
開局全部 `0xFF`。**所以「某國遷都了」是一則情報，不是公開事實**——
沒有在那邊佈外交官，首都換了也不會知道。

這讓外交官的定位比說明書寫的多一層：它不只是外交行動的前置佈署（§3），
也是**看得見那個國家在做什麼**的條件。

兩條路的實作與訊息對照見 [`../spec/64`](../spec/64-capital-relocation-report.md)。
