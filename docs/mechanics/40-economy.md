# 40 — 經濟：資金與預備兵

**狀態：機制齊全（說明書），公式未解。**

- 來源：日文原版說明書 3.2、5.1、5.2、**5.4、8.1、9.4、10.3、10.4、10.6** 節
- 推論等級：全部 `說明書`，尚未在機器碼裡驗過

⭐ 兩個容易做錯的地方：**生產力是複利模型**（§4），
**防災值是二元護盾不是減傷**（§4）。

## 1. 資金

> プレーヤー勢力の国庫にある金額です。
> **月末に拠点の生産力と税率に合わせて収入**があります。
> 行軍、内政、外交に使用することで随時減少していきます。
> 月末には**予備兵にも支払われる**ため、**これがマイナスになると予備兵が減少**します。

| 規則 | 等級 |
|---|---|
| 收入在**月末**結算，由**據點生產力 × 稅率**決定 | 說明書 |
| 支出：行軍、內政、外交（隨時扣） | 說明書 |
| 月末還要**付預備兵的維持費** | 說明書 |
| **資金為負 → 預備兵開始減少** | 說明書 |

### 這條是死亡螺旋

資金為負 ＝「疲弊狀態」（`70-ai.md` §1.4 的定義），而疲弊會

1. 讓預備兵減少 → 補不了前線 → 更容易丟據點
2. 丟據點 → 生產力下降 → 收入更少
3. **被 AI 看見**——「敵が疲弊中」是敵國君主可用的說服理由，
   等於在你最弱的時候招來更多敵人

**remake 必須完整保留這個回饋迴路**，它是本作經濟壓力的來源。

## 2. 預備兵

> その勢力が保有している**編成可能な兵力**です。
> 月末に拠点の生産力と募兵数にあわせて増加します。
> もちろん、予備兵にも**月単位で経費**がかかり、月末に支払われます。
> **騎馬、弓兵、歩兵の3種類**があります。なお、**解雇はできません**。

| 規則 | 等級 |
|---|---|
| 預備兵 ＝ 還沒編成的可用兵力 | 說明書 |
| 月末依**據點生產力**與**募兵數設定**增加 | 說明書 |
| 每月要付維持費 | 說明書 |
| 三種：**騎馬 / 弓兵 / 步兵** | 說明書 |
| **不能解雇** | 說明書 |

「不能解雇」讓募兵數變成一個**不可逆的承諾**：
募多了就得一直養，養不起就資金轉負，轉負又開始扣兵。
玩家調財政那四個數字時是在下長期賭注，這是設計而不是疏漏。

## 3. 月結的完整順序（推定）

把 §1、§2 與 `15-realtime.md` §4 拼起來：

```
月末：
  1. 收入  ← 各據點生產力 × 稅率
  2. 支出  ← 預備兵維持費（三兵種）
  3. 募兵  ← 依生產力與募兵數設定增加預備兵
  4. 若資金 < 0 → 預備兵減少
  5. 下個月起改用新設定的稅率與募兵數（設定時延遲一期）
```

⚠ **步驟順序是推定的**，說明書沒明講先扣錢還是先募兵。
`假說`，反組譯月結程式時要驗。

### 月結程式已經找到：`sub_15358`（confirmed）

換月時由時鐘 `sub_11D8E` 直接呼叫，見 `docs/re/06` §5。已定案的三件事：

| 事實 | 證據 |
|---|---|
| **勢力表 ＝ 22 筆 × 64 byte** | 迴圈 `add si,40h` ＋ `cmp cl,16h` |
| 勢力記錄 `+0` ≥ `0x80` 表示存在 | `cmp byte ptr [si], 80h` |
| `+1Ah`(word) 與 `+1Ch`(byte) 是**月結時讀完就歸零的累計值** | 讀 → 算 → 寫 0 |

那兩個歸零的欄位很可能就是**本月累計的收入與支出**
（財政視窗要顯示「今月末」的數字）。→ 假說，待驗

### ⭐ 「次月末生效」的實作找到了

月結最後做一次 **4 個 word 的複製**：

```
cs:0D10h ──4 word──> cs:0D08h
```

`0D10h` 是玩家在財政視窗改的「來月」緩衝區，`0D08h` 是實際生效的值。
4 個 word 正好是**稅率、騎馬募兵數、弓兵募兵數、步兵募兵數**。

說明書那句「来月末より使用されます」就是這一行複製。**confirmed。**

經濟公式全部在 `sub_15358` 呼叫的九支子程式裡
（`sub_1563B`、`sub_153C6`、`sub_15609`、`sub_15828`、`sub_15695`、
`sub_1585F`、`sub_155A6`、`sub_15715`、`sub_1578F`）→ 下一輪的目標。

## 4. 據點參數（說明書 5.4）

### 生產力

> その拠点の繁栄を表します。大きい方が収入が大きく、**兵の集まりも良く**なります。
> この値は、月末に**上昇値の割合に応じて変化**します。
> このため**大きい数値の方が変化が大きく**なります。
> **拠点ごとに上限値が決まっている**ため、一定値以上は上がりません。

### 上昇值 ＝ 成長率（可以是負的）

> この値は、月末に生産力を上昇させる値で **0 の時変化無し**でプラスの場合は上昇、
> **マイナスで下降**します。
> **戦争の後や、災害の後などこの値が大きく落ち込み**、
> そのままにしておくと**生産力が 0 になってしまいます**。

拼起來就是一條可實作的遞迴式：

```
月末：生產力 ← clamp(生產力 × (1 + k·上昇值), 0, 該據點上限)
```

| 事實 | 等級 |
|---|---|
| 上昇值是**成長率**，不是增量 | 說明書 |
| 變化量**與生產力本身成正比** | 說明書 |
| 上昇值可為負 → 生產力會一路掉到 0 | 說明書 |
| 每個據點有**各自的生產力上限** | 說明書 |
| 戰爭與災害都會讓上昇值**大幅下跌** | 說明書 |

⚠ `k` 的實際值未知（說明書只說「割合に応じて」）→ 反組譯目標。

**這是複利模型，不是線性模型。** 大據點成長快、崩得也快；
上昇值轉負而不處理，據點會指數衰減到 0。
攻略章第 10.3 節的結論正是「基本就是**別讓上昇值變成負的**」。

### 城兵數

> その拠点に配置している**守備の兵士**の人数です。拠点により違いがあり、
> **戦術では門の固さと比例**します。
> **自然に回復**しますが、**内政官を任命すると回復率が良く**なります。
> 特に**武術の高い武将**を配置すると効果があります。

| 事實 | 等級 |
|---|---|
| 城兵數 ∝ **戰術上的門強度** | 說明書 |
| 會自然回復 | 說明書 |
| 派內政官加快回復 | 說明書 |
| **武術**高的內政官效果更好 | 說明書 |

「守城要派武術高的人當內政官」是很不直覺的一條，
但它讓武術高／政治低的猛將在承平期也有用途。

### 防災值是**開關**，不是減傷

> 災害を受けたときに生産力や上昇値の受ける被害を押さえます。
> **この数値が 1 でもあると他への被害はいっさいありません。**
> しかし、この数値自身が下がるため、0 になった場合は注意が必要です。

| 事實 | 等級 |
|---|---|
| 防災值 **≥ 1 → 其他參數完全不受損** | 說明書 |
| 災害只扣防災值本身 | 說明書 |
| 防災值 **＝ 0 時**，災害才開始扣生產力／上昇值／城兵數 | 說明書 |

**不是按比例減傷，是二元的護盾。** remake 若做成「防災值越高減傷越多」
會完全改變玩家的維護策略——原版只要維持在 1 以上就夠。

### 四個參數總表

| 參數 | 作用 |
|---|---|
| **生產力** | 決定收入與募兵量；遷都只能往更高的據點；有上限 |
| **上昇值** | 生產力的**成長率**，可負 |
| **防災值** | ≥1 就完全擋住災害；歸 0 才會出事 |
| **城兵數** | 據點守軍，**決定戰術上的門強度** |

## 4.1 內政是全權委任

> このゲームの内政は**全て武将の委任**となっていますので、
> **直接城兵を増やせとか、防災値をあげろとかの命令はできません**。
> それに加えて、拠点のパラメータの変化が非常に大きいため、
> **生産力が一気に落ちて収入が半減する場合があります**。

玩家能做的只有「派誰去哪個據點」，**不能指定做什麼**。
這讓人事（`10-strategy.md` §3）成為內政的唯一操作介面。

攻略章 10.3 的建議：

> 通常は**税率を下げるだけで、内政の必要はありません**。
> ただし、国境で取り合いになった後など、生產力がほとんど 0 の状態の場合、
> このときだけは一時的に内政官を派遣し、上昇値をあげておいてください。
> **基本は、上昇値がマイナスにならないように注意することです。**

## 4.2 稅率的雙重作用

> 各拠点の収入の**何割を徴収するか**を表します。
> **高いほど拠点が荒廃していき、低いほど繁栄していきます。**

稅率不只決定收入，還直接影響據點的繁榮（多半是透過上昇值）。

```
收入 ↑ ⇄ 上昇值 ↓
```

**這是本作經濟的核心取捨**，而且因為生產力是複利模型（§4），
高稅率的代價是**指數性**的，不是線性的。

## 4.3 募兵是上限不是保證，而且有地域偏差

> 予備兵として雇う兵数です。集まった兵数がこれに満たない場合など、
> **必ず集まるとは限りません**。が、**これを越えることはありません**。
> **騎馬は北方でよく集まり、弓は南方でよく集まります。**

| 事實 | 等級 |
|---|---|
| 募兵數設定是**上限**，實際募到可能更少 | 說明書 |
| 實際募到量取決於據點生產力 | 說明書 |
| **騎馬在北方好募，弓兵在南方好募** | 說明書 |

**地域決定兵種。** 佔北方的勢力天然是騎兵國，南方是弓兵國——
而騎兵**不能登城牆**、在海戰幾乎無用（`30-combat.md`），
所以「北方勢力攻南方城池」在機制上就是吃虧的。
這一條把地圖與兵種綁在一起，remake 不能省。

## 4.4 行軍費用是啟動成本

> 軍団が**停止している場合、費用は予備兵と大差ありません**。
> しかし、**移動を始めると即座に大きな経費**がかかります。

| 事實 | 等級 |
|---|---|
| 駐紮中的軍團花費 ≈ 同等預備兵 | 說明書 |
| **一開始移動就立刻產生大筆支出** | 說明書 |

**是啟動成本，不是每 tick 的行進成本。** 所以「反覆改變目的地」
在原版是很貴的，remake 若做成按距離計費，玩法會完全不同。

## 5. 災害

三種：**暴風雨、火災、暴動**（說明書第 9 章）。

> 被害がでると、まず**防災値**が下がっていき0になると、
> 生産力、上昇値、城兵数がそれぞれ減少します。
> なお、**軍団への影響はありません**。

| 規則 | 等級 |
|---|---|
| 先扣防災值 | 說明書 |
| 防災值歸零後才扣生產力、上昇值、城兵數 | 說明書 |
| **軍團不受影響** | 說明書 |

**這在所有中文攻略裡都沒被提到。**
