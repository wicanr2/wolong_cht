# 80 — 勝負判定

- 日期：2026-08-08

**狀態：勝負條件全部定案。⭐ 結局的觸發已由機器碼定案
（[`../re/59`](../re/59-game-over-exit-codes.md)）：存活勢力數減到 1。**

- 來源：日文原版說明書 **1.1、1.2**、5.1、4.1 節
- 推論等級：結局／敗北的觸發 **confirmed**（`KI.EXE` 的三個離開碼 ＋
  四個劇本的 `+0x3A` 交叉驗證）；劇情層面的敘述仍是 `說明書`

## 0. 目的

> 中国の三国志上で戦争、駆け引きを目的とした戦略シミュレーションです。
> プレーヤーは三国志上でどこかの勢力の**軍師**となり、
> **仕える君主に中国を統一させて**ください。

**玩家不是統一天下的人，是讓別人統一天下的人。** 這句話定義了整個遊戲。

## 0.1 ⭐ 勝負條件（說明書 1.2）

### 勝

> 最後にプレーヤーの仕える君主の勢力が残った場合。
> ただし、**中立拠点は残っていても構いません**。

**只要消滅所有其他勢力就贏，中立據點可以留著。**
不是「佔滿 192 個據點」——這個差別對 remake 的終局判定很重要，
也讓遊戲不會在最後拖一段無意義的清場。

### 負（兩種）

| 條件 |
|---|
| 玩家所仕君主的勢力**滅亡** |
| **信賴度歸 0**，被逐出勢力 |

### 兩條沒有的限制

> ただし、**年月日によるタイムリミットはありません**。
> 又、ゲーム中は**武将が寿命で死ぬことはありません**。

| 事實 | 影響 |
|---|---|
| **沒有時間限制** | 年份跑到 999 封頂（`docs/re/06` §2）純粹是欄位上限，不是遊戲設計上的結束點 |
| **武將不會老死** | 武將名冊是靜態的，只會因戰死或被俘而變動 |

「武將不會老死」在三國 SLG 裡是少見的選擇——
它讓長期經營沒有隱形的倒數計時，也讓「養成一個班底」是可行的策略。

## 1. ⭐ 敗北條件不是亡國，是被自家君主開除

> **信頼度**：君主の軍師に対する評価のようなもので、
> これが大きいほど進言が成功しやすくなります。
> また、進言が成功すると上昇し、状況に合わない説得をすると下降します。
> さらに、停戦や協力外交などに成功すると大幅に上昇します。
> ただし、下降した結果、**0 になるとその勢力を追い出され、ゲームオーバー**となります。

**玩家扮演軍師，所以輸的方式是被君主炒魷魚。**
這是本作與所有「亡國才算輸」的三國 SLG 最大的差別，
也是 remake 絕對不能改掉的一條。

| 信賴度變化 | 幅度 | 機器碼 |
|---|---|---|
| 進言被君主採納 | **＋20**（飽和 0xFF）——**全遊戲唯一的加分點** | `sub_13830` → `sub_13D91(al=0x14)` |
| 進言被君主拒絕 | **−20** | `sub_13830` → `sub_13DC9(al=0x14)` |
| 說得時選了不符狀況的理由 | **−20** | `sub_13BA9` 的失敗分支 |
| 外交回報「你提的金額惹火對方」（回應碼 3）| **−30** ＋ 君主罵人（組 `0x1A5`＝#526–528，只有主公型變體）| `sub_13C3D` 的 `al=0x1E, cx=1A5h` |
| 資金赤字（事件 13）| **−50** | `sub_1350?` 的 `al=0x32` |
| **降到 0** | **被逐出勢力 → Game Over**（`sub_13DC9` 減到 0 當場 `sub_11CB1(al=1)`）| |

以上是 `byte_10D00` **全部的寫入端**（另一處是讀檔載入 `+0x2B`）——
說明書「停戰や協力に成功すると大幅に上昇」對應的就是**提案被採納的
那筆 ＋20**（外交結果本身不再另外加分）。推論等級：**confirmed**
（寫入端窮舉：`add`／`sub byte_10D00` 各一支，呼叫點全數讀出，2026-08-25）。

### 對玩法的影響

信賴度同時是**資源**與**生命值**：

- 它決定進言成功率 → 是你推動一切的燃料
- 它歸零就結束 → 亂猜說服理由是會死的

所以「不確定該用哪個理由時，用進言撤回收手」（不損信賴度）
是有明確價值的保守選項，而不是認輸。
`70-ai.md` §1.2 的三種結果對應到這裡就是：**加血 / 扣血 / 不動**。

### 儲存位置與初始值都已定案

信賴度是原版 `cs:0D00h`（IDA `seg000:10D00`、`byte_10D00`），對應每個
`SINARIO.DAT`／`SAVE.DAT` 區塊的 `+0x10` u8；`sub_18CAE`／`sub_18CFF`
的全域 59-byte 搬移證明它會隨存檔持久化。`sub_13D91`／`sub_13DC9` 直接對
該 byte 做增加／減少並在 0…255 飽和。

**新遊戲初始值 ＝ `0xFF`（滿條），confirmed**：實機開新遊戲後量條滿長
160 px（[`../playtest/44`](../playtest/44-trust-init-oracle.md)），與區塊
`+0x10 = 0xFF` 一致。`sub_18B12` 那行 `[word_10CFD+0x2B]` 的讀取在
`word_10CFD = 0xFFFF`（未選勢力）時迴繞到勢力 0 的 `+0x2A`（外交官欄，
開局 0xFF）——殊途同歸，remake 不移植這行。勢力 `+0x1D=200` 已由
`sub_16F26` 定案為編成軍團的士氣基準，與信賴度無關。

### remake 的實作意義

信賴度必須是**一個顯示給玩家的數值**（主畫面右側就有），
但君主的好戰等級**不顯示**。兩者的可見性差異是刻意的：
你看得到自己的處境，看不到對方的脾氣。
