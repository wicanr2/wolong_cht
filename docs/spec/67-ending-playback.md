# 67 — 結局的播放

**狀態：CONFORMED。** 十二幕、色盤、逐字文字、第一幕的三塊合成與「終」那一頁
都照原版接上了，**三段的節拍也各自照原版的常數重做**（§8）。
⭐ 整段從 1 分 47 秒變成 **3 分 21 秒**——先前把第一幕的常數套到第 2–11 幕，
每幕少了 11 秒的看圖時間。

- 日期：2026-08-18
- 出處：`D7END.EXE`（`sub_10094`／`sub_10293`／`sub_1035F`／`sub_1178A`）
- 推論等級：來源與節拍結構 **confirmed**；絕對秒數 **強證據**
  （18.2 Hz 未改頻的前提，[`../re/70`](../re/70-d7end-ending-player.md) §4）

## 1. 這一段在做什麼

存活勢力數減到 1 時 `internal/state` latch `Victory`，
`cmd/wlgame` 先放結局過場，放完才回到結果對話框（兩則訊息，[`30`](30-victory.md)）。
原版接的是 `D7END.EXE`：十二幕過場 ＋ 一段逐字打出來的結尾文字。

## 2. 要照抄的

| 項目 | 原版 | 出處 |
|---|---|---|
| 幕序 | `END_S1` … `END_S12`，一幕一張 | `re/70` §3 |
| 色盤 | `ENDPAL.BRG` 第 n 組 ＝ 第 n 幕 | `formats/09` §3 |
| 淡入／淡出 | 17 階（0–16）| `re/70` §4 |
| 第一幕的圖 | **320 px 寬**，貼在 x ＝ 160 | `formats/09` §6 |
| 第一幕的文字 | 200 個全形字，x 從 64 每字 +16、到 384 換行、y 從 48 每行 +32 → **一行 20 字、共 10 行** | `re/70` §2 |
| 打字速度 | 每字 `delay(0x12)` ≈ 0.25 s | `re/70` §4 |
| 幕間停留 | `delay(0x32)` ≈ 0.69 s，之後淡入、再停 `delay(0x320)` ≈ 11.0 s；第一幕結尾是 `delay(0x258)` ≈ 8.2 s | `re/70` §3.1、§4 |
| 結束 | 停在最後一幕，等**滑鼠鍵** | `re/70` §3 |

## 3. remake 的差異（要標記）

| 差異 | 為什麼 |
|---|---|
| 鍵盤也能結束 | 原版只認滑鼠鍵；remake 的其他畫面一律 Enter／Space 可用，只認滑鼠會讓人以為當掉 |
| 第一幕的捲動不做 | `sub_10094` 的 `si -= 0x50`／`dx += 0x50` 那一段是逐列捲上來；改用整張淡入 |
| 固定時間步 | 原版的節拍綁在 18.2 Hz 的 BIOS tick；remake 用自己的固定 tick（同 `15-realtime.md` 的 remake 差異）|

## 6. 驗證

| 方式 | 內容 |
|---|---|

| 單元測試 ✅ | `TestFirstSceneFadesOutBeforeFinalPage`：換到「終」那一頁的**那一刻畫面必須全黑**（`step == 0`），擋「在全亮時直接換頁」|

## 8. ⚠ 整段結局的節拍：原版與 remake 的對照（2026-08-21）

`sub_10293` 逐行讀出來之後（[`../re/70`](../re/70-d7end-ending-player.md) §3.1），
**三段的節拍都與 remake 不同**，不只第 2–11 幕。

### 8.1 原版的完整序列

| 幕 | 原版 | 出處 |
|---|---|---|
| **0**（`END_S1` ＋ 文字 ＋「終」）| 淡入 17 階 × `0x0A` → 打字 200 字 × `0x12` → **淡出 17 階 × `0x07`** → 換成「終」那一頁 → **淡入 17 階 × `0x0A`** → 停 `0x258` → 淡出 17 階 × `0x0E` | [`../re/70`](../re/70-d7end-ending-player.md) §4 |
| — | 幕 0 之後 `start` 還有一段 `delay(0xC8)`，畫面是黑的 | 同上 §3 |
| **1–10**（`END_S2`–`S11`）| 貼圖 → 畫字幕 → **停 `0x32`（畫面還是黑的）** → 淡入 17 階 × `2` → **停 `0x320`** → 淡出 17 階 × `2` | 同上 §3.1 |
| **11**（`END_S12`）| 淡入 17 階 × `8` → **停住等滑鼠鍵**（`jmp $`），沒有停留也沒有淡出 | 同上 §3 |

換算成秒（單位 ＝ 1/4 BIOS tick、18.2 Hz，同 §2）：

| 參數 | 單位 | 秒 |
|---:|---:|---:|
| `0x02` | 2 | ≈ 0.03 |
| `0x07` | 7 | ≈ 0.10 |
| `0x08` | 8 | ≈ 0.11 |
| `0x0A` | 10 | ≈ 0.14 |
| `0x0E` | 14 | ≈ 0.19 |
| `0x12` | 18 | ≈ 0.25 |
| `0x32` | 50 | ≈ 0.69 |
| `0xC8` | 200 | ≈ 2.7 |
| `0x258` | 600 | ≈ 8.2 |
| `0x320` | 800 | ≈ 11.0 |

### 8.2 remake 改之前是什麼樣

| 幕 | 改之前 | 差在哪 |
|---|---|---|
| 0 | 淡入 `0x0A` → 打字 `0x12` → **停 `0x32`** → 淡出 `0x0A` | 打完字**沒有淡出再換頁**，而是在全亮的狀態下直接換成「終」；停留 `0x32` 而不是 `0x258` |
| 1–10 | 淡入 `0x0A` → 停 `0x32` → 淡出 `0x0A` | `0x32` 擺在淡入**之後**；**完全沒有 `0x320` 那段看圖時間**；淡入淡出用第一幕的 `0x0A` 而不是 `2` |
| 11 | 淡入 `0x0A` → 停 `0x32` → 收 | 應該用 `8`，而且不該有停留 |

**影響**：第 2–11 幕每幕快了約 10 秒，整段結局短掉一分半。
這不是刻意的 remake 差異——是 `sub_10293` 沒讀就照第一幕的常數套過去。

`endingFinalHoldUnits`（`0x258`）改之前**宣告了但沒有任何程式碼用它**，
只有 `TestEndingDelayConversion` 在斷言它的換算。

### 8.3 remake 實作（2026-08-22 已接）

| 項目 | 位置 |
|---|---|
| 每一幕的三個參數 | `cmd/wlgame/ending.go` 的 `scenePace(scene, finalPage)`——回傳「淡入前的黑幕停留、每階的淡入淡出、全亮的停留」；淡出另有 `fadeOutUnits`（只有第一幕的兩趟與淡入不同值）|
| 黑幕停留 | 新的 `endingPreHold` 相位（`step = 0`，畫面全黑）|
| 第一幕的兩趟 | `endingState.finalPage`：第一趟畫 `END_S1` ＋ 文字，**淡出到黑之後**才翻成 `true` 再淡入「終」|
| 幕 0 之後的 `0xC8` | 併進幕 1 的黑幕停留（`0xC8 + 0x32`）——兩段中間畫面都是黑的，合併不改變觀感 |

### 8.4 改完之後的長度

`cmd/wlgame` 逐幀跑一次（200 個全形字、60 fps）：

| 幕 | 幀 | 秒 |
|---:|---:|---:|
| 0（`END_S1` ＋ 文字 ＋「終」）| 4,107 | 68.5 |
| 1 | 935 | 15.6 |
| 2–10（各）| 770 | 12.8 |
| 11 | 119 | 2.0 |
| **合計** | **12,091** | **201.5（3 分 21 秒）** |

改之前用舊常數算是 **6,420 幀 ＝ 1 分 47 秒**（每幕 17×8 ＋ 41 ＋ 17×8 ＝ 313 幀）。
⭐ **差 94 秒，而且差的幾乎全部是「看圖時間」**——原版讓玩家看每一幕 11 秒，
remake 先前只給 0.69 秒。

⚠ **`0x320` 的秒數建立在「18.2 Hz 未改頻」這個還沒實跑量過的前提上**
（[`../re/70`](../re/70-d7end-ending-player.md) §4）。**相對比例不受它影響**——
就算基準頻率不同，第 2–11 幕仍然是「看圖 16 倍於幕間停頓」。
字幕描述子表 `cs:0x780` 也還沒 dump，補上字幕之後排版會再動一次。
