## 2. 互動

| 熱區 | 位置 | 作用 |
|---:|---|---|
| `0x20` | (328, 272) 48×16 | **確定**（下面那顆）|
| `0x21` | (328, 248) 48×16 | **自定**（上面那顆）|

⚠ 熱區編號與畫面上下**顛倒**。

### 2.1 ⭐ 這個視窗只有這兩個熱區

`sub_18E5A` 的迴圈把 `sub_1E453` 取到的熱區編號減 `0x20`：

```asm
sub al, 20h
jb short loc_18E70      ; ★ 不是這兩個 → 回去等，什麼都不做
ja short loc_18E8E      ;   0x21 自定
…                       ;   0x20 確定
```

所以**卡片上其他任何位置的點擊都被忽略**，滑鼠**移動**更不會改變任何東西。
換勢力要用右鍵退回上一層的**勢力清單**（[`../re/73`](../re/73-new-game-faction-list.md) §2），
卡片上沒有換勢力的熱區。

⭐ 按「確定」時，若軍師欄是 `0x7F` 且名字還是空的，原版會**當成按了自定**
——先去命名再說（[`docs/re/53`](../re/53-lord-select-window.md) §3）。

## 3. remake 要做什麼

`cmd/wlgame/lordcard.go`（新增）畫這張卡，啟動殼層的「選君主」那一頁用它。

| 項目 | 作法 |
|---|---|
| 版面 | 照 §1 |
| 輸入 | **只認兩個熱區**（§2.1）：點「確定」＝ 決定、點「自定」＝ 目前無效的提示。卡片其他位置的點擊與滑鼠移動一律不改變選中的勢力 |
| 換勢力 | 原版是退回上一層的**勢力清單**（[`79`](79-new-game-faction-list.md)），右鍵／ESC 就回去。remake 差異：卡片上仍保留 ↑↓ 換一個，它與清單共用同一個 `cursor`，不會產生第二份真相 |
| 兩顆按鈕 | 畫出來了，但 remake 這一輪只有「確定」有效 |
| 劇本標題 | 顯示在卡片上方，**從區塊 `+0x40` 讀**（[`25`](25-slot-select-window.md) §1.2）|

⭐ **劇本名先前是硬編的四個字串**（「第一章　呂布歸天」…），
而原版寫的是「第一章・　　「呂布歸天」之卷」——連格式都不一樣。
現在 `game.scenarioTitles` 啟動時從 `SINARIO.DAT` 讀。
