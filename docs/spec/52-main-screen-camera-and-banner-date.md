## 1. 鏡頭：首都 −(16, 12)

```
camX = clamp(首都X − 16, 0, 344)      344 = 384 − 40
camY = clamp(首都Y − 12, 0, 233)      233 = 256 − 23
```

上下限出自 `sub_12151` 的 `cmp ax, 158h` 與 `cmp ax, 0E9h`，
與可視範圍 40×23 格算得出來的值一致。

| 勢力 | 首都 | 世界格 | 量到的鏡頭 | −(16,12) | −(20,11)（舊）|
|---|---|---|---|---|---|
| 曹操 | 許昌 | (206, 114) | (190, 102) | ✅ | ✗ 差 4 格 |
| 孫策 | 濡須口 | (291, 165) | (275, 153) | ✅ | ✗ 差 4 格 |

⚠ **不要寫成 `viewCols/2`、`viewRows/2`。** 40×23 的正中央是 (20, 11.5)，
而原版是 (16, 12)——**水平偏左四格**，垂直則比中央低半格。
這個差別在畫面上是整整 64 px：逐區對拍在修之前地圖區
**66.6% 不同**，修完 **0.5%**（[`../playtest/37`](../playtest/37-main-screen-parity.md)）。

## 2. 橫幅的日期

橫幅本身（`ICONGRF` 段 0）已經印好「年 月 日」，遊戲只填數字。

| 項目 | 原版 | remake（修前）|
|---|---|---|
| 顏色 | 調色盤 **色 9** ＝ `#F3D392` | 硬寫 `#F0F0E6` |
| 「年」的數字右緣 | x 496 | 494 |
| 「月」 | x 528 | 526 |
| 「日」 | x 562 | 560 |

三個右緣一致差 2 px，數字的總寬兩邊相同，所以是**整體平移**不是字寬不同。
