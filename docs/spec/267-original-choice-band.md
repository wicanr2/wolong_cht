## 原版離散語意

| 條件 | 結果 |
|---|---|
| 進入文字選單 | 反白第一列、保存游標位置、隱藏游標，選列器座標設為 `(0,100)` |
| `100 <= y <= 131` | 保持目前反白列 |
| `y > 131` | 下一列，游標設回 `(0,100)` |
| `y < 100` | 上一列，游標設回 `(0,131)` |
| 第一列／最後列 | 夾住，不循環；仍回置游標 |
| 左鍵 | 在任何位置確認目前反白列，優先於同次位置處理 |
| 右鍵 | 取消目前選單，由既有 caller 處理返回 |
| 離開選單 | 恢復進入前位置及游標顯示 |

一次輸入取樣最多移動一列。按住滑鼠鍵不重複確認，進入選單的父點擊不確認新選單。
數值子視窗使用自己的滑鼠輸入；返回文字選單時重新建立選列器。

## 桌面接線

由 `cmd/wlgame/choiceband.go` 維護選列器生命週期，所有文字選單只使用這一份操作。
遊戲中的文字選單獨占滑鼠時，外部工具列停用；右鍵取消或左鍵確認後恢復工具列。
這讓原版的隱藏與回置行為完整保留，也不把工具列的點擊送進遊戲。
不改規則、存檔、資料包或選單繪圖位置；仍依既有規格 266 全程滑鼠操作。
