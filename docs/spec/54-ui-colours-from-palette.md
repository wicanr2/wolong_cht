## 1. 問題

`internal/ui/chrome` 的五個顏色是**手抄的 RGB 常數**，注解寫「原版量到的」。
那些值是在調色盤還走 `v*255/15` 的時候量的，[`51`](51-vga-dac-palette-scale.md)
改成 VGA 的 6 bit DAC 之後**每一個都差了 2–4**：

| 用途 | 舊的手抄值 | 調色盤索引 | 正確值 |
|---|---|---:|---|
| `Menu` 選單／情報視窗底 | `(0, 32, 101)` | 8 | `(0, 32, 97)` |
| `Sheet` 清單視窗底 | `(255, 223, 154)` | 9 | `(243, 211, 146)` |
| `Select` 反白條 | `(85, 154, 69)` | 5 | `(81, 146, 65)` |
| `Paper` 深藍底上的字 | `(255, 255, 255)` | 15 | `(243, 243, 243)` |
| `Ink` 米色底上的字 | `(0, 0, 0)` | 0 | `(0, 0, 0)`（不變）|

⭐ **手抄的顏色會與調色盤脫鉤。** 解碼修好了，抄下來的常數不會跟著修——
所以顏色改成**跟著 `GAMEPAL.BRG` 走**，`Load` 時查一次。

## 2. 命令列的底是黑的

原版命令列（`(0, 32, 432, 32)`）的框與其他視窗相同，但**內部是純黑**：

| | 底 | 字 |
|---|---|---|
| 原版 | 色 0 `#000000` | 色 15 `#F3F3F3` |
| remake（修前）| 色 8 深藍 ＋ 龍紋 | `#FFFFFF` |

⚠ **龍紋不是每個深藍視窗都有。** 自勢力情報視窗有（實機上看得到黑底藍紋），
命令列**沒有**——它整片是色 0。

文字的位置與字形本來就對：兩邊的白色像素**都是 1,037 個、都落在 x 32–398**。
差的只有顏色與底。

## 3. remake 實作

| 項目 | 位置 |
|---|---|
| 五個顏色 | `chrome.Load` 從 `library.PaletteColor` 取，索引寫成具名常數 |
