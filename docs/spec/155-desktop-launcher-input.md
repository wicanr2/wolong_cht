## 行為契約

1. **已證實：** 選劇本的可點矩形就是日期欄 `(256,144+48k,120,16)`，k=0..3。
   啟動選章與讀檔共用 `saveSlotRect`，不再使用舊殼層列高。名稱欄與日期欄外側不選章。
2. **已證實：** 勢力清單剛打開不反白；第一次左鍵選列反白，第二次左鍵確認原選取列。
   選取狀態下點另一資料列不改選，而是確認先前的選取。右鍵先解除反白，再按才回劇本。
   君主卡右鍵返回清單時恢復瀏覽狀態。
3. **重製便利性保留：** 滾輪捲動視野、方向鍵選列、Enter 確認、右鍵／ESC 返回。
   方向鍵在清單改選後回到瀏覽狀態；滑鼠移動本身不改勢力。
4. 兩階段只增加「是否反白」狀態，不複製已選勢力；君主卡與清單仍共用原有游標。
5. 空列、標題、捲軸不當成新的勢力；合法性仍由既有資料邊界驗證。
6. 不改存檔格式、遊戲規則、Android UI 或公開散布邊界。
