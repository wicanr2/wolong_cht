# 119 — `\1` 與 `\4` 代入的是呼び名，不是姓名

**狀態：CONFORMED。** 七個 `\N` 標記的 handler 全部讀完之後，
兩個代入點要改：`\1`（訊息裡的武將）與 `\4`（玩家的軍師）取的是
武將記錄 `+0x08` 呼び名，remake 一直代 `+0x02` 姓名。
`\2`／`\3` 現行的代入是對的。

- 日期：2026-09-03
- 出處：`KI.EXE`（SHA-256 `fffeba98…d43868`）的 `CS:08A4` 跳躍表與五支
  handler——[`../re/79`](../re/79-talk-marker-handlers.md)
- 推論等級：**confirmed（原始 bytes 交叉解碼）**
- 相關：[`../formats/01`](../formats/01-talk-dat.md) §3（資料側）、
  [`../formats/08`](../formats/08-sinario-save.md) §3（武將記錄 `+0x02`／`+0x08`）

## 1. 原版做什麼

| 標記 | 記錄 | 欄位 | 顏色 |
|---|---|---|---:|
| `\1` | 武將（參數 ＝ 編號 × 32 ＋ `0x4240`）| **`+0x08` 呼び名** | 9 |
| `\2` | 據點（參數 ＝ 編號 × 32 ＋ `0x0840`）| `+0x02` 名稱 | `0x0B` |
| `\3` | 勢力（參數 ＝ 編號 × 64）→ `+0x01` 君主 | 武將 `+0x02` 姓名 | `0x0C` |
| `\4` | 玩家勢力（`cs:word_10CFD`）→ `+0x02` 軍師 | **武將 `+0x08` 呼び名** | 9 |
| `\5` | 玩家勢力 → `+0x01` 君主 | 武將 `+0x02` 姓名 | `0x0C` |

顏色 9 與 [`../playtest/43`](../playtest/43-field-battle-parity.md) 逐像素定案的
「`\1` 代入的名字畫色 9」互相印證——兩條獨立的路指到同一個值。

## 2. 差在哪裡

松崗版四個劇本裡呼び名與姓名不同的只有四人：

| 姓名 | 呼び名 | 劇本 |
|---|---|---|
| 司馬懿 | **仲達** | 全部四個 |
| 諸葛亮 | **孔明** | 全部四個 |
| 龐統 | **鳳雛** | 全部四個 |
| 李暹 | **（三個全形空白）** | 只有劇本一 |

⚠ **李暹那一格是空的**，原版真的會畫出一片空白。**照抄，不要補**——
「看起來像資料缺漏」與「原版就是這樣」在保存專案裡是不同的事，
而唯一能分辨的是機器碼：handler 沒有任何 fallback。

⭐ **四個人聽起來很少，但三個是名人。** `\1` 在 `TALK.DAT` 出現 102 次，
是最常用的標記；諸葛亮、司馬懿、龐統只要被任何一則提到，
remake 顯示的就是錯的字。

## 3. remake 要怎麼改

`internal/state.General` 已經有 `Alias` 欄（讀檔、寫回、劇本 JSON 都在），
**只是沒有任何顯示路徑用它**。

| 項目 | 位置 |
|---|---|
| `\1` 代入 | ✅ `cmd/wlgame/corps.go` 的兩處、`cmd/wlgame/battletalk.go` 的 `pumpDuelTalks` |
| `\4` 代入 | ✅ `cmd/wlgame/advise.go` 的 `advisorName` |
| 取值共用一支 | ✅ `internal/state.General.TalkName()`：`Alias` 非空就用它，否則退回 `Name` |

⚠ **退回 `Name` 的那條路是 remake 差異**，原版沒有：原版直接畫 `+0x08`，
是空的就畫空白。remake 保留退路是因為 `Alias` 也可能在改造存檔裡沒填；
**但四個劇本的原版資料一格都不缺**，所以正常玩不會走到（§5 的測試釘住這一點）。

### 3.1 顏色與定寬是**標記的性質，不是框的性質**

五支 handler 都在 `sub_1075B` 底下，而 `sub_1075B` 同時被
`sub_18853`（左下角狀態列，[`140`](140-status-message-box.md)）與
`sub_18810`（一般訊息框，[`41`](41-message-box-geometry.md)）呼叫。
所以 **§1 那張顏色表對每一個畫 TALK 文字的框都成立**，
定寬三格（五支一律 `al = 3` 再 `call loc_10701`）也一樣。

remake 起初只在狀態列做，一般訊息框整段畫白的——
[`../playtest/92`](../playtest/92-personnel-assign-parity.md) 的內政官解任
逐像素量到那 150 px（`\2` 代入的「濮陽」原版是 `(243,162,0)`）。

收法：代入與繪製各收成一支。

| 項目 | 位置 |
|---|---|
| 每個標記的顏色 | `cmd/wlgame/statusbox.go` 的 `talkMarkerInk(marker)`：`\1`／`\4` → 9、`\2` → `0x0B`、`\3`／`\5` → `0x0C` |
| 補白 ＋ 收集欄位 | 同檔 `padTalkVars(vars)`：回傳補好白的 `vars` 與 `[]talkField{文字, 色}` |
| 繪製 | `drawTalkLineFields`：一行裡凡是等於某個欄位的那一段就換那個色，**長的先比**，避免「曹操」把「曹操軍」切一半 |
| 狀態列 | `setStatusTalk` 存 `fields`，`drawStatusBox` 照畫 |
| 一般訊息框 | `enqueueTalkWithPortraitSeq` 存 `fields` 到 `messageDialog`，`drawLegacyTalkBox` 照畫 |

⚠ **補白收進 `padTalkVars` 之後，呼叫端不要再自己補**——重複補是無害的
（已經滿三格就不動），但兩份實作會漂。
