## 1. 撥款沒有這一擲

`sub_139E8`（事件 4／5 的撥款三選一，000139E8–00013B07）整支**沒有**
`call sub_1ECE0`。它直接拿 `sub_13B7E` 的選項碼分流
（`0` ／ `0x202` ／ `0x303`）並在 `[bp+2] != 2` 時寫入資金。

⇒ **只有外交要問君主，撥款不用。** 兩支長得很像，共用
`sub_13B7E`（三選一）與 `sub_17C6E`（數值編輯器），差別只在這一擲。

## 2. 為什麼它在對拍裡看得見

同局面 196/5/13 11 時的君主召見（「曹操　的使者前來希望我國協助一事」）
是 90 天內唯一一次玩家互動。玩家按第 1 列「無條件」之後，
原版在**同一拍**取了第 4 次亂數，remake 只取 3 次
（`tools/parity_pace_diff.py --tick 5541`）。

一次錯位就讓之後每一座據點的內政決策換一組亂數：跑到 5/14 1 時
（拍 5,658）時**89 座據點差 144 個 byte**，而勢力、全域、佇列、
交友度五張表仍然全 0——**上昇值、防災值、城兵各差 1 到 5，
形狀與規則分歧一模一樣**。

## 3. 「不採納」那一支還沒有被驗過

這一局的信賴度是 `0xFF`（快照 `+0x10`），而 `al` 是 8 位元，
所以 `ja`（al > 0xFF）**結構上不可能成立**——本局一律採納。

⇒ 對拍能證明的是「**那一擲被取走了**」，不能證明「不採納時會怎樣」。
remake 照機器碼的形狀實作成「跳過套用」（`[bp+2]` 保持進入時的初值，
外層 `cmp al, 2` 之後不會走收尾），並標為**假說**。
要驗它得先讓信賴度掉下來（`AdjustTrust`），那是另一輪的事。

## 4. remake 的修法

```go
// ⭐ 亂數一定要取，不管玩家選了哪一列——包含「拒絕」。
roll := 0
if w.rng != nil {
    roll = w.rng.Next() & 0xFF
}
if roll > clampU8(w.Trust) {
    return false        // 君主不採納
}
```

⚠ **位置很重要**：原版是在三選一關掉之後、套用之前擲，
所以它落在 `PendingDiplomacy` 出現的**那一拍**（remake 拍 5,541），
排在該拍三次據點內政亂數的**後面**。
