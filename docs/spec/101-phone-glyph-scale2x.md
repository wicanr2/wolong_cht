# 101 — 手機版放大的字用 Scale2x 去鋸齒

**狀態：CONFORMED（2026-08-28 實作、單測、截圖放大對照過）。**

- 日期：2026-08-28
- 出處：**remake 差異**（使用者裁定 2026-08-28：「android 字體放大後有鋸齒，我想消除」）。
  接在 [`100`](100-phone-text-scale.md) 之後。
- 推論等級：不涉及原版事實。

## 1. 鋸齒從哪來

`100` 把 16×15 的點陣字用最近鄰放大 2 倍：每個點變 2×2 的方塊，
斜筆畫（撇、捺、點）就變成一格一格的階梯，放到手機的高 DPI 上格外明顯。

## 2. 決定：Scale2x（EPX），不用雙線性

| 方法 | 結果 | 取捨 |
|---|---|---|
| 雙線性（`FilterLinear`）| 整個字糊掉，筆畫邊緣變灰階 | 點陣字的「硬邊」是它的長相，糊掉反而更難讀 |
| **Scale2x／EPX** | 斜線的階梯補成 45 度，直線、筆畫粗細、空隙都不動 | 已知副作用：對角相鄰的兩個點會連起來（1 px 斜線變成連續的 45 度線）——對字這正是想要的 |
| hq2x／xBR | 更圓滑 | 查表大、對 1 bit 字模的收益不明顯，先不做 |

算法（每個點 P 分成 e0 e1 e2 e3 四格，鄰居 上／下／左／右）：

```
e0 = (左==上 && 左!=下 && 上!=右) ? 上 : P
e1 = (上==右 && 上!=左 && 右!=下) ? 右 : P
e2 = (下==左 && 下!=右 && 左!=上) ? 左 : P
e3 = (右==下 && 右!=上 && 下!=左) ? 下 : P
```

只在倍率 2 時套；其餘倍率仍走 `Draw` 的 GeoM 最近鄰。
放大後的字模進快取（鍵含倍率），畫的時候不再縮放。
