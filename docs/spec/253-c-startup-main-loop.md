## 實作與驗收

- 證據審查：42函式1021指令與3個raw片段（11＋1＋8指令）已逐條核對。初態使用PSP fixture（含`80h`長度位元組）、DOS配額基址、唯讀`END_S15.DAT`、固定VGA裝置、INT61向量狀態、`IRQ0Every`不可達大值與有界滑鼠事件；兩側各自raw初始化，不跨機器複製執行後狀態。
- 固定矩陣涵蓋：滑鼠有／無兩條`start`路、命令列長度邊界、8次滑鼠far-call參數、INT61六種`AH`、回呼登記狀態／取消、tick回呼raw直接入口（含`D2D`飽和邊界`FE／FF`）、15筆MZ段值、命名UI八個跳表項與取消路、`5221h`循環邊界（`1912D`下捲至`92h`、`19144`上捲回零）、`190A3`查表下界借位、`18FC9`配額／讀檔／釋放、`1EB6C`／`1EB93`連續I/O、主迴圈有界迭代與`11CB1`離場轉移。
- 原版先通過獨立數值與資料模型，再比較C。`sub_11BE0`無窮迴圈以固定事件序列與迭代上限驗收；離場尾段比较I/O軌跡與離場碼，不比較離場後狀態。
- 未註冊熱區碼（含`0x29`越界字）不在執行矩陣內；分派字解析以位元組契約記載，不宣稱自然可達。

- 兩側各自raw初始化，固定原始RNG與等價輸入；C不執行原版CPU指令，不借原版執行後狀態。
- 以O0／O2比較完整RAM、VGA、DAC、暫存器、FLAGS、SS／SP、IN／OUT、API及callee軌跡；正常返回、離場轉移與DOS離場分列。217案／opt全同（13群，stage exit 7／pause 10／return 196／transfer 4，獨立稽核818）。
