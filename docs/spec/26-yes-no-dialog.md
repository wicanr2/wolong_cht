## 2. ⭐ 命中判定不走熱區表

其他視窗都用 `sub_1E3D7` 登記熱區，這一個**直接比座標**：

```asm
[bp] += 28h / [bp+2] += 28h      ; 基準點 ＝ 框 + (40, 40)
等待:
  sub_121E7
  cx −= [bp]   / jb → 等待
  cmp cx, 80h  / jnb → 等待       ; X 要落在 0–127
  dx −= [bp+2] / jb → 等待
  cmp dx, 48h  / jnb → 等待       ; Y 要落在 0–71
  ax = 0 / dx >>= 3
  cmp dx, 2 / jz → 等待           ; ⭐ 第 2 條（Y 16–23）是縫，兩邊都不算
  jb → 回傳 0（ＹＥＳ）
  inc ax → 回傳 1（ＮＯ）
```

**Y ÷ 8 等於 2 的那 8 px 兩個選項都不算**，不是四捨五入到最近的按鈕。
兩個框之間的空隙是 (+56)–(+63)，正好落在那一條。

## 3. remake 要做什麼

`cmd/wlgame/yesno.go`（新增）提供 `drawYesNo` 與 `hitTestYesNo`，
給任何需要 Ｙ／Ｎ 的地方共用。第一個使用者是 **F10 離開確認**
（`CLAUDE.md` §9 要求的那一個），位置置中 `(216, 152)`。

| 項目 | 作法 |
|---|---|
| 版面 | 照 §1 |
| 命中 | 照 §2，**含中間那條縫** |
| 選取標記 | remake 差異：選取的那格多一圈黃框。**不換文字顏色**——紅色在這個專案固定表示負值 |
| 鍵盤 | remake 差異：↑↓ 換選項、Enter 決定、Y／N 直接決定、ESC 取消 |

先前的離開確認是一個半透明黑條加一行「確定離開？（Y／N）」，與原版無關。
