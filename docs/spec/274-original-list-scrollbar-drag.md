## 已證實的契約

| 原始定位 | 行為 |
|---|---|
| `sub_184DD`：184E1／184E4、18509／1850E | 進入拖曳隱藏游標，離開再顯示 |
| 184E9–18505 | 持續輪詢滑鼠、換算Y並呼叫預覽；BX任何按鍵未放開都留在迴圈，X不限制 |
| 184FE `cs:word_181A6`、18513 `cs:byte_181BC` | 拖曳中以預覽top呼叫畫列回呼；全部按鍵放開後才提交top |
| `sub_18713` | 以總列數換算Y，再扣半頁及夾限，不是以可捲動列數線性換算 |
| `sub_18607`、`sub_18662` | 預覽滑塊的偏移採上取整，滑塊高度採下取整 |

槽高度H、槽頂Y、總列數N、一頁P列，正常有效資料為N大於P：

```text
previewTop = clamp(floor(clamp(pointerY-Y, 0, H)*N/H) - floor(P/2), 0, N-P)
thumbOffset = ceil(previewTop*H/N)
thumbHeight = floor(H*P/N)
```

遊戲內槽為 `(24,120,16,128)`，P=10。N=22時，Y座標128／152／184／240
對應預覽0／0／6／12，滑塊偏移0／0／35／70；拖曳至X=300仍保留控制權。
正常勢力表回呼指標為CS:796Ch，畫面確認列內容同步預覽，放開後top=12。
原版收據在 `original-stable/scroll-trace.json`，截點為184FE回呼返回後的18503；
等待原版實際消費位移，不把尚未輪詢的指標位置當成畫面完成。
列不足一頁或空表採安全無捲動，不模擬原版無效除法。

## 實作契約

1. 狀態分為未拖曳與拖曳中。只由未反白清單中、槽內的新左鍵開始。
   拖曳保存預覽top，同步預覽滑塊與列內容，不增加反白；正式top不改。
   放開全部按鍵後提交一次。
2. 拖曳中先處理捕捉，再處理取消；右鍵或中鍵仍按住時不取消清單。
   指標離開槽或進入外部工具列仍由原拖曳擁有，不能觸發工具列按鈕。
3. 清單物件或啟動器階段改變即丟棄舊拖曳，不把放開事件套到新視窗。
   不存入遊戲存檔。焦點恢復依當前按鍵釋放完成，不補發點擊。
4. 繪圖用預覽top畫滑塊及列表。拖曳中隱藏箭頭。
   新遊戲勢力表與遊戲內表共用換算及滑塊幾何，不改已反白後的確認原列契約。
5. 垂直鏈為原始清單描述／資料、既有typed清單、UI捕捉、預覽、提交、取消返回。
   世界規則、資料包與存檔格式不變；不以這片代證編成或全部視窗完成。

## 驗收與停止線

- 正常首頁、勢力表、遊戲內表，以實際滑鼠按住移動、槽外及工具列放開，
  再抽驗編成與返回。檢查遊戲熱鍵仍停用，文字輸入不改。
- 比較原版與remake清單視窗、槽及滑塊的實際像素，畫面狀態不同比較時明列限制。
