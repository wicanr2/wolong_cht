## 1. 原版做什麼

`sub_1699E` 是軍師進言選單（`TALK.DAT` #77）的第五項「請求君主出陣」。
君主答不答應由兩道閘決定，**兩道都要過**。

## 2. 演算法

```
門檻 = (0x0F − 勢力.好戰等級) × 4        # 單位是「資金 >> 8」
資金高位 = 勢力.+0x21（＝ 資金 >> 8）
if 資金高位 < 0x80 and 資金高位 < 門檻:   答應 = false
預備兵 = 勢力.+0x04 + 勢力.+0x06 + 勢力.+0x08   # 騎馬 ＋ 弓 ＋ 步
if 預備兵 < 0x258（600）:                 答應 = false

if 答應:
    sub_16E8F 編一支軍團（君主本人帶）
    and byte [軍團.+0x00], 0FBh          # ← 立刻清掉「委任」位元
```

換算成資金：門檻 `(15 − 好戰等級) × 4 × 256` ＝ **`(15 − 好戰等級) × 1,024`**。

> **君主親征那一支不是委任狀態**，所以別的據點求援時調不動它
> （[`docs/re/45`](../re/45-corps-command-mode.md) §3）。
> 這一行很容易在實作時漏掉——它在編成**之後**，看起來像收尾。
