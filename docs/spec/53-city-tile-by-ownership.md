# 53 — 據點中心的圖塊跟著歸屬換，首都再疊一張

**狀態：CONFORMED。** 規則是拿松崗實機的九座據點、四種歸屬狀態逐格比對
`MMAP.MDL`／`MMAP.MCH` 得到的，每一座都**逐像素 0 差**。
⭐ **地圖檔存的是「無所屬」那一張；有主就往前挪一或兩號。**

- 出處：[`../re/67`](../re/67-city-emblem-on-strategy-map.md)

## 1. 地圖檔只存一種狀態

`MMAP.MAP` 在 `0xCB`–`0xD3` 這個範圍只用到三個值，而且**加起來剛好 192**
——就是據點數：

| 值 | 格數 | 是什麼 |
|---:|---:|---|
| 205 | 183 | 一般據點的中心 |
| 208 | 4 | 另一種據點的中心 |
| 211 | 5 | 關隘的中心（虎牢關是其中之一）|

⭐ **三個值兩兩相差 3，而每一組的三張圖塊就是三種歸屬。**

## 2. 換圖塊的規則

```
自勢力  → 檔案值 − 2      203 / 206 / 209
他勢力  → 檔案值 − 1      204 / 207 / 210
無所屬  → 檔案值          205 / 208 / 211
```

驗過的樣本（合成結果與原版截圖**逐像素相同**）：

| 據點 | 歸屬 | 檔案值 | 原版畫的 |
|---|---|---:|---:|
| 陳留・陳・官渡・舞陽 | 玩家所仕（曹操）| 205 | **203** |
| 牛渚 | 別的勢力（嚴白虎）| 205 | **204** |
| 舒縣 | 無所屬（`0x18`）| 205 | **205** |
| 虎牢關 | 玩家所仕 | 211 | **209** |

「自勢力」的判準與縮小地圖同一套（[`../re/62`](../re/62-strategy-minimap.md) §2）：
`0x18` ＝ 無所屬，等於 `byte_10CFF`（玩家所仕勢力）＝ 自勢力，其餘 ＝ 他勢力。

⚠ **兩局才看得出來**：曹操局與孫策局的紅都是玩家自己那一方。
只看一局會把它推成「紅色是固定的」。

## 3. 首都再疊一張 MCH

首都的中心格是 **`MMAP.MDL` 203 ＋ `MMAP.MCH` 圖塊 255**（112 個不透明點），
合成之後與原版逐像素相同。非首都的據點**不疊**——疊上去反而差 75 點。

兩局各驗一座（曹操的許昌、孫策的濡須口），兩座都 0 差。

## 4. 自勢力的據點還會換裝飾格

把原版與 remake 逐格比，差異格的（檔案值 → 畫的值）全部是 **+10**，
而且合成之後**逐像素 0 差**：

| 檔案值 | 畫的值 | 是什麼 |
|---:|---:|---|
| 222–225 | 232–235 | 5×5 大城的四個角 |
| 226–229 | 236–239 | 3×3 據點的四個角 |
| 230 | 240 | **關隘上下的門柱**（只有這個位置）|

⚠ **只有自勢力換。** 別的勢力（嚴白虎的牛渚）與無所屬（舒縣）的角落
與地圖檔逐像素相同——換句話說**敵人的城不會亮旗**。

⚠ **帶的兩端是硬的，230 還要看位置：**

- 220、221、231 也在據點方塊裡（許昌 5×5 的中列與上下列），**不換**。
- 230 在**關隘的正上方與正下方**會換，在**大城方塊的左右邊不換**
  ——許昌的 (208,113)／(208,115) 是 230，原版照畫。
  所以 230 只在中心是 211（關隘）時、只在 `(X, Y±1)` 換。

全圖有 838 格落在 222–230，其中 43 格離任何據點中心超過兩格；
**半徑要限制在 ±2**，不能整張掃。

## 5. 中心格在哪

**據點記錄座標的右邊四格、同一列**（`X + 4, Y`）。
六座據點（3×3、5×5、關各有樣本）都成立。

remake 在載入時**逐座檢查**那一格是不是 205／208／211，
不是就記一筆 warning——這樣「+4 這個假設哪天不成立」會當場現形，
而不是變成畫面上一個安靜的錯誤。
