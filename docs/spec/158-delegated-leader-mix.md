## 已證實契約

以武力 M、原統率 C 表示。M ≥ C 時消費一次亂數，低兩位非零取 2M；
低兩位為零取 **M − floor(M/4) + C**。M < C 時不取亂數，取 C − floor(C/4) + C。

原始定位保留如下；附加語意均為**已證實**，來源是上述 IDA bytes 與原版動態輸出：

| 位址／原指令 | 語意 |
|---|---|
| `000152FA 8AF2 mov dh, dl` | 混合分支用武力作被扣除四分之一的基數 |
| `000152FC–00015302 mov ch,dh / shr dh,1 / shr dh,1 / sub ch,dh` | 基數減其四分之一，整數截斷 |
| `00015304 02AF5242 add ch,[bx+4252h]` | 從原記錄重新讀統率相加；不是相加已覆寫的 DH |

原版實測：M/C=12/6 得 15（多數分支 24）；15/11 得 23（多數分支 30）；
4/12 得 21。另涵蓋 0、1、15、相等能力與不取亂數分支。
工具在自然委任遭遇的 `000152E7` 保存狀態，修改能力與 RNG 計數位元組後執行至
`00015308`，不改指令或強制輸出；屬窄狀態對照，不冒充完整玩家路徑。

## 實作與驗收

- 分開保存混合基數與原統率，保持其他分支與 RNG 消費不變。
- 修正將 12/6 → 21 固化為答案的舊測試；加入原版動態邊界答案。
- 野戰與攻城共用 Power 路徑都要涵蓋混合分支。
- 原有委任收據重播與完整檢查通過；完整世界結算仍由另一項工作驗證。
- 不改存檔、能力資料、戰術傷害、玩家流程或已發布封包。

本規格只定義將領混合值，世界結算與戰術排程不在本規格範圍。
