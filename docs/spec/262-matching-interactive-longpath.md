## 為什麼還要跑（SHA 全同還跑什麼）

整檔 SHA 同證明 bytes 相等，不證明重建產物在玩家路徑上跑得起來：
載入、重定位、工作目錄與 dosgolem 的 EXE 解析任一環在罕用路徑上
出錯，SHA 都是綠的。slice A 的互動止於開局對話；選單、清單與
多日推進會走到不同的載入與分派路徑，本片補這一截。
**本片不宣稱邏輯相等**（那由 SHA 背書），只背書「跑得起來且
與原版在同一時間軸上逐步一致」。

1. slice A 開局段（playtest/122）：開機 → 第一章 → 孫策／周瑜 →

⚠ 即時制：取樣點寫成遊戲日期與事件（截圖掛在流程節點上），
不寫秒數。每步的 `steps:` 預算在兩側必須相同，截圖同名。
