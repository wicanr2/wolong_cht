## 1. 原版做什麼

側欄 x 480–640，左右兩根柱子在 480 與 624，四條橫帶把中間切成七格。
整條側欄由 `sub_1C7A9` 在戰術設定段畫**一次**；只有計量條、小地圖標記與
選取框每幀更新。

| y | 格 | 內容 |
|---|---|---|
| 8–40 | 標題 | 「〈戰場地名〉作戰」／「〈我方君主〉對〈對方君主〉」 |
| 48–80 | 上格 | **對方**的將旗（段 1 `0x0800`）＋ 主將名 ＋ 兵力條 ＋ 大將體力條 |
| 80–208 | 小地圖 | 128×128，地形 ＋ 部隊點 ＋ 陣形線 ＋ 游標十字 |
| 208–240 | 下格 | **我方**的將旗（段 1 `0x1000`）＋ 主將名 ＋ 兩條同上 |
| 248–280 | 陣形 | 8 欄 × 2 列 ＝ 十六個陣形（段 1 `0x0000`）|
| 280–376 | 指令 | 六列指令 ＋ 右側三個陣線位置（段 1 `0x1800`）|
| 376–392 | `▶▶` | 段 1 `0x3500` |

**上下不是攻守，是敵我**：`sub_14ED7` 依玩家攻守互換
`word_10D2E`／`word_10D30`，而側欄固定把 `word_10D2E`（我方）畫在下面。
⚠ **照抄，不要改成「攻方在上」**——那會讓玩家守城時整條側欄上下顛倒。

## 2. 演算法

### 2.1 版面常數（全部照抄，單位 px）

```
側欄       x 480,  寬 160        柱：480、624，各 16 寬
橫帶       y 0、40、240、392     x 496 起，寬 128，高 8
標題文字   (512,8) 地名   (560,8) 「作戰　」
           (512,24) 我方君主  (560,24) 「對　　」  (576,24) 對方君主
上格美術   (496,48)  128×32      熱區 0x0E (496,48,128×24) → 無動作
上格主將名 (528,52)
小地圖     (496,80)  128×128     熱區 0x02 (496,80,128×128)
下格美術   (496,208) 128×32      熱區 0x0D (496,216,128×24) → 無動作
下格主將名 (528,221)
陣形選單   (496,248) 128×32      熱區 0x03；格 16×16，8 欄 × 2 列
指令面板   (496,280) 128×96      熱區 0x09/08/07/0A/0B/0C，各 (496, 280+16k, 48×16)
陣線三格   (552,288,64×24) 0x04 / (552,312,64×32) 0x05 / (552,344,64×24) 0x06
▶▶ 列      (496,376) 128×16      熱區 0x0F
```

文字全部是 `sub_106FD`＝**固定三個全形字**（48 px），調色盤索引：
地名與「作戰」9、君主名與「對」11、主將名 15。

### 2.2 標題的戰場地名

```
if 戰場類別 == 0:  地名 = 據點名          # 攻城戰
elif 戰場類別 == 1: 地名 = "陸上　"
else:              地名 = "海上　"
```

### 2.3 四條計量條

x 都是 498，高 2 px，總長上限 124，未填的部分畫色 0。

```
上格 y=72   長 = min(對方兵力 >> 2, 124)              色 12
上格 y=75   長 = min(對方大將體力 × 3 / 4, 124)        色 11
下格 y=211  長 = min(我方兵力 >> 2, 124)              色 12
下格 y=214  長 = min(我方大將體力 × 3 / 4, 124)        色 11
```

「大將體力」＝ 該側第 0 個單位記錄的 `+0x03`；開場等於軍團士氣。

### 2.4 ⭐ 六列指令的順序

熱區碼 − 7 ＝ 命令碼，由上而下：

| 列 | y | 熱區 | 命令碼 | 按鈕 |
|--:|--:|---|--:|---|
| 0 | 280 | `0x09` | **2** | 突擊 |
| 1 | 296 | `0x08` | **1** | 攻擊 |
| 2 | 312 | `0x07` | **0** | 陣形 |
| 3 | 328 | `0x0A` | 3 | 城壁 |
| 4 | 344 | `0x0B` | 4 | 守陣 |
| 5 | 360 | `0x0C` | — | 退却 |

⚠ **畫面順序不是命令碼順序**：第 0 列送命令 2、第 2 列送命令 0。
台詞（TALK `0x1B1 + 命令碼`，×8 展開後 622／630／638／646／654）
把三個名字釘死了：命令 0 ＝「擺出陣形！！」、
命令 1 ＝「前進！轉為攻擊！」、命令 2 ＝「好啊！衝啊！！！」。

命令 3（城壁）在沒有城的戰場改叫「這哪裡有城壁啊！！」（TALK 582）並
**不下達命令**。

### 2.5 小地圖上的四種標記

座標 `screenX = 496 + 2×mapY`、`screenY = 80 + 2×(63 − mapX)`，每格 2×2。

| 標記 | 調色盤索引 |
|---|---:|
| 部隊點（側 0 ＝ 我方）| **10** |
| 部隊點（側 1 ＝ 對方）| **3** |
| 陣形線（側 0 的陣形原點那一整行）| 11 |
| 游標十字（一行 ＋ 一列）| 0 |

### 2.6 陣形選單

```
選中格 = (游標X − 496) / 16  +  (游標Y − 248 >= 16 ? 8 : 0)      # 0..15
陣形表偏移 = 選中格 × 96
選取框：格內縮 1 px 的 14×14 矩形，選中色 12、取消色 10
```
