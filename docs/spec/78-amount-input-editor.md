## 1. `sub_17C6E` 的參數

```asm
mov dx, <錨點 X> / mov bx, <錨點 Y> / mov ax, <上限>
call sub_17C6E
jb  → 玩家取消，不要寫回                ; CF ＝ 取消
（CF 清掉時）ax ＝ 輸入的值
```

進去之後 `mov [bp+0], ax`——**那一格從頭到尾只當上限用**：

| 用它的地方 | 做什麼 |
|---|---|
| `sub_17DA5`（數字鍵）| `si = si×10 + 數字`，然後 `cmp si,[bp+0] / jbe / mov si,[bp+0]` |
| `sub_17DC3`（`00`）| `si ×= 100`，同樣夾上限 |
| `sub_17DEC`（最大）| `si = [bp+0]` |

⚠ **[`../re/13`](../re/13-pc98-numeric-window.md) §3 原本把 `5Fh` 記成
「還原呼叫端初值」。那是錯的**——`si` 開場就是 `xor si, si`（0），
呼叫端根本沒有機會給初值。那一鍵是**「最大」**，
而 [`../re/48`](../re/48-window-display-list.md) §6 從圖庫解出來的
按鍵字樣本來就寫著「最大」，兩邊現在對得上。

### 1.1 六個按鍵的實際語意

`bl = al − 0x52`，`bl −= 9` 沒有借位就當索引，否則索引 0：

| raw | 索引 | 常式 | 動作 | 圖庫上的字樣 |
|---|---:|---|---|---|
| `52h`–`5Bh` | 0 | `sub_17DA5` | `si×10 ＋ 數字`，夾上限 | 0–9 |
| `5Ch` | 1 | `sub_17DC3` | `si×100`，夾上限 | `00` |
| `5Dh` | 2 | `sub_17DDD` | `si÷10` | `◀` |
| `5Eh` | 3 | `sub_17DF1` | `si = 0` | 取消 |
| `5Fh` | 4 | `sub_17DEC` | `si = 上限` | 最大 |
| `60h` | 5 | `sub_17DEA` | `STC` → 離開迴圈並回 CLC | 決定 |

⭐ **`sub_17DEA` 的 `STC` 不是「取消」。** 呼叫端 `jnb loc_17CA4`
（沒有進位就繼續迴圈），有進位才落到 `clc; jmp` ——**離開時的旗標是清的**。
真正的取消是 `sub_121E7` 回進位那條路（右鍵），它跳到 `loc_17CD5` 的 `stc`。

### 1.2 幾何是呼叫端給的，不是寫死的

```
存／還原區  (錨點X − 8, 錨點Y − 8)   112 × 80    ; sub_19796 / sub_197C3
外框 blit   (錨點X,     錨點Y)        96 × 64     ; sub_17D0D
3×6 格      (錨點X,     錨點Y ＋ 16) 每格 16×16  ; sub_17D5F 的 add bx,10h
```

| 呼叫端 | 錨點 | 上限 | 用途 |
|---|---|---:|---|
| `sub_13902`／`sub_139E8` | (88, 184) | `7530h` ＝ 30,000 | 事件 2／3 的獻金 |
| `sub_167CD` | **(296, 184)** | `64h` ＝ **100** | 財政：稅率 |
| `sub_167E6` | (296, 184) | `2710h` ＝ **10,000** | 財政：騎兵募集人數 |
| `sub_16806` | (296, 184) | `2710h` ＝ 10,000 | 財政：弓兵 |
| `sub_16826` | (296, 184) | `2710h` ＝ 10,000 | 財政：步兵 |

⭐ **這張表順便解掉 [`14`](14-finance-window.md) §5 的「徵兵數的上限」**：
三個兵種都是 **10,000 人**。三支都在寫回前 `div 10`，
所以存進 `cs:word_10D12`／`10D14`／`10D16` 的是**點數**（≤ 1,000），
與預備兵同一個單位（[`21`](21-corps-formation-reserves.md) §1）。

## 2. 演算法

```
開啟(錨點, 上限):
    存下 (錨點−8) 起 112×64 的畫面
    畫 96×64 外框、3×6 格
    值 ← 0
    迴圈:
        畫出「值」（六位數，sub_1062F）
        等點擊；右鍵 → 取消，直接還原畫面回去
        依格子的 raw byte 分派（§1.1）
        「決定」→ 離開迴圈
    還原畫面
    回傳 (值, 取消了沒)
```
