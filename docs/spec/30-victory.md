# 30 — 結局：存活勢力數歸一

**狀態：READY。⭐ 觸發條件在機器碼裡是**單一一個**——存活勢力數 `== 1`。
「佔領所有城池」不是另一條規則（§3）。**

- 日期：2026-08-16
- 出處：[`docs/re/59`](../re/59-game-over-exit-codes.md)（離開碼與結局閘門）
- 推論等級：**confirmed**（機器碼 ＋ 四個劇本的資料交叉驗證）
- 範圍：DOS/V 版 `KI.EXE`

## 1. 出處：`KI.EXE` 用離開碼把結局交給另一支程式

`YNVSHELL.COM` 是串接器，`KI.EXE` 結束時的 `AL` 決定下一支跑誰：

| 離開碼 | 去向 | 觸發點 |
|---:|---|---|
| 0 | 回 shell（正常離開）| `0x160C8` |
| 1 | `D7OVER.EXE`（遊戲結束）| 信賴度歸零 `sub_13DC9`；玩家所仕勢力滅亡 `sub_14FCE` |
| **2** | **`D7END.EXE`（結局）** | `sub_11CD0`：`cmp cs:byte_10D2A, 1` |

`byte_10D2A` 是**存活勢力數**：

- 靜態初值 0，全庫只有一個寫入點——`sub_14FCE` 的 `dec`
- 它是劇本／存檔區塊 `+0x3A`（59 byte 全域區塊的最後一個 byte，
  [`docs/formats/08`](../formats/08-sinario-save.md) §1）
- 四個劇本的值：**22／11／6／4**，正是各劇本的勢力數

## 2. 算式

```
載入時      存活勢力數 ← 區塊 +0x3A
勢力滅亡時   存活勢力數 −= 1        （原版 sub_14FCE）
主迴圈檢查   存活勢力數 == 1 → 結局  （原版 sub_11CD0，離開碼 2）
```

**滅亡的判定是「據點數歸 0」**：`sub_14CF3` 在據點易主時對舊持有者
`dec byte [bx+23h]`（勢力記錄的據點數），`sub_14DF0` 回 CF ＝ 1 就呼叫
`sub_14FCE`。舊持有者是 `0x18`（無主城）時整段跳過。

⚠ 順序有意義：`sub_14FCE` **先**判斷滅亡的是不是玩家所仕的勢力
（`cmp bx, cs:word_10CFD`）→ 離開碼 1；**才** `dec` 計數器。
所以玩家自己滅亡時走敗北，不會因為「剩一個」而誤判成結局。

## 3. ⚠ 「佔領所有城池」不是第二條規則

使用者裁定時提了兩個條件（2026-08-16）：「沒有其他主君」與「佔領所有城池」。
**機器碼裡只有前者**——`sub_11CB1` 的四個呼叫點全部列在 §1，
離開碼 2 只有一個來源。

兩者的關係是：所有據點都歸一個勢力 ⇒ 其餘勢力的據點數都是 0 ⇒ 全部滅亡
⇒ 存活勢力數 ＝ 1。**「佔領所有城池」是「存活勢力數 == 1」的充分條件，
不是獨立的觸發**。反過來不成立：留著無主城（持有者 `0x18`）時，
存活勢力數仍可能是 1，結局照樣觸發。

**remake 只實作機器碼裡的那一條。** 多加一條會讓兩個條件在無主城的
情況下不一致，而原版沒有那個行為。

## 4. remake 實作

| 項目 | 作法 |
|---|---|
| 欄位 | `World.LivingFactions`，從區塊 `+0x3A` 載入、寫回同一個位置 |
| 減量 | 集中在 `eliminateFaction`——**唯一**清 `Alive` 的入口 |
| 結局 | 減量之後 `LivingFactions == 1` → latch `Victory` |
| 敗北 | 滅亡的是玩家所仕勢力 → latch `DefeatFactionEliminated`（先判、再減） |
| 呈現 | `cmd/wlgame` 的 `updateOutcome`；音樂走 `endbgm-0`（`D7END` 的曲子）|

⚠ **不要用「每幀掃描」補設結果**（`outcome.go` 開頭的既有規則）：
結局要在真實的 mutation 邊界 latch，否則載入舊存檔會被瞬間判定。

## 5. 驗證

| 方式 | 內容 |
|---|---|
| 資料 | 四個劇本的 `+0x3A` 對上勢力數（22／11／6／4）——測試直接讀 `SINARIO.DAT` |
| round-trip | 存檔寫回後 `+0x3A` 不變（未滅亡時） |
| 規則 | 單元測試：滅到剩一個 → `Victory`；玩家先滅 → `DefeatFactionEliminated` 而不是 `Victory` |
| 長跑 | `wlsim` 跑到結局，確認不會提早觸發 |
