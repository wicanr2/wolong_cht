# 66 — 城壁與門打壞之後，畫面上的地形要跟著換

**狀態：CONFORMED。** 原版打壞的那一刻就把圖塊值換掉並重新展開堆疊，
下一幀畫出來的就是瓦礫或破門；remake 的繪圖層原本拿的是進戰場那一刻的
靜態副本，現在改成跟著規則層的圖塊版本走。

- 日期：2026-08-18
- 出處：`sub_1B824`（`0001B5EB` 起）→ `sub_1B799`（同排一起垮）
  → `sub_1BB6D`（重新展開那一格的堆疊）；繪圖端 `sub_1DC9D`／`sub_1DD22`
  每一幀從戰場緩衝區重建顯示格
- 推論等級：**confirmed（靜態）**
- 輸入檔：`workplace/orig/dosv/KI.EXE`

## 1. 原版做什麼

實體（城壁／門）耐久歸零時：

```
sub_1B824:
  耐久 > 0 → 減一，結束
  耐久 = 0 → sub_1B799：掃 16 筆，把 [+0x08]（Y）相同的實體全部打壞
             圖塊值：未滿 0xF0 加 0x10，否則加 8
             （城壁 0xD0–0xDF → 0xE0–0xEF 瓦礫；門 0xF0–0xF7 → 0xF8–0xFF 破門）
             sub_1BB6D：重新展開那一格的堆疊
```

⭐ **換掉的是戰場緩衝區本身**，而 `sub_1DC9D`／`sub_1DD22` 是**每一幀**
從那個緩衝區重建顯示格的——所以「規則變了」與「畫面變了」在原版是同一件事。

### 1.1 破門長什麼樣：只剩兩根柱子

門的四個圖塊對（`0xF0`/`0xF1`、`0xF4`/`0xF5` 是門扇，`0xF2`/`0xF3`、
`0xF6`/`0xF7` 是另一種）都只有**一層**子圖塊：

| 圖塊 | 堆疊 |
|---|---|
| `0xF0`／`0xF4` | `[177]` |
| `0xF1`／`0xF5` | `[176]` |
| `0xF2`／`0xF3`／`0xF6`／`0xF7` | `[129]` |
| **`0xF8`／`0xF9`** | `[181 180 180 180 180 179]` |
| **`0xFC`／`0xFD`** | `[181 180 180 180 179]` |
| `0xFA`／`0xFB`／`0xFE`／`0xFF` | 同上但底座是 `178` |

⭐ 也就是說**完好的門是一層、破門是五到六層**——打壞之後那一格會
從一塊門扇變成一對高過城牆的木柱，畫面差異很大，不是換個顏色而已。

### 1.2 這條在對拍上被量到

第 61 步的 `field` 差異裡有一群 88 px（螢幕 (25..36, 24..38)），
把 192 個子圖塊逐張套進那個 32×16 顯示格去比，**只有子圖塊 179
覆蓋全部 88 個差異點、零個畫錯**。而 179 只出現在破門圖塊的頂層。

順著座標回推：那個顯示格是（列 2, 欄 2），深度 4 對應戰場格 (31,20)，
它的圖塊是 `0xF5`（完好的門）；`0xF5 + 8 = 0xFD`，堆疊 `[181 180 180 180 179]`
的第 4 層正好是 179。⭐ **格子、深度、子圖塊三項同時對上**——
原版那一刻那道門已經破了，remake 那一刻還沒破。

兩邊的時刻本來就對不齊（同一張截圖裡對方將旗的計量條也差 20 秒），
所以這 88 px **不是繪圖算式錯**。真正的缺陷是下一節：即使 remake 也把門打破，
畫面依然不會變。

## 2. 兩份圖塊要接起來

`newBattleView` 在進戰場那一幀取 `battleLib.Tiles(field)` 的副本展開成
`v.subs`，而規則層的 `Field.Retile` 改的是 `internal/rules/tactical`
自己那一份。**兩份各走各的**時的症狀是：打壞城壁或門之後兵走得過去
（規則層對），但畫面上牆還立著。單元測試看不到——它們驗的是 `Field`
的狀態，不是畫出來的像素。

## 3. remake 實作

| 項目 | 位置 |
|---|---|
| 圖塊版本 | `internal/rules/tactical/tactical.go`：`Field.rev` 由 `Retile` 遞增，`Field.Revision()` 對外 |
| 每幀比對 | `internal/ui/isoview/isoview.go` 的 `syncTiles`，由 `drawBattleIso` 呼叫；版本變了才從 `Field` 的現值重建 `v.subs` |
| 旗**不重建** | `sub_19E10` 只在開場掃一次；重掃會重擲揮舞相位，旗會在牆垮的那一幀跳一下 |
| 座標框 | 規則層與繪圖層拿的都是**轉過的**那一份（`battle.go` 的 `Rotate180`），可以直接對位 |
