## 1. 原版怎麼做

軍團每 tick 更新一次（`sub_12662`）。**在野外路徑上**（`[si+0Eh] ≥ 0x800`）
才呼叫 `sub_142AB`，站在據點上不呼叫。

```
前方端點 ＝ 這一段路的兩端裡，步進量指著的那一端
若 前方端點.所屬勢力 == 軍團.所屬勢力      → 通過
若 前方端點.所屬勢力 == 24（中立）          → 通過
若 交友度[軍團.勢力][前方端點.勢力] < 0x80  → 通過   （最高位元 0 ＝ 交戰中）
否則：
    目標據點 ← 路的**另一端**
    +0x14 ← 目標 × 8；+0x20 ← 目標
    +0x00 |= 2（下一步要重算）
```

⚠ **交友度是有向的**，用的是「軍團所屬勢力**對**前方勢力」那一格。
⚠ **判斷用的是含和平位元的原始值**，不是低 7 位的交友度。

## 2. 為什麼是「掉頭」不是「拒絕下令」

原版在下令時完全不檢查：`sub_1703C` 只問「那一格是不是據點」
（[`../re/85`](../re/85-march-target-hit-test.md)），訊息 #21「向{2}移動下」
照跳。折返發生在路上，所以**畫面上沒有任何錯誤提示**——
玩家看到的是軍團走出去又走回來。

remake 要照抄這個行為，**不要改成下令時拒絕**：那會讓玩家看到
原版沒有的訊息，而且會遮掉「先宣戰再出兵」這條玩法規則。

## 3. remake 實作

| 項目 | 位置 |
|---|---|
| 掉頭判定 | `internal/state/corps.go` 的 `turnBackAtBorder`，由 `step` 在移動前呼叫 |
| 三個放行條件 | 同一支的 `borderIsClosed` |
| 前方端點 | 同一支的 `nextCityOnRoute`（路線序列裡第一個踩到據點座標的格）|
| 折返路線 | 同一支的 `reverseLeg`（反向那一段路的格子序列，從目前這一格切開）|
| 差異 | 無 |

⚠ **既有的六支測試因此要先宣戰。** `TestCorpsMeetAndFight`、
`TestPlayerBattleGoesTactical`、`TestNormalScenarioMarchIntoGarrison`、
`TestMarchFollowsRoads`、`TestTacticalBattleAlwaysResolves`、
`TestInvariantsUnderWar` 都是「派軍團去打」，而它們都跑在**開局的和平狀態**上。
⭐ `TestNormalScenarioMarchIntoGarrison` 失敗時停的位置是 **`node=87`（舞陽）**，
與原版實跑停的據點**完全相同**——這是接對了的第一個訊號。

⚠ **remake 的路徑是多段的**（`internal/rules/march` 的 Dijkstra），
原版是一段一段走。等價的判準是「**下一個要踏進的據點**是不是和平勢力的」
——用 `routes` 序列裡下一個踩到據點座標的格子，等於原版的「前方端點」。

## 4. 驗證

| 方式 | 證據 |
|---|---|
| 單元測試 | `TestMarchTurnsBackAtPeacefulBorder`（和平 → 折返回出發據點）、`TestMarchPassesWhenAtWar`（交戰 → 通過）、`TestMarchPassesIntoNeutral`（中立 → 通過）|
| **突變測試** | 三組都做過：拔掉 `step` 裡的接線 → 正面樣本紅；把交戰條件反過來 → 兩條紅；拿掉中立那一條 → 中立測試紅。⚠ **第三組一開始不會紅**——中立編號 24 超出 `Friendship` 的 22×22，越界保護先擋掉了。把越界改成「當成擋住」之後才測得出來：**靠越界保護生效的規則，等於沒有測到** |
