## 1. 原版

同一格（攻城＝據點座標）上同勢力的軍團可能不只一支。開打前
`sub_14C72` 先收名單（最多 127 支），再逐支計分挑**應戰者**：

```
分數 ＝ ((兵數 >> 4) 的低 byte) × (士氣 >> 4) × ((大將評價 >> 4) ＋ 1)
```

取**嚴格最大**（同分取先者）。兵數是軍團記錄 `+0x04`（點數）、
士氣 `+0x06`、評價是大將的 `+0x1F`（`sub_155A6` 月結重算的衍生值）。
沒有任何一支 → CF=1，攻城走打城兵那條。
