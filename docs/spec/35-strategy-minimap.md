## 1. 原版做什麼

縮小地圖的地圖區是 (440, 40) 192×128，**1 px 對 2 格**（世界 384×256 格）。
底圖是 `ICONGRF` 段 2，上面每幀重畫兩種東西：

1. **192 個據點標記**，4×4 px，外框一圈 ＋ 中心 2×2，顏色看所屬勢力
2. **視野框**，20×12 px，標出大地圖現在捲到哪

顏色（`GAMEPAL.BRG` 第 0 組的色號）：

| 據點屬於 | 外框 | 中心 |
|---|---|---|
| 無所屬 | 0 黑 | 15 白 |
| 自勢力 | 10 `#dd0000` | 12 `#ffee00` |
| 圖例第二格選中的勢力 | 15 白 | 3 `#3344dd` |
| 其餘勢力 | 8 `#002266` | 3 `#3344dd` |

標記的左上角 ＝ `(440 + x/2 − 2, 40 + y/2 − 2)`，那個 −2 是把 4×4 置中。

底下的圖例兩格：左格是自勢力君主名（紅底白字），
右格是**玩家指定要盯著的勢力**（藍底白字），點右格會開一個 22 勢力的選單。

## 2. remake 做什麼

| 項目 | 做法 |
|---|---|
| 標記 | 照 §1 的四種顏色與 4×4 形狀畫在底圖上 |
| 座標 | `(minimapX + city.X/2 − 2, minimapY + city.Y/2 − 2)`。`city.X/Y` 已經是格座標 |
| 無所屬 | `Owner` 落在 `[0, len(Factions))` 之外就是無所屬（原版存 `0x18` ＝ 24，而勢力只有 22 個）|
| 顏色來源 | `g.lib.PaletteColor(季節, 色號)`，**不自己挑 RGB**。取不到就用 fallback 並記一行 log |
| 視野框 | 畫一個 20×12 的白色矩形外框。**原版那是一張美術**（`word_10D4C`），remake 畫線 → **標記為 remake 差異** |
| 圖例第二格 | 顯示 `g.minimapFaction` 那個勢力的君主名，初值 0（原版 `byte_198A7` 的靜態初值），若不存活就往後找第一個存活且非自勢力的 |
| 換第二格 | 點圖例右半格（熱區 `0x17` ＝ (536,168,96,16)）**換到下一個存活勢力**。原版是開一個 22 格的選單視窗，**remake 這一步是簡化**，標記為 remake 差異 |

**不做的事**：22 勢力的選擇視窗（`sub_15AFC` 的版面沒解，只解了行為）。
