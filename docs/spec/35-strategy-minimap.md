## 1. 原版做什麼

縮小地圖的地圖區是 (440, 40) 192×128，**1 px 對 2 格**（世界 384×256 格）。
底圖是 `ICONGRF` 段 2，上面每幀重畫兩種東西：

1. **192 個據點標記**，4×4 px，外框一圈 ＋ 中心 2×2，顏色看所屬勢力
2. **視野框**，20×12 px，標出大地圖現在捲到哪

顏色（`GAMEPAL.BRG` 第 0 組的色號）：

| 據點屬於 | 外框 | 中心 |
|---|---|---|
| 無所屬 | 0 黑 | 15 白 |
| 自勢力 | 10 `#dd0000` | 12 `#ffee00` |
| 圖例第二格選中的勢力 | 15 白 | 3 `#3344dd` |
| 其餘勢力 | 8 `#002266` | 3 `#3344dd` |

標記的左上角 ＝ `(440 + x/2 − 2, 40 + y/2 − 2)`，那個 −2 是把 4×4 置中。

底下的圖例兩格：左格是自勢力君主名（紅底白字），
右格是**玩家指定要盯著的勢力**（藍底白字），點右格會開一個 22 勢力的選單。

## 2. remake 做什麼

| 項目 | 做法 |
|---|---|
| 標記 | 照 §1 的四種顏色與 4×4 形狀畫在底圖上 |
| 座標 | `(minimapX + city.X/2 − 2, minimapY + city.Y/2 − 2)`。`city.X/Y` 已經是格座標 |
| 無所屬 | `Owner` 落在 `[0, len(Factions))` 之外就是無所屬（原版存 `0x18` ＝ 24，而勢力只有 22 個）|
| 顏色來源 | `g.lib.PaletteColor(季節, 色號)`，**不自己挑 RGB**。取不到就用 fallback 並記一行 log |
| 視野框 | 畫一個 20×12 的白色矩形外框。**原版那是一張美術**（`word_10D4C`），remake 畫線 → **標記為 remake 差異** |
| 圖例第二格 | 顯示 `g.minimapFaction` 那個勢力的君主名，初值 0（原版 `byte_198A7` 的靜態初值），若不存活就往後找第一個存活且非自勢力的 |
| 換第二格 | 點圖例右半格（熱區 `0x17` ＝ (536,168,96,16)）**換到下一個存活勢力**。原版是開一個 22 格的選單視窗，**remake 這一步是簡化**，標記為 remake 差異 |

**不做的事**：22 勢力的選擇視窗（`sub_15AFC` 的版面沒解，只解了行為）。

## 2.5 點地圖捲鏡頭與勢力選擇視窗（2026-08-22 補）

兩件事的機器碼都解出來了（[`../re/71`](../re/71-strategy-hotspot-dispatch.md)）。

### 2.5.1 熱區 `0x16`：點縮小地圖 ＝ 把鏡頭捲過去

```
世界格 X ＝ (螢幕 x − 440) × 2      # 負數夾成 0
世界格 Y ＝ (螢幕 y −  40) × 2
鏡頭左上角 ＝ (世界格 X − 20, 世界格 Y − 12)   # 與開局定位同一支 sub_12151
```

⭐ **`−(20, 12)` 與開局鏡頭是同一組立即值**
（[`52`](52-main-screen-camera-and-banner-date.md)）——點縮小地圖與開局
走同一支置中常式，所以 remake 也要共用同一段換算。
邊界夾制照既有的 `clampCam`。

### 2.5.2 熱區 `0x17`：22 勢力的選擇視窗

| 項目 | 值 | 出處 |
|---|---|---|
| 外框 | **(512, 192, 128 × 208)** | `sub_1895D(al=0x1F, dx=0x20, bx=0x0A, cx=0x0D08)` |
| 標題列底色 | (520, 200)–(631, 215)，色 **7** | `sub_1F1A3` |
| 清單底色 | (520, 216)–(631, 391)，色 **9** | `sub_1F1A3` |
| 標題 | **「勢力一覽」**，(544, 200)，屬性 `0x7001` | `cs:5C04` |
| 熱區 | (520, 216, 112 × 176) | `sub_1E3D7(al=0x20, cx=0x160E)` |
| 左欄 X ／ 右欄 X | **524 ／ 580** | `sub_15C14` 的 `dx = 0x20C` ／ `0x244` |
| 第 n 列的 Y | **216 + (n mod 11) × 16** | 同上 `bx <<= 4 / += 0xD8` |
| 每欄列數 | **11**（22 ÷ 2）| 同上 `cmp bl, 0x0B` |
| 空槽 | **「－－－」**，屬性 `0x9001` | `cs:5C0D` |
| 欄的分界 | 點擊 X **≥ 576** ＝ 右欄 | `cmp cx, 0x240` |
| 字色 | 一般 `0x90` ＝ 黑、自勢力 `0x9A` ＝ 紅 10、選中 `0x93` ＝ 藍 3 | [`../re/62`](../re/62-strategy-minimap.md) §4.2 |

規則兩條：**勢力要存在**（記錄 `+0x00 ≥ 0x80`）、**不能選自己**。
**右鍵關閉**（`sub_20000(ax=5,bx=1)` 回非 0 就走 `loc_15BEB` 擦掉框）。

⭐ **三塊互相印證**：外框 (512,192)–(639,399)，兩塊填色與熱區都剛好四邊
各內縮 8 px。那 8 px 就是框邊，與訊息框同一個數。

> **remake 差異**：原版的字色來自屬性 byte 的高低位元組，remake 走
> 既有的 `paletteInk`；顏色索引照抄（0／10／3）。
