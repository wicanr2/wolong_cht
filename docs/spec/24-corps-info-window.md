## 1. 版面

視窗 `sub_1895D(al=1Fh, bx=0Ah, dx=1Bh, cx=0D0Dh)` → **(432, 192, 208, 208)**
——**與自勢力情報視窗同一格**，開著的時候蓋掉它。
顯示清單場景 4 的原點是 (440, 200)。

### 1.3 空槽照原版畫天秤

圖庫基底是紅色組（段 3 `0x1BA0` 起四張），而兵種 4（空槽）算出來是
**第五張 ＝ 綠色組的第一張天秤**——越界一張的原版瑕疵
（[`docs/re/51`](../re/51-corps-info-window.md) §4）。

**remake 照抄。** 這是呈現層的原版行為，不是玩法；換成空白會讓畫面
與原版不一致，而這個專案的定位是保存。`library.DOSVResourceIcon(0, true, bank)`
就是那一張。

## 2. 互動

原版：**自己的軍團**看完接著進指令流程（`sub_17FDB`，見
[`../re/45`](../re/45-corps-command-mode.md) §1）；
**別人的軍團**只是看，狀態列掛 TALK #4，按右鍵關掉。

remake 這一輪只做顯示，兩種都是按 ESC 關掉。

## 3. remake 要做什麼

`cmd/wlgame/corpsinfo.go` 照 §1 畫，由軍團一覽選取後開啟。
先前「軍團」指令只開一覽表，選完什麼都不做。

| 項目 | 作法 |
|---|---|
| 視窗 | `chrome.Window(432, 192, 208, 208)` |
| 靜態層 ＋ 動態層 | 照 §1 |
| 空槽 | 照 §1.3 畫天秤 |
| 頭像 | `library.Portrait(General.Portrait, bank)` |
| 離開 | ESC |

⚠ **空槽的兵種要是 4 才畫得對。** `FormCorps` 先前把沒編兵的槽留成
「兵種 0、人數 0」，那在原版是**騎馬空隊**；已改成寫 `state.EmptySlotKind`。
