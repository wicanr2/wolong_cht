# 38 — 一覽表：視窗幾何、欄位與逐列格式

**狀態：CONFORMED。** 視窗矩形、捲軸的四個熱區、五組欄位標題、欄寬定義與
四個家族的逐列格式都有機器碼出處，已實作並有單測。

- 日期：2026-08-16
- 出處：[`../re/26`](../re/26-list-window-engine.md) §2（幾何）、§4.1（標題與欄數）、

## 1. 原版做什麼

### 1.1 視窗

`sub_181C0` 的 `cx = 0x0B18` ＝ **24 格 × 11 格**（一格 16 px）
＝ **384 × 176**，左上角 `(24, 88)`。x 範圍與命令列相同（24–408）。

一列 16 px，扣掉標題那一列 ⇒ **一頁 10 列**——`sub_18546` 用
「尺寸的高 byte − 1」當一頁列數算 `top` 的上限，這是第二個獨立來源
（[`../re/26`](../re/26-list-window-engine.md) §10）。

### 1.1.1 左邊 16 px 是捲軸

| 元件 | 矩形（一覽表 (24,88,384,176)）| 行為 |
|---|---|---|
| 清單本體 | (40, 104, 368, 160) | 點一列 ＝ 選取 |
| ▲ | (24, 104, 16, 16) | `top − 1` |
| 捲軸槽 | (24, 120, 16, 128) | 按住拖曳換算 `top` |
| ▼ | (24, 248, 16, 16) | `top + 1`，上限 `筆數 − 10` |
| 欄位標題 | (24, 88, 384, 16) | 點一欄 ＝ 排序 |

**框畫在內容區外面**：往左上各退 8 px、寬高各多 16 px ⇒ (16, 80, 400, 192)。

### 1.2 五組欄位標題與欄寬

`si` 指向標題字串，其後緊跟一條**分隔線**——那條線就是欄寬定義：
全形 `－` 佔 16 px、半形 `-` 佔 8 px，**一段連續的 `－`／`-` 就是一欄**。

| 家族 | 標題 | 欄數 |
|---|---|--:|
| 軍團 | `武將名　總兵數　士氣值 現在位置 目標據點` | 5 |
| 據點 | `據點名　生產力　上昇率　防災　城兵　內政官` | 6 |
| 武將 | `武將名　武術 統率 政治　　勢力　　　身分` | 6 |
| 勢力 | `勢力名　武將　據點　首都　　外交　　外交官` | 6 |
| 開局選勢力 | `勢力名　軍師名　　武將　據點　　首都` | 5 |

分隔線逐字對應（[`../re/26`](../re/26-list-window-engine.md) §4.1）：
`－` 的欄放中文、`-` 的欄放數字。

⚠ **「同一種清單、兩種取法」**：指令列的「看」與人事／外交的「選」
用**同一組欄位**，只有內容不同（`../re/26` §4.2）。
remake 先前替每個 picker 各編一組欄位，那是自創的。

### 1.3 逐列格式（[`../re/27`](../re/27-list-row-fields.md) §2）

| 家族 | 欄 | 格式 |
|---|---|---|
| 據點 | 生產力／上昇率／防災／城兵／內政官 | 5 位／4 位**先減 100**／3 位／4 位**先 ×10**／`0xFF` 空白 |
| 武將 | 武術／統率／政治／勢力／身分 | 各 2 位／勢力名／[`../re/26`](../re/26-list-window-engine.md) §9 的六個名稱 |
| 勢力 | 武將／據點／首都／外交／外交官 | 3 位／3 位／據點名／六級名稱／`0xFF` 空白 |
| 軍團 | 總兵數／士氣值／現在位置／目標據點 | 4 位**先 ×10**／3 位**< 100 換色**／不在據點顯示「－」／同左 |

軍團最右端還有一格無標題：委任中印「**委任**」，否則印兩個全形空白。
那一格**不在分隔線裡**，所以 `listFamily.Extra` 另外給它兩個全形寬，
接在分隔線右邊空一格的位置。

外交六級（`../re/27` §4）：交戰／最惡／險惡／普通／良好／親密／`－－`，
**交戰那一筆換色**（屬性 `0x0A`）。

身分六個值（`../re/26` §9）：`－－－`／軍團長／內政官／外交官／俘虜／君主。

### 1.4 沒有資料的列印的是分隔線

原版**一頁永遠畫滿十列**：資料不夠時，剩下的列每一欄印的就是分隔線那一行
——全形欄印 `－`、半形欄印 `-`，數量照欄寬。

證據是 DOS/V 實錄影格的軍團一覽（`workplace/parity/ytframes/f023.png`）：
兩支軍團，下面八列全是破折號，而且**第一欄三個粗的全形、第二欄四個細的半形**
——與分隔線 `－－－　 ----　　---` 逐字對上。

## 2. remake 做什麼

| 項目 | 做法 |
|---|---|
| 幾何 | 視窗 (24, 88, 384, 176)、列高 16、一頁 10 列 |
| 欄位 | 四個家族各一組，**標題與分隔線照抄原版字串**，欄的 x／寬由分隔線算 |
| 排序 | 點標題排序照舊（[`../re/26`](../re/26-list-window-engine.md) §5 的持久排序已實作）|
| 數字欄 | 靠右對齊到該欄右緣；文字欄靠左 |
| 換色 | 三條都做（`../re/27` §5）：**軍團總兵數 < 300 點**、**軍團士氣 < 100**、**據點上昇率 0**；外交「交戰」那一格也換色 |
| 空列 | 照 §1.4 印分隔線字元，一頁固定十列 |
| 身分 | remake 的武將記錄只留 `Posted bool`，所以**由狀態反推**：君主 → 勢力表、內政官 → 據點的 `Governor`、外交官 → 勢力的 `Diplomat`、軍團長 → `Posted`，其餘 `－－－` |
| 捲軸 | 照 §1.1.1 畫在內容區左緣 16 px：▲／槽／▼ 三段。滑塊的位置照 `top ÷ (筆數 − 10)` 取比例——**原版的滑塊繪製常式沒讀，這一格是 remake 的畫法** |
| 清單本體 | 從 `x + 16` 起、寬 `W − 16`，欄位的 x 全部以它為基準 |
| 頁尾 | **不畫**。翻頁交給捲軸，取消交給右鍵／ESC，與原版一致 |
| 標題列 | 黑底白字（影片影格），標題是原版的一整條字串 |

## 4. 未解

| 項目 | 現況 |
|---|---|
| 滑塊的樣式 | 熱區與 `top` 的換算已解，但**畫滑塊的常式（`sub_18713` 的反向）沒讀**，remake 依比例自己畫 |
| 俘虜身分 | remake 的 `Posted` 是 bool，存不下 `+0x17` 的 0–5；俘虜狀態目前推不出來 |
| 「看」與「選」的內容差異 | 原版兩種取法的**列表內容**不同（`../re/26` §4.2），remake 只統一了欄位 |
| 「委任」那一格的顏色 | 實錄影格上看起來是紅字，但影片是壓縮過的、也沒有機器碼證據。remake 先畫成一般色 |
