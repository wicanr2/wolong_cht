`{6}` ＝ 排版標記（空字串）。

## 3. remake 改了什麼

`cmd/wlgame/advise.go` 先前用的是**改寫過的中文**，而且三個指令共用一組。
對照第一句就看得出來：

```
remake  「不可答允，別平白增加敵人。」
原版    「無法答允！別平白增加敵人。」
```

⚠ 更嚴重的是**停戰與協力顯示的是敵對那一組的措辭**——原版三組各不相同。

改法：`adviseTalkBase(cmd)` ＋ `adviseTalkIndex(base, 位置, 變體)`，
全部改成 `g.talkLines(...)` 查 `TALK.DAT`。
玩家看得到的文字**不再寫在 Go 原始碼裡**（`CLAUDE.md` §6）。

**保留的 remake 差異**：進言仍走清單視窗（有一份對話紀錄），
不是原版「插圖 ＋ 兩個框輪流講話」的模態流程，所以每一行前面留
「君主：」「軍師：」當說話者標記——那個視窗沒有肖像可以分辨。
