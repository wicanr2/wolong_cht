# 96 — 守陣不可以在回陣的那一步被降級成「就位」

**狀態：CONFORMED。** `doGuard` 本來借 `doFormation` 走回陣形，而
`doFormation` 到位時會把命令改成「就位」（狀態 7）——於是**守陣只活一幀**：
下令的下一幀敵人還沒進 16 格，兵就永遠變成原地待命。
抽出 `walkToFormation`（只設目標、不碰命令）之後守陣撐得住了。

- 日期：2026-08-27
- 出處：[`../re/11`](../re/11-tactical-battle.md) §5.8（命令對照表：
  **命令 0**「走到 `+0x14` 指定的座標，**到位轉狀態 7**」；
  **命令 4** `sub_1A99C` 只用距離 16 選行為，不改命令）、
  同 §5.8 的 `sub_1ABB2`（守陣**疲勞** < 16 才把命令改回 0）
- 推論等級：confirmed（「到位轉狀態 7」寫在命令 0 那一列，
  命令 4 那一列只有「距離 ≤ 16 換行為」）

## 1. 原版做什麼

| 命令 | 到位時 | 什麼時候換命令 |
|---:|---|---|
| 0 陣形 | **轉狀態 7（就位）**、疲勞補滿 | — |
| 4 守陣 | 不轉 | **疲勞** `[si+19h] < 16` 時改回命令 0（`sub_1ABB2`）|

說明書 4.2：「守陣（守備陣形）：擺陣 → **敵人靠近就攻擊** →
**敵人後退就回陣**」。**回陣是行為，不是換命令**——不然下一次敵人靠近
就沒有人會反應了。

## 2. remake 現況

```go
func (b *Battle) doGuard(side, k int) {
    if s.Target < 0 { b.doFormation(side, k); return }   // ← 借用
    ...
    b.doFormation(side, k)                                // ← 借用
}

func (b *Battle) doFormation(side, k int) {
    ...
    if s.X == x && s.Y == y {
        s.Stamina = StaminaFull
        s.Cmd, s.Next = Holding, Holding   // ★ 命令 0 專屬的轉換
    }
}
```

守陣的兵開場就站在陣形位置上，第一幀還沒鎖到敵人（`Target < 0`），
於是走「借用」那條路 → 判定已經到位 → **命令變成就位**。

量到的（據點 82 的攻城 fixture，把玩家側的開場常令改成守陣試跑）：

| | 守方的命令分布 |
|---|---|
| frame 0 | `{0: 48}`（還沒套用）|
| frame 5 | **`{7: 48}`** ——48 個兵全部變成就位 |
| frame 200 | `{7: 48}`，而且**每個兵都已經鎖到敵人**（有目標 48）|

**鎖到敵人的時候命令已經不是守陣了**，所以永遠不會反應。

## 3. 演算法

把「走回陣形位置」與「命令 0 到位的轉換」拆開：

```
走回陣形(side, k)：            # 只設目標，不碰命令
    目標 = 陣形位置
    回傳「是不是已經在那裡」

命令 0（陣形）：
    if 走回陣形(...):
        疲勞補滿；命令 ← 就位

命令 4（守陣）：
    沒有鎖定目標           → 走回陣形
    目標在 16 格內         → 走攻擊那條路
    疲勞 < 16              → 命令 ← 0，再走命令 0
    其餘                   → 走回陣形（**命令維持 4**）
```
