## 4. ⚠ 為什麼遊玩時不自繪

原版在「清單等待點選」時旗標是 0，也就是**畫面上沒有游標**——
玩家要靠反白列。這在真機上說得通與否，**沒有實機佐證**：
dosgolem 是否完整模擬 `INT 33h AH=0Ch` 設的中斷副程式（滑鼠移動時
由驅動回呼重畫）還沒查，所以「旗標 0 時移動也不重畫」有可能是
oracle 的限制而不是原版行為。

⭐ **「旗標 1 → 有游標」是可信的**（十個狀態逐格對上），
所以對拍端先接這一半：`-cursor` 讓那幾張從 95 px 收到 0 px。
遊玩端要等「旗標 0 到底畫不畫」有實機佐證再動——
現在改成自繪反而可能讓玩家在清單上看不到游標。
