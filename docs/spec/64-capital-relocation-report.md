## 1. 原版做什麼

`sub_133FD` 是**唯一**改首都的地方，兩條進來的路共用它：

```asm
000133FD  sub ax, 840h / shl ax,1 ×3 / mov al, ah   ; 新首都的據點編號
00013408  xchg ah, [si+3]                           ; si ＝ 勢力記錄，+0x03 ＝ 首都
0001340B  cmp al, ah / jz retn                      ; ★ 沒換就什麼都不做
0001340F  …/ call sub_14502                         ; 掛舊首都的軍團改掛新首都
0001341A  cmp si, cs:word_10CFD / jnz loc_13449     ; ★ 這是玩家的勢力嗎
```

### 1.1 是玩家的勢力：君主下令

```asm
00013421  mov al, [si+3]        ; 新首都
00013424  mov ah, 0FFh / push ax / mov di, sp
00013429  mov bh, [si+1]        ; 勢力 +0x01 ＝ 君主編號
00013434  mov ah, [bx+425Eh]    ; 君主的說話型（raw）
00013438  mov al, [bx+4241h]    ; 君主的肖像
0001343C  mov cx, 1A4h / call sub_18810
00013445  call sub_15E60
```

`0x1A4` 是**組編號**不是索引：`0x196 + (0x1A4 − 0x196) × 8 + 說話型`
＝ **518 ＋ 變體**（[`../re/25`](../re/25-message-variants-and-personnel.md) §1）。
君主是**主公型**，說話型落在 0–2（同文件 §「0–2 ＝ 主公型」）：

| 變體 | 索引 | 文字 |
|---:|---:|---|
| 0 | 518 | 將首都移{2}，　立刻準備！！ |
| 1 | 519 | {4}！就將京城移往{2}。為此做準備吧！ |
| 2 | 520 | 將京城移往{2}。就此進行吧。 |

### 1.2 ⭐ 不是玩家的勢力：沒有外交官就一句話都不報

```asm
00013449  mov ch, [si+2Ah]      ; 派駐該勢力的外交官
0001344C  cmp ch, 0FFh / jz retn ; ★ 沒有 → 直接返回
00013467  mov cx, 39h / mov al, 93h / call sub_18810   ; #57
00013473  mov cx, 1A4h
00013476  mov ah, [di+1Eh]      ; ★ 外交官的說話型
00013479  mov al, [di+1]        ; ★ 外交官的肖像
0001347E  call sub_18810
```

`+0x2A` 就是外交官欄（[`../re/07`](../re/07-monthly-settlement.md)），開局全部 `0xFF`。
外交官是**臣下型**，說話型落在 3–7：

| 訊息 | 文字 |
|---:|---|
| **#57** | 駐{3}勢力的外交官{1}大人前來報告。 |
| 521 | {3}遷都到{6}{2}了，特此報告。 |
| 522 | {3}已將首都遷移到{6}{2}了，特此報告。 |
| 523 | 報告！{3}遷都到了{6}{2}了。 |
| 524 | {3}機密地遷都到了{6}{2}了。 |
| 525 | {3}遷都到{6}{2}了，特此報告。 |

⭐ **「某國遷都了」是一則情報，不是公開事實。** 沒有在那邊佈外交官，
首都換了也不會知道——外交官除了是外交行動的前置佈署，也是情報站
（[`../mechanics/50-diplomacy.md`](../mechanics/50-diplomacy.md) §9.6）。

## 2. 演算法

```
遷都(勢力 f, 新首都 n):
    if f.首都 == n: return                  # 沒換就什麼都不做
    舊 ← f.首都 ; f.首都 ← n
    掛舊首都的軍團改掛新首都              # sub_14502，remake 已有

    if f == 玩家:
        說(518 + 君主.說話型, {2}=n)  肖像 ＝ 君主
        return
    if f.外交官 == 無: return               # ★ 情報閘
    說(#57, {3}=f, {1}=f.外交官)
    說(518 + 外交官.說話型, {3}=f, {2}=n)  肖像 ＝ 外交官
```
