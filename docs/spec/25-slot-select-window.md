## 1. 版面

視窗 `sub_1895D(al=1Fh, bx=3, dx=6, cx=0F13h)` → **(96, 80, 304, 240)**，
顯示清單場景 6 的原點是 (104, 88)。

### 1.1 靜態層

| 元件 | 座標 | op |
|---|---|---|
| 水平分隔線 | (104, 111) 長 287，色 `0x0F` | **05** |
| 名稱欄 ×4 | (120, 118 + 48k) 256×20 | 03 |
| 日期欄 ×4 | (256, 144 + 48k) 120×16 | 03 |
| 日期欄的立體外框 ×4 | (254, 142 + 48k) 與 (255, 143 + 48k) 各一圈 | **04** |

### 1.2 動態層

| 值 | 座標（第一槽）| 位數 | 色 | 來源 |
|---|---|---:|---|---|
| 標題 | (184, 91) | — | `0x0F` | 三選一（§1.3）|

三個數字各自嵌在「年　月　日」那三個字的**前面**。

### 1.3 三個標題

`ds:98C8` 起每筆 19 bytes：`ＮＥＷ　ＧＡＭＥ　`／`ＬＯＡＤ　ＤＡＴＡ`／`ＳＡＶＥ　ＤＡＴＡ`。
**原版沒有獨立的選劇本畫面**——新遊戲時四個槽是 `SINARIO.DAT` 的四個劇本，
讀取／儲存時是 `SAVE.DAT` 的四個存檔，同一份版面讀兩個檔。

## 2. 互動

四個熱區 `0x20`–`0x23` 在 **(256, 144 + 48k) 120×16**，與日期欄逐格重合；
左邊的名稱欄不可點。

⭐ **只有儲存可以選空槽**：新遊戲與讀取都會檢查名稱欄的第一個字是不是
`0xD0A1`（空槽標記），是就當作沒點到。

## 3. remake 要做什麼

`cmd/wlgame/save.go` 照 §1 畫。先前是自己排的 `(112,72,416,248)`
加四行文字，與原版無關。

| 項目 | 作法 |
|---|---|
| 視窗 | `chrome.Window(96, 80, 304, 240)` |
| 靜態層 | 照 §1.1；`04` 的立體外框用兩圈 `StrokeRect` |
| 名稱 | `World.Title`（新增欄位，區塊 `+0x40`）|
| 年月日 | 照 §1.2 的座標與位數 |
| 熱區 | `saveSlotRect` 改成 (256, 144+48k) 120×16 |
| 空槽 | 讀取模式不可選，與原版同一條規則 |
| 標題 | 照 §1.3 三選一 |

remake 差異（保留）：鍵盤上下選槽、`確定`／`取消` 兩個按鈕、
`-save-file` 沒指定時的提示——**都移到原版視窗外面**的另一個框。
