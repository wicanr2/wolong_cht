## 2. 互動

四個熱區 `0x20`–`0x23` 在 **(256, 144 + 48k) 120×16**，與日期欄逐格重合；
左邊的名稱欄不可點。

⭐ **只有儲存可以選空槽**：新遊戲與讀取都會檢查名稱欄的第一個字是不是
`0xD0A1`（空槽標記），是就當作沒點到。

## 2.9 ⭐ 殼層的**選劇本**與 LOAD DATA 都是這一個視窗

原版的開場流程（ＮＥＷ　ＧＡＭＥ ＮＯ → LOAD DATA）與遊戲中的
系統選單第 0 列走的是**同一支 `sub_18B5D` → `sub_18B7C`**，
差別只有標題那三選一（`ＮＥＷ　ＧＡＭＥ`／`ＬＯＡＤ　ＤＡＴＡ`／
`ＳＡＶＥ　ＤＡＴＡ`，[`../re/52`](../re/52-slot-select-window.md) §2）。

⚠ remake 起初在啟動殼層另外畫了一份（「第 1 槽　196年4月16日　曹操」
那種版面），於是 [`../playtest/99`](../playtest/99-slot-window-parity.md)
對到 0 px 的那些修正（空槽照畫日期、日期欄黑字綠底、名稱欄用滿寬）
**只套到遊戲中那一份**。收成一支：殼層走到那一頁時
`beginSaveUI(saveRead)`，畫面交給 `drawSaveUI`。

### 2.9.1 選劇本也是——只是換一個檔

§1.3 已經寫明「**原版沒有獨立的選劇本畫面**」：新遊戲時四個槽讀
`SINARIO.DAT`，讀取／儲存時讀 `SAVE.DAT`，**同一份版面讀兩個檔**。
名稱欄兩邊都是區塊 `+0x40`——劇本檔裡是「第一章．「呂布歸天」之卷」，
存檔裡是「第一章勢力：曹操　軍師：荀彧」，**同一個欄位不同內容**。

所以 remake 的三個模式只差兩件事：

| 模式 | `saveAction` | 標題 | 資料源 |
|---|---|---|---|
| 新遊戲選劇本 | `saveNewGame` | `ＮＥＷ　ＧＡＭＥ　` | `SINARIO.DAT` |
| 讀取 | `saveRead` | `ＬＯＡＤ　ＤＡＴＡ` | `SAVE.DAT` |
| 儲存 | `saveWrite` | `ＳＡＶＥ　ＤＡＴＡ` | `SAVE.DAT` |

⚠ 劇本那四槽**一律可選**：`inspectLauncherSlots` 的 `validLauncherPlayer`
是給存檔用的（存檔要有合法的玩家勢力），劇本沒有玩家。

⚠ **日期與標題跟「這一槽能不能選」無關**——原版畫的是區塊裡的值（§1.2）。
把它們讀在 `validLauncherPlayer` 後面的話，選劇本那一頁四列日期會全是
`0年 0月 0日`。

⚠ **劇本一律讀 `SINARIO.DAT`。** `savepath.InitialLoadPath` 在有存檔時
回的是**存檔**，拿它去 `LoadScenario` 讀出來的標題會變成
「第一章勢力：曹操　軍師：荀彧」那種存檔摘要。

## 3. remake 要做什麼

`cmd/wlgame/save.go` 照 §1 畫。先前是自己排的 `(112,72,416,248)`
加四行文字，與原版無關。

| 項目 | 作法 |
|---|---|
| 視窗 | `chrome.Window(96, 80, 304, 240)` |
| 靜態層 | 照 §1.1；`04` 的立體外框用兩圈 `StrokeRect` |
| 名稱 | `World.Title`（新增欄位，區塊 `+0x40`）|
| 年月日 | 照 §1.2 的座標與位數 |
| 熱區 | `saveSlotRect` 改成 (256, 144+48k) 120×16 |
| 空槽 | 讀取模式不可選，與原版同一條規則 |
| 標題 | 照 §1.3 三選一 |

remake 差異（保留）：鍵盤上下選槽、`確定`／`取消` 兩個按鈕、
`-save-file` 沒指定時的提示——**都移到原版視窗外面**的另一個框。

### 3.1 空槽也照畫（2026-09-06 原版擷取）

原版擷取（`orig-save`）顯示：**空槽不是留白，也沒有另外一句話**——

| | 名稱欄 | 日期欄 |
|---|---|---|
| 有存檔的槽 | 「第一章勢力：曹操　軍師：荀彧」（色 9）| `196年 4月16日` |
| 空槽 | **一整排「－」**（同樣色 9）| **`0年 0月 0日`** |

那排破折號**就是檔案裡的 `+0x40` 字串**（空槽標記 `0xA1D0` ＝「－」，§2），
所以原版根本沒有「空槽」這個分支：名稱欄照畫 `+0x40`、日期欄照畫三個數字，
空槽的值剛好是破折號與 0。

remake 先前的做法有三個分歧：

1. **儲存模式根本沒去看槽**（`beginSaveUI` 只在讀取時 `inspectLauncherSlots`），
   於是四槽全部顯示成空的——**要覆蓋哪一格看不到**。
2. 空槽畫成紅字「空白槽位」，原版是破折號。
3. 空槽不畫日期，原版畫 `0年 0月 0日`。

收法：`inspectLauncherSlots` 連**載不起來的槽**也把 `+0x40` 的原字串填進
`Title`（`state.SlotTitle`），繪製端一律照畫，不再分「有／沒有」。
⚠ **「可不可以選」是另一回事**——讀取與新遊戲仍然擋空槽（§2），
那道判斷走 `Available`。
