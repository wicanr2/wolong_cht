# 65 — 退到畫面外的兵算生還，不算戰死

**狀態：CONFORMED。** 分歧點是同一支移除常式的一個參數，逐行讀得出來，
remake 兩條路分開了。

- 日期：2026-08-18
- 出處：`sub_1B4B8`（`0001B4D6`）、`sub_1AAED`（退卻離場）、
  `sub_1ADC8`（`0001AE0E` 的死亡收尾）、`sub_19F58`（打完的寫回）
- 推論等級：**confirmed（靜態）**

## 1. 原版做什麼

兵離場只有一支常式 `sub_1B4B8`，`ah` 決定算不算生還：

```asm
0001B4C0  bx = 隊編號 × 4 + 8        ; si ≥ 0x600（側 1）再 +8
0001B4D6  and ah, ah
0001B4D8  jnz short loc_1B4DE        ; ★ ah ≠ 0 → 不加
0001B4DA  inc byte ptr es:[bx+3]     ; ★ 第 k 隊的存活數 +1
0001B4DE  … sub_1B3B2                ; 把圖擦掉
```

`es:[bx+3]` ＝ `+0x0B + 4k`，也就是**第 k 隊的存活數**
（[`../re/11`](../re/11-tactical-battle.md) §3.9）。

兩個呼叫端傳的 `ah` 不同：

| 呼叫端 | `ah` | 情境 | 算存活嗎 |
|---|---:|---|---|
| `sub_1AAED` | 0 | **退卻走到畫面邊緣** | ✅ 加 |
| `sub_1ADC8` `0001AE0E` | 1 | 倒地動畫數完四幀 | ❌ 不加 |

打完之後 `sub_19F58` 的寫回是

```
新兵力 ＝ Σ（各隊存活數 ＋ 各隊待機數）
新士氣 ＝ 舊士氣 × 新兵力 ÷ 舊兵力
```

所以**退到畫面外的兵會跟著軍團回去**，戰死的不會。
說明書 4.1 寫的就是這件事：「兵士が戦闘して敵にやられると、
**画面外に退却**し、待機中の兵が出陣します」——退卻是保命，不是損失。

### 1.1 ⚠ 這與勝負判定是**兩個**計數

勝負看的是 `word_1D31C`，那是 `sub_1ADC8` 每幀從頭數一次「場上還有幾個」
（`sub_1AEA9`），與存活數無關。**兩者不能共用一個函式**——
把離場的兵加回「場上人數」，戰鬥就永遠打不完。

## 2. 演算法

```
兵走到畫面邊緣（退卻）: 離場；該隊生還 += 1
兵體力歸零           : 離場；生還不變

打完:
    新兵力 ＝ Σ（各隊生還 ＋ 各隊待機） ＋ 還站在場上的
```
