## 2. 互動

**沒有熱區**——`sub_17E1F` 的迴圈只等右鍵離開，是純顯示視窗。

## 3. remake 要做什麼

`cmd/wlgame/cityinfo.go` 照 §1 畫，由一覽表選取後開啟。
先前「據點」指令只開一覽表，沒有這個視窗。

| 項目 | 作法 |
|---|---|
| 進入 | 一覽表選一個據點之後開情報視窗。原版是在地圖上點據點；一覽表是既有的 remake 差異，保留 |
| 視窗 | `chrome.Window(0, 272, 256, 128)` |
| 靜態層 ＋ 動態層 | 照 §1 |
| 景觀圖 | `library.Location(City.KindHigh, bank)`；解不出來就留白，**不要換一張圖頂替** |
| 離開 | ESC／右鍵 |

`City.KindHigh` 是 confirmed 的 `KYOGRF` 張號（[`docs/re/50`](../re/50-city-info-window.md) §3）。
