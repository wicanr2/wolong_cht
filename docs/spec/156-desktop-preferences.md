# 156 — 桌面偏好跨次啟動保存

**狀態：CONFORMED（2026-09-08，正式 AppImage 正常設定與重啟通過）。**

- 日期：2026-09-08。

## 依據與範圍

使用者於 2026-09-08 授權執行設定記憶等桌面打磨，Windows／macOS 原生操作改由人工驗收。
這是明示的 remake 便利性差異，不主張原版曾保存這些偏好，不需推測 DOS 欄位。
本規格取代 [89 §7](89-siege-damage-report-toggle.md) 的當次執行生命週期限制；
原版與原生遊戲存檔格式、戰鬥規則及 Android 不變。

## 保存契約

- 在 `os.UserConfigDir()` 下的 `wolong-remake/preferences.json` 保存版本 1 的 JSON。
- 保存語言、畫面模式、音效選項、戰略／戰術速度、主君編成、損害報告、戰後結果秒數。
- 無檔案時沿用既有預設，戰後結果仍預設關閉。新遊戲與讀檔不重設偏好。
- 正常玩家啟動讀取偏好；明示的命令列設定優先。直接進場、截圖與錄影驗收不讀寫偏好。
- 玩家變更偏好時立即以同目錄暫存檔完成寫入，再替換正式檔；啟動讀取不寫檔。
- 輸入限 64 KiB，版本或欄位值無效時保留原檔、記錄錯誤並沿用預設。
  使用者之後主動變更設定時才允許寫回有效偏好。
- 寫入失敗保留當次選擇，透過既有事件列及日誌提示，不能插入確認頁或中止遊戲。
- 系統視窗開啟時，背景事件列與策略狀態提示不覆蓋設定視窗；關閉後沿用原有提示生命週期。
- 速度值限 0–4、音效值限 0–4，戰後秒數只接受既有六個選項；語言沿用既有四語。

## 驗收與停止線

驗證無檔預設、重啟還原、命令列優先、壞檔／未知版本／過大檔案、寫入失敗保護，
及實際 AppImage 正常設定後退出再啟動。設定來源可追溯到使用者操作，不混入遊戲存檔。
本項不以偏好保存宣稱原版戰況對拍或 Windows／macOS 原生驗收完成。

正式 v.1.0.14 的設定重啟與完整設定視窗 0 像素差異見 [playtest/113](../playtest/113-desktop-polish.md)。

## 未解

無阻擋實作的偏好語意缺口；Windows／macOS 原生設定路徑與操作由人工驗收。
