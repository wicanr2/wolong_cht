## 2. 原版怎麼做

### 2.1 陣形選單（熱區 `0x03`，(496, 248, 128×32)）

```
col = (游標X − 0x1F0) >> 4              ; 0–7
if (游標Y − 0xF8) >= 0x10: col += 8     ; 下面那一列
byte_1D346 = col                        ; 選中的格
word_1D342 = col × 96                   ; 側 0 的陣形表偏移
```

選取框：格 16×16，起點 `(496 + (i&7)×16, 248 + (i&8 ? 16 : 0))`，
內縮 1 px 畫 14×14，**取消色 10、選中色 12**。

### 2.2 陣形線（熱區 `0x04`／`0x05`／`0x06`）

| 熱區 | 矩形 | `word_1D33C` 低 byte ← |
|---|---|---|
| `0x04` | (552, 288, 64×24) | `0x30` ＝ **48**（敵軍側）|
| `0x05` | (552, 312, 64×32) | `0x1C` ＝ **28**（中央）|
| `0x06` | (552, 344, 64×24) | `0x05` ＝ **5**（自軍側）|

三個 handler 形狀相同：值沒變就直接回；變了就先用**舊值**抹掉小地圖上
那條線，寫入新值，再用色 11 畫新線。

⚠ **兩側的三個值不對稱**（玩家 48／28／5、腳本 58／36／16），
照抄兩組，不要自己算鏡射。

## 3. remake 做什麼

| 項目 | 做法 |
|---|---|
| 陣形選單 | 點 (496,248,128×32) 的 8×2 格 → `g.battleFormation` 與 `b.Sides[0].Formation` 一起改。選取框照 §2.1 畫（未選色 10、選中色 12）|
| 陣形線 | 點三格之一 → `b.Sides[0].Line = tactical.LineFor(0, k)`。**k 的順序照矩形由上而下 ＝ 敵軍側／中央／自軍側** |
| 小地圖上的線 | 在縮小地圖上照 `Line` 畫一條色 11 的直線 |
| 生效時機 | 兩者**立即寫入**，下一次「陣形」命令生效時部隊才走過去——與原版相同（原版也是先寫 `word_1D342`／`word_1D33C`，命令生效才移動）|

**不做的事**：抹掉舊線再畫新線那套髒格更新（remake 每幀重畫）。
