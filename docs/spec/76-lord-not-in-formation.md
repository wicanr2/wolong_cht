# 76 — 主君能不能編成：系統選單裡的開關

**狀態：CONFORMED。系統選單多一列「主君編成」，遊戲中可隨時切；
⚠ 預設「可」——與原版行為不同，是使用者裁定的 remake 差異。
對拍要用原版行為時帶 `-lord-corps=false`（2026-08-24 加的驗收旗標）。**

- 日期：2026-08-23
- 出處：見 §2（**強證據，不是 confirmed**）
- 推論等級：**強證據**

## 1. 問題

`cmd/wlgame/corps.go` 的 `formCandidates()`：

```go
if gen.Alive && gen.Faction == g.world.Player &&
    !gen.Posted && gen.Captor == 0xFF {
```

**沒有排除君主**，所以 `-open-corps` 截出來的軍團一覽是
「曹操 6000／夏侯淵 6000」——玩家把自己的君主編成了軍團長。

## 2. 憑什麼說原版不行

⚠ **這一條是強證據不是 confirmed**，四項一起看：

| # | 證據 | 強度 |
|---|---|---|
| 1 | 使用者實機經驗：「原版主君不能夠編成」 | 使用者是玩過原版的人 |
| 2 | 受控 DOSBox-X 實機：走指令列「編成」編出來的軍團長是**夏侯惇**，不是曹操（`workplace/promo-live/probe-march/e1-corpslist.png`，196年4月7日）| 一次觀察 |
| 3 | ⭐ **原版讓君主帶兵走的是另一條路**：請求出陣時 `sub_16E8F` 由君主本人帶一支軍團，而且 `sub_16EC9` 專門擋「君主已經帶著軍團」（[`11`](11-ai-sortie.md)）| **結構論證** |
| 4 | ✅ **已讀（2026-08-24）**：候選過濾在建清單 callback（線性 `0x176A0`）：`[si] ≥ 0x80`（活著）∧ `+0x1C` ＝ 玩家勢力 ∧ **`+0x17` ＝ 0（無職）** ∧ **`si ≠ 君主記錄`**（`sub_187FF` 由勢力 `+0x01` 取君主）。**君主排除是 confirmed** | **confirmed** |

⭐ 第 4 項讀完之後整條升 **confirmed**。另外同一段實機截圖（`../playtest/42` §4）
顯示**軍師（荀彧）也不在候選裡**——劇本檔的 `+0x17` 初始全 0，
所以是執行期有人把軍師的身分寫進去；**寫入者未讀**（缺口）。
remake 對應：`formCandidates()` 排除 `Advisor`（實機行為 confirmed，機制出處待補）。

⭐ 第 3 項是這裡最有份量的一條。**如果一般編成本來就選得到君主，
那條專用的出陣路徑與那道「已經帶著軍團」的擋都沒有存在的必要。**
一個機制存在，通常是因為別的路走不到它。

⚠ 第 2 項只是一次觀察——那一次的點擊選的是清單第一列，
**不排除曹操只是排在別的位置**。所以它是佐證不是定案。

## 3. ⭐ 使用者裁定：做成開關，預設「可」

使用者 2026-08-23 裁定兩件事：

1. **開關放系統選單**（調速度那個畫面），遊戲中可以隨時切。
2. **預設「可」**——也就是**預設行為與原版不同**。

⚠ **這是明確標記的 remake 差異，不是還原。** 原版不讓一般編成選君主
（§2），remake 預設放行。想要原版行為的人自己把那一列切成「不可」。

⚠ **系統視窗因此不再與原版逐像素相同。** 原版那個視窗是六列、高 192；
第七列放不進去，視窗要加高到 216。[`../playtest/39`](../playtest/39-system-window-parity.md)
的「系統選單開著 0 px」**只對六列的舊版成立**，那一份已如實改寫成缺口。
這個代價是使用者在知情下選的。

⭐ **新列加在原版六列的後面，不是插在「遊戲結束」之前。** 插進去的話
原版最後那一列會被往下推一格，**六列沒有一列還在原座標**；加在後面
只多出下緣 24 px，那六列一個 px 都不動。代價是「遊戲結束」不再是
視覺上的最後一列——換到的是原版版面不被動到。

## 4. 演算法

```
formCandidates():
    for 每個武將 g:
        g 活著 且 屬於玩家勢力 且 未帶兵 且 不是俘虜
        且 (允許主君編成 或 g 不是本勢力的君主)
```

系統選單第 6 列（`sysRowLordCorps`）左右鍵都是 toggle，值顯示「可」／「不可」。

⚠ **開關只作用在玩家的編成指令，不要碰 `autoFormCorps`。**
請求出陣那條（`internal/state/advise.go:85`）
`autoFormCorps(w.Player, w.Factions[w.Player].Lord, false)`
**本來就是要讓君主帶兵**，照 `docs/spec/11`。兩條路不同，判定不共用。

### 6.1 ⚠ 驗收 fixture 自己抄了一份規則

第一次改完 `formCandidates()`，截圖裡**曹操還在**——因為 `demoCorps`
（`-open-corps` 用的 fixture）自己掃了一遍 `Generals`，沒有走那支。

⭐ **修好的規則沒有套到驗收路徑上，而截圖看起來像沒修。**
現在 `demoCorps` 直接用 `formCandidates()`。這是同一輪裡第二次踩到
「一條規則兩份實作」（另一次是右鍵取消散成十二份）。
