## 1. 原版做什麼

編一隊上場時（`sub_19B6D`），八個兵的記錄一次寫齊：

```asm
00019B73  mov ah, [bx+6]            ; ★ 軍團摘要的 +0x06 ＝ 士氣
...
00019BBA  mov cx, 8                 ; 一隊八個兵
00019BBD  mov es:[di+3], ah         ; ★ 體力 ← 士氣
00019BC1  mov es:[di+4], al         ; 兵種 × 18
00019BC5  mov es:[di+18h], dl       ; 戰力（另一條算式）
00019BC9  mov byte ptr es:[di+19h], 80h
00019BCE  mov word ptr es:[di+1Ah], 1
00019BD4  add di, 20h / loop
```

`word_1D30A:+0x06` 開打時由 `sub_19E70` 從軍團記錄抄進來
（[`../re/11`](../re/11-tactical-battle.md) §3.9），也就是大地圖上看得到的
那個士氣值。**士氣高的軍團，每個兵開場血就厚。**

### 1.1 100 是回復上限，不是開場值

`sub_1B97E` 的 `cmp [bx+3], 64h` 把**回復**擋在 100
（[`../re/11`](../re/11-tactical-battle.md) §5）。兩件事不衝突：
士氣 200 的軍團開場每個兵 200 點，掉到 100 以下才開始回，
回也只回到 100。

### 1.2 側欄那條體力條讀的是大將

`sub_1C6F6` 用 `word_1D30E:+0x03`（我方）與 `+0x603`（對方），
也就是**每側第 0 個單位**的體力，畫成 `值 × 3 ÷ 4`、上限 124
（[`../re/60`](../re/60-tactical-sidebar.md) §5）。上限 124 對應到值 165，
所以士氣 200 的軍團開場那條是滿的。

## 5. ⛔ 擋住這一條的是移動的互換規則，不是這一條

把開場體力改成士氣（士氣 200）之後，戰術戰鬥**不會結束**：
跑 95 萬 tick，兩軍的存活數、待機數與體力一個 byte 都沒動。

重現（一輪約 2 秒，改回 `HP: MaxHP` 就正常結束）：
劇本 0、`rng.NewFixed(5)`、雙方君主各編一支滿編軍團互相進攻，
`SyntheticFormations()` ＋ 全 0 的平地戰場，開到戰術畫面後 `Run`。

卡住的樣子：

| | 側 0 | 側 1 |
|---|---:|---:|
| 存活 | **2**（大將 ＋ 一名騎馬，命令「就位」，HP 滿 200）| 48 |
| 待機 | 0 | 84–90 |

### 5.1 ⭐ 沒有人打得到，因為沒有人「輪到自己時」站在相鄰格

側 1 的 48 個兵全部鎖定側 0 的兵 8（在 `(3,28)`）。逐 tick 追一支：

```
tick n   側1 兵17 在 (3,30) 鎖定 8 在 (3,28)   ← doAttack 進來時的位置
tick n+1 側1 兵17 在 (3,30) 鎖定 8 在 (3,28)
…（八個 tick 一模一樣）
```

而**同一時刻的全域快照裡，兵 17 站在 `(3,29)`**——距離 1。
兩個都是真的：它在自己的 `updateSoldier` 尾端由 `moveToward`
走到 `(3,29)`，然後在同一幀被別的兵**互換**回 `(3,30)`
（`sub_1B240` 的位置互換，remake 在 `soldier.go` 的 `other.Swapped` 那一段）。

⭐ 所以 `doAttack` 的 `曼哈頓距離 ≤ 1` 永遠不成立：
1,000 個 tick 裡 47,376 次走到近身路徑，**相鄰 0 次**，
看到的最小距離固定是 2。**目標旁邊那一格被反覆換人，
換進去的那個永遠不是「下一個輪到更新」的那個。**

### 5.2 為什麼開場 100 時看不到

`applyHit` 的退卻閘是 `e.HP < MaxHP`。開場剛好等於 100 時，
第一次挨打就低於門檻、第二次就排退卻，受傷的兵很快走光，
`Remaining()` 歸零，戰鬥就結束了——**是「大家都很快退場」
蓋住了「擠在一起就打不到人」**。開場 200 的兵要挨滿 100 點才會排退卻，
於是留在場上把目標圍住，缺陷才浮出來。

下手點：`sub_1AF69`（三軸依序試的移動）與 `sub_1B240`（互換）
原版的先後與旗標條件，對照 remake 的 `moveToward`。
