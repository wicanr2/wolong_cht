## 1. `sub_1474A` 的後半段

戰鬥結束後**兩邊各跑一次**（`sub_15130` 呼叫兩次，結果進 `ah` 的
bit 0／bit 1）。`cl` 是勝敗旗標：

```
士氣 0 或大將槽兵力 0            → 壞滅
cl == 0（勝方）                  → 原地不動，Stage 8
站在自家據點上                   → 原地不動，Stage 8
否則 sub_1487B 找退路
  找不到                         → ★ 壞滅
  找到 next                      → 目標改成 next、設「下一步要重算」
      兵力 ≤ 300 或 next ＝ 首都 → Stage 10（回首都補兵）
      否則                       → Stage 8（等士氣）
```

⭐ **敗方一次只退一站**，而且那一站必須是自己的地。
「退不了」與「被打光」在原版是同一個結局。

## 2. `sub_1487B`：回家路上的下一站

```
capital = 勢力記錄 +0x03；＝ 0xFF ⇒ 失敗（沒有首都就無處可退）
起點 = [si+0Eh]
    < 800h（站在節點上）⇒ 起點就是它
    ≥ 800h（走在路上，那是連結記錄的位址）⇒ 從這條邊的兩端挑（§2.1）
loc_1491B 廣度優先找路（起點 → 首都）
    回 carry ⇒ next ＝ 首都本身，直接成功（不再檢查歸屬）
    否則方向（±4）決定讀 +6 還是 +8 那一槽 ⇒ next
next 不是自己的據點 ⇒ 失敗
```

**目標是首都，不是攻擊目標。** 兩個歸屬檢查各擋一種情況：
出發那一格的鄰接要是自己的、下一站也要是自己的。

### 2.1 ⭐ 走在路上時，起點挑的是「**B 端優先**」，不是出發那一端

```asm
                mov     dl, [si+1]            ; dl ＝ 自己的勢力
                mov     bx, [si+0Eh]
                mov     cx, bx
                cmp     bx, 800h
                jb      short loc_148E5       ; < 800h ⇒ 站在節點上，起點就是它
                mov     cx, [bx+6]            ; cx ← A 端
                mov     bx, [bx+8]            ; bx ← B 端
                mov     di, cx / shl di,1 ×2
                cmp     dl, es:[di+841h]
                jz      short loc_148C4       ; A 是自己的 ⇒ cx 留著 A
                mov     cx, bx                ; 否則 cx ← B
loc_148C4:
                mov     di, bx / shl di,1 ×2
                cmp     dl, es:[di+841h]
                jz      short loc_148D7       ; ⭐ B 是自己的 ⇒ 用 B
                cmp     bx, cx
                jz      short loc_14903       ; B 不是自己的、而且 cx 也是 B
                                              ;   ⇒ 兩端都不是自己的 ⇒ 失敗
                mov     bx, cx                ; 否則用 cx（＝ A，前面驗過是自己的）
loc_148D7:      call    loc_1491B             ; 從這個起點往首都找路
```

⇒ 判準是**這條邊的兩端誰屬於自己**，跟「軍團從哪一端出發、正朝哪個方向走」
完全無關。**兩端都是自己的時候拿 B 端**——那可能是軍團剛離開的那一站，
也可能是它正要去的那一站。

⚠ **「出發那一端」不是等價的判準**：只有一端屬於自己時兩者同解，
兩端都是自己的邊上才會岔開，而那正是「敵人深入自家領地」的局面。
開局的道路表上這種邊有 80 條（§6），不是罕見情況。

## 3. 這支不是 Stage 10 用的

`sub_1487B` 的呼叫者只有兩個：`sub_1474A`（戰後）與
`sub_14DA4`（據點失守時把受影響的軍團調頭）。

**Stage 10／11 走的是另一條路**：`sub_144A9`／`sub_144D6` 直接
`mov [si+20h], bh`（bh ＝ 首都）＋ `or byte ptr [si], 2`，
一次把目標設成首都，不逐站。remake 的 `headHomeResupply`／
`arriveDisband` 與這兩支一致。

## 4. remake 實作

| 項目 | 作法 |
|---|---|
| **起點** | `World.retreatOrigin(i)`：站在節點上就是它；走在路上（`LinkAddr != 0`）時用 `roads.EdgeByLink` 查出兩端，**先看 B 端再退回 A 端**，兩端都不是自己的 ⇒ 失敗（§2.1）|
| 找下一站 | `World.nextHopHome(i)`：`roads.Route(起點, 首都)` 的第 2 個節點；沒有首都、沒有下一站或下一站不是自己的 ⇒ −1 |
| 廣度優先回 carry | `Route` 回 nil 或長度 < 2 ⇒ 直接回首都（對應 `loc_1490C`）|
| 戰後處理 | `World.retreatOrPerish(i, won)`：回傳 true 表示「退不了 ⇒ 壞滅」，並在成功時 `March` 到下一站 ＋ 設 Stage |
| 接線 | `resolveCorpsBattle`／`fightGarrison`／戰術結算三處：`destroyed = 士氣判定 \|\| retreatOrPerish(...)`，再交給既有的 `afterBattle` |
| 沒有道路圖時 | `nextHopHome` 退回首都，等於一次走完。**規則層不讀檔案**，道路圖由呼叫端注入（`SetRoads`）|

⚠ **攻城時守方站在自己的城裡**，走「原地不動」那一支，
所以攻城的勝負與據點易主完全不受這條規則影響。

### 4.1 ⭐ 「站在自家據點上」要連座標一起問（2026-09-10）

原版的判準是節點欄 `+0x0E < 800h`（§2 的「現在在野外」）——行軍中那一欄
放的是**連結記錄的位址**，一定 ≥ `800h`。remake 的 `Node` 不是這樣：
它在行軍中**留著出發／中繼據點的編號**，所以
`army.KindOf(Node) == CityNode` 對「走在路上的軍團」也成立。

判準因此改成 `World.onCity(i)`：`Node` 是據點**而且**座標就在那個據點上。

⚠ 這個判準在**城外對峙**（[`175`](175-encounter-standoff-countdown.md)）
之下特別要緊：軍團停在據點前一格，`Node` 還是自家的上一站，
只看它就會把攻方讀成「站在自家城裡」而不退。
