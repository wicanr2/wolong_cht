## 1. `sub_1474A` 的後半段

戰鬥結束後**兩邊各跑一次**（`sub_15130` 呼叫兩次，結果進 `ah` 的
bit 0／bit 1）。`cl` 是勝敗旗標：

```
士氣 0 或大將槽兵力 0            → 壞滅
cl == 0（勝方）                  → 原地不動，Stage 8
站在自家據點上                   → 原地不動，Stage 8
否則 sub_1487B 找退路
  找不到                         → ★ 壞滅
  找到 next                      → 目標改成 next、設「下一步要重算」
      兵力 ≤ 300 或 next ＝ 首都 → Stage 10（回首都補兵）
      否則                       → Stage 8（等士氣）
```

⭐ **敗方一次只退一站**，而且那一站必須是自己的地。
「退不了」與「被打光」在原版是同一個結局。

## 2. `sub_1487B`：回家路上的下一站

```
capital = 勢力記錄 +0x03；＝ 0xFF ⇒ 失敗（沒有首都就無處可退）
目標 = [si+0Eh]
    < 800h（站在節點上）⇒ 目標就是它
    ≥ 800h（走在路上，那是連結記錄的位址）⇒ 這條邊的**兩端**都當目標（§2.1）
loc_1491B 廣度優先，⭐ **從首都往外搜**，碰到任一個目標就停
    目標之一就是首都 ⇒ 回 carry ⇒ next ＝ 首都本身
    否則回傳最後走過的那條邊，方向（±4）決定讀 +6 還是 +8 那一槽 ⇒ next
next 不是自己的據點 ⇒ 失敗
```

**目標是首都，不是攻擊目標。** 兩個歸屬檢查各擋一種情況：
出發那一格的鄰接要是自己的、下一站也要是自己的。

### 2.1 ⭐ 走在路上時，回家的路接在**離首都近的那一端**

```asm
                mov     dl, [si+1]            ; dl ＝ 自己的勢力
                mov     bx, [si+0Eh]
                mov     cx, bx
                cmp     bx, 800h
                jb      short loc_148E5       ; < 800h ⇒ 站在節點上，就是它
                mov     cx, [bx+6]            ; cx ← A 端
                mov     bx, [bx+8]            ; bx ← B 端
                … A 不是自己的 ⇒ cx ← B ；B 不是自己的 ⇒ bx ← cx
                … 兩端都不是自己的 ⇒ loc_14903（STC）
loc_148D7:      call    loc_1491B
```

⭐ **`bx` 與 `cx` 不是「起點」，是廣度優先的兩個「終止條件」**：

```asm
loc_1491B:      cmp     ax, bx / jz → STC     ; 目標之一就是首都 ⇒ 回 carry
                cmp     ax, cx / jnz → 繼續
loc_14925:      mov     si, ax                ; ⭐ 從**首都**開始搜（ax ＝ 首都 × 8）
                mov     cs:word_149B8, bx     ; 兩端各寫進一個 inline 立即值
                mov     cs:word_149BE, cx
                mov     cs:byte_149D2, dl
```

⚠ 那三行寫的是**後面幾行的運算元**——`byte_149B6` 起整段是自我修改碼，
IDA 因此解成資料（`CLAUDE.md` §7 第 28 條）。展開後是
`cmp si, <bx> / jz …` ＋ `cmp si, <cx> / jz …`：**搜到任一端就停**。

⇒ 兩端都屬於自己時，**先被搜到的那一端 ＝ 離首都近的那個**勝出；
只有一端屬於自己就只找那一端；兩端都不是自己的地就退不了。

⭐ **搜到之後直接取那一端當下一站**，不再往前算一步。方向那兩行分得出來：
站在節點上走 `cmp ax, 4`、走在路上走 `cmp ax, 0FFFCh`——**判準相反**，
所以前者取的是「往首都的那一端」（＝ 往首都走一步），後者取的是
「被搜到的那一端」（＝ 軍團腳下這條邊的端點）。兩者的語意一致：
**都是往首都方向退一站**，差別只在走在路上時那一站就是這條邊的端點。

⇒ 三種讀法在 a（首都）—b—c、軍團走在 b—c 上時互相分得開：
退到 **b**（正解）／退到 **a**（把端點當起點又算一步）／退到 **c**
（固定取 `+8`）。§5.2 的兩組原版實測都指向第一種。

## 3. 這支不是 Stage 10 用的

`sub_1487B` 的呼叫者只有兩個：`sub_1474A`（戰後）與
`sub_14DA4`（據點失守時把受影響的軍團調頭）。

**Stage 10／11 走的是另一條路**：`sub_144A9`／`sub_144D6` 直接
`mov [si+20h], bh`（bh ＝ 首都）＋ `or byte ptr [si], 2`，
一次把目標設成首都，不逐站。remake 的 `headHomeResupply`／
`arriveDisband` 與這兩支一致。

## 4. remake 實作

| 項目 | 作法 |
|---|---|
| **走在路上** | `World.retreatEndpoint(i, capital)`：用 `roads.EdgeByLink` 查出兩端，取**屬於自己而且離首都近**的那一個——它**就是下一站**。兩端都不是自己的 ⇒ −1（§2.1）|
| 站在節點上 | `World.nextHopHome(i)`：`roads.Route(節點, 首都)` 的第 2 個節點；沒有首都、沒有下一站或下一站不是自己的 ⇒ −1 |
| 廣度優先回 carry | `Route` 回 nil 或長度 < 2 ⇒ 直接回首都（對應 `loc_1490C`）|
| 戰後處理 | `World.retreatOrPerish(i, won)`：回傳 true 表示「退不了 ⇒ 壞滅」，並在成功時 `March` 到下一站 ＋ 設 Stage |
| 接線 | `resolveCorpsBattle`／`fightGarrison`／戰術結算三處：`destroyed = 士氣判定 \|\| retreatOrPerish(...)`，再交給既有的 `afterBattle` |
| 沒有道路圖時 | `nextHopHome` 退回首都，等於一次走完。**規則層不讀檔案**，道路圖由呼叫端注入（`SetRoads`）|

⚠ **攻城時守方站在自己的城裡**，走「原地不動」那一支，
所以攻城的勝負與據點易主完全不受這條規則影響。

### 4.1 ⭐ 「站在自家據點上」要連座標一起問（2026-09-10）

原版的判準是節點欄 `+0x0E < 800h`（§2 的「現在在野外」）——行軍中那一欄
放的是**連結記錄的位址**，一定 ≥ `800h`。remake 的 `Node` 不是這樣：
它在行軍中**留著出發／中繼據點的編號**，所以
`army.KindOf(Node) == CityNode` 對「走在路上的軍團」也成立。

判準因此改成 `World.onCity(i)`：`Node` 是據點**而且**座標就在那個據點上。

⚠ 這個判準在**城外對峙**（[`175`](175-encounter-standoff-countdown.md)）
之下特別要緊：軍團停在據點前一格，`Node` 還是自家的上一站，
只看它就會把攻方讀成「站在自家城裡」而不退。

### 5.2 ⭐ 走在路上退到哪：兩組原版實測

兩組都是「跑到某一刻 → `siege:攻方,據點` 開一場打得輸的仗 → `corps` 讀
戰後的目標欄」。收據在 `workplace/parity/retreat/`。

| | 軍團 | 走在哪條邊 | 兩端歸屬 | 首都 | 兩端到首都 | **戰後目標** |
|---|---:|---|---|---:|---|---:|
| 甲 | 1（勢力 11）| `14—16`（`+0x0E` ＝ `0970h`）| 11／11 | 29 | 16 近、14 遠 | **16** |
| 乙 | 39（勢力 0）| `85—88`（`+0x0E` ＝ `0F60h`）| 0／0 | 82 | 85 近、88 遠 | **85** |

⭐ **兩組都退到「離首都近的那個端點」本身**，而不是從那一端再往首都走一步
（甲會是 23、乙會是 82），也不是固定取 `+8`（甲會是 16——這一組剛好同解，
乙會是 88——這一組分得開）。

| 讀法 | 甲 | 乙 | 對得上實測嗎 |
|---|---:|---:|---|
| **離首都近的端點本身** | 16 | 85 | **兩組都對** |
| 端點當起點再走一步 | 23 | 82 | 兩組都錯 |
| 固定取 `+8`（B 端）| 16 | 88 | 甲對乙錯 |

⚠ **一組樣本不夠。** 甲那一組「離首都近的端點」與「固定取 B 端」同解，
只看它會得到一個自洽但錯的規則；乙才把兩者分開。

另有一組只驗到一半的：§5.1 的軍團 19 走在 `122—129` 上（A 端 122 屬於
勢力 10、B 端 129 屬於它自己），退到 129——只有一端屬於自己，三種讀法
同解。長時間軸的五個取樣點裡，走在路上的軍團大多落在這種邊上。
