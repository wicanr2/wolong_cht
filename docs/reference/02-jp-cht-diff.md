# 02 — 日中對照：`TALK.DAT` 第一批發現

**狀態：第一批 15 則譯文缺陷已定案，全量對照未做。**

- 日期：2026-08-07
- 輸入：`translations/extract/talk-dosv.json`（cp950）、`talk-pc98.json`（cp932）
- 方法：兩版索引一一對應（各 1,022 則），逐則比對變數標記與內容
- 推論等級：標在每一項

## 1. 為什麼這條線這麼便宜

PC-98 日文原版與松崗繁中版的 `TALK.DAT` **索引完全一一對應**——
同一個索引就是同一則訊息的兩種語言。**不需要做句子對齊**，
`talkdat.py diff` 直接就能跑出差異。

這是 §3.10（`CLAUDE.md`）「23 檔 byte-for-byte 相同」那條發現的延伸：
松崗版是移植不是重寫，連訊息表的槽位順序都照搬。

## 2. 變數標記不一致的 12 則（confirmed 有差異）

`talkdat.py diff` 跑出來 1,022 則裡有 12 則的變數標記集合不同。
**每一則都是實質的翻譯缺陷**，不是排版差異。

### 2.1 中文漏掉變數，台詞變成沒有主詞（6 則）

`#718`、`#720`、`#721`、`#723`、`#724`、`#751`

```
日  まだまだこれからだっ ／ {1}覚悟！！！！
中  才剛要開始呢！覺悟吧 ／ ！！！！
```

日文是「{武將名}，覺悟吧！」，中文把名字整個丟掉。
戰場上五則不同武將的台詞因此變成同一句。

`#751`：

```
日  {6}なんの！ ／ これしきのことで参る ／ {1}では無いわ！
中  {6}沒什麼！我可不會這樣 ／ 就輸的！
```

日文是「我{1}可不是這種程度就會倒下的人」，中文同樣丟掉了名字。

### 2.2 中文漏掉勢力／據點名（3 則）

| 則 | 日文 | 中文 |
|---|---|---|
| `#290` | それでは引続き**{2}**の内政を行います。 | 那麼我就繼續進行內政了。 |
| `#195` | うむ、今ならば**{3}**も断りはしまい。 | 事到如今，不答應也不行了 |
| `#321` | **{6}**外交資金が底を尽きました。金{6}{7}程掛かりそうなのですが | 外交資金以用完了，大約需要金額{6}{7}左右。 |

`#321` 的中文還有一個錯字：「以用完了」應為「已用完了」。

### 2.3 變數編號被換掉（1 則）

`#223`：日文用 `{4}`，中文用 `{3}`。

```
日  それは明案だ！{4}殿ならばきっと協力してくれるに違いない
中  這是好提案！{3}大人必定會出力協助。
```

**這一則要特別驗。** 如果 `{3}` 與 `{4}` 指的不是同一個東西，
中文版在這裡會顯示錯誤的名字。變數語意還沒解（`docs/formats/01` §7），
先掛著。

### 2.4 中文多出變數 / 內容被搬走（2 則）

`#192`、`#322`。`#192` 見下一節。

## 3. `#192`–`#195` 譯文錯位（強證據）

停戰外交那一段，中文版的內容整體位移了：

| 索引 | 日文（PC-98 原版） | 中文（松崗） | 中文其實對應到日文哪一則 |
|---|---|---|---|
| #190 | 他国と交戦中？そのような報告は入っておらぬぞ！ | 正和他國交戰？我可沒接到那種報告啊！ | #190 ✅ |

| **#192** | 他国と交戦中？そのような報告は入っておらぬぞ！ | 現在停戰的話，就能賣個人情給{3}吧，好，准許停戰。 | **#193** ❌ |

## 5. 已排除的誤判

### `#225` 不是錯字

第一版用 Python 的 `big5` 解碼，`#225` 出現 `這哪<f9>堿O什麼好策略？`，
看起來像松崗版打錯字。實際上 `F9D8` 是 Big5 罕用字區的**「裏」**，
原文是「這哪裏是什麼好策略？」，完全正確。

**錯的是解碼器不是原版。** 改用 `cp950` 之後正常。
細節見 `docs/formats/01` §4。

  「原文、松崗譯文、校訂後譯文、依據」，不要直接改。
- **變數語意解出來之前不要改 `#223`。** `{3}` 與 `{4}` 是不是同一個東西未知。
- **`#192`–`#195` 的錯位要先確認遊戲怎麼取用這幾則**（是依索引直取還是隨機挑
  變體），才知道玩家實際會不會撞到。反組譯 `KI.EXE` 的訊息輸出常式時一併查。
