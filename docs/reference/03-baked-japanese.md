# 03 — 燒進美術裡的日文：松崗版沒重繪的部分

**狀態：已確認的缺口：標題橫幅「臥竜伝」兩版相同（松崗沒重繪）。**

- 日期：2026-08-07
- 方法：兩版逐檔比對（`docs/re/01`）＋ 解出的圖像
- 推論等級：**檔案相同是 confirmed；哪些圖裡有日文要逐張看過才算數**

## 1. 為什麼會有這種缺口

松崗版是移植不是重寫——**23 個檔在兩版之間 byte-for-byte 完全相同**
（`docs/re/01` §2）。文字如果燒進了美術，這些檔就不會被改，
中文版的畫面上就會留著日文。

**兩版 diff 直接告訴我們哪些美術被重繪過**：

| 素材 | 兩版比對 | 結論 |
|---|---|---|
| `END_S3`–`END_S11` | 九張全不同 | 有燒字，**松崗重繪過** |
| `END_S1`／`S2`／`S12` | 相同 | 沒有燒字 |
| `OPEN_S1`–`S6` | 六張全相同 | 開場沒有燒字，文字是疊繪的 |
| **`ICONGRF.DAT`** | **相同** | **沒重繪 → 裡面的日文留著** |
| `KAOGRF`／`KYOGRF`／`IVENTGRF` | 相同 | 純圖像，目前看過的都沒有文字 |

## 2. 已確認的缺口

### 2.1 主畫面標題橫幅（`ICONGRF.DAT` 段 0，640×32）

![標題橫幅](../images/icongrf-r0-banner.png)

橫幅上寫的是**「臥竜伝」**——日文漢字，不是「臥龍傳」。
這條橫幅在主畫面最頂端（繪製時 `bx = 0`，VRAM 偏移 0），
**玩家整場遊戲都看得到**。

右側的「年 月 日」三個字倒是中日通用，不必改。

## 4. remake 怎麼處理

**這一項是 remake 相對於原版的實質改進**，要在文件裡標記為 remake 差異
（`CLAUDE.md` §1）：

- 原版素材**保持不動**（保存原則），中文版的橫幅另外做一份，執行時依語系選用。
- 兩份都要留：玩日文原版時用原圖，玩繁中版時用重繪版。
- 重繪要對齊原版的 640×32 尺寸與 16 色調色盤，不要改成高解析
  ——那會與周圍的原版素材風格衝突。
