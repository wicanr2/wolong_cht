## 4. Android 完整版的音樂就是原版 ogg

使用者 2026-08-30 特別點名這件事。實測：

- APK 內含 `assets/gamedata/audio/bgm-*.ogg` 等 **32 個 ogg**，
  與四個桌面遊戲包同一批檔案。
- 這些 ogg 是 remake 自己的 OPL3 合成（`tools/bgm2ogg.sh` 從使用者自備的
  `BGM.DAT` 算出來，[`../spec/29`](../spec/29-audio.md)），演奏的是原版的曲子。
- 手機版走的是與桌面同一份 `internal/ui/sound`：
  `mobile/wolong/game.go` 的 `sound.Open(audioDir)` ＋ `PlayMusic`。

**所以這一項不需要改任何程式**，是既有行為；記在這裡是為了下次不必再查一次。

## 6. ⭐ 這一批第一步就會停——`rebuild()` 的白名單少一行

`release_all.sh` 的第一步是 `release_all_fs.py rebuild`，它只清「已知的發行輸出」，
遇到不認得的項目就停。而 `finalise()` 會把 `LICENSE` 寫進發行根目錄，
**`LICENSE` 卻不在那份白名單裡**——症狀是完整重建在第一步就停：

```
dist-all 含未列入發行輸出的項目，拒絕清理：LICENSE
```

授權定案那一輪（`10` §6）只跑過 `refresh`，沒有跑過 `rebuild`，
所以這個洞從 08-28 埋到 08-30 要重打包時才浮出來。
**寫入端與清理端是兩份清單，加了一個檔案要同時改兩邊。**
