## 4. 這一批重建了兩顆映像

`tools/release_all.sh` 與 `tools/android_build.sh` 的預設標籤都帶日期，
而那兩顆映像**不在機器上**——`20260827` 那一批的 macOS 映像被清掉了。

```sh
docker build -t wolong-osxcross-go:20260828 -f docker/osxcross-go/Dockerfile docker/osxcross-go
docker build --network host -t wolong-go-android:20260828 docker/android
```

兩顆都因為層快取而很快建完（`osxcross-go` 幾乎只是 COPY）。
`docker/osxcross-go/Dockerfile` 的抬頭現在留著**從這一份建過的標籤清單**——
發行紀錄會引用當批的那一顆，沒有那份清單的話 `tools/stale_scan.py`
會把舊紀錄裡的標籤判成過期。

### 5.1 順手補上兩支腳本

先前有兩批推廣片素材**沒有留下產生它們的命令**：主預告的五張靜態圖，
與四段語系畫面。重拍要先重新猜一次旗標，而猜錯的症狀是「圖看起來很像」。

| 腳本 | 補了什麼 |
|---|---|
| `tools/promo_stills.sh`（新增）| 五張靜態圖的旗標寫死在腳本裡。**驗過**：用它重拍一次，五張與版控裡的舊圖**逐位元組相同** |
| `tools/promo_live_capture.sh` | 四段語系 ＋ 實機對照片要的 `newgame`／`form`／`march` 三段一併納入；「不重複張數」的下限改成逐段設定 |

⭐ **下限要逐段設定的理由是量出來的**：語言段會動的只有時鐘，
而「130 張裡有幾張不一樣」還跟**當下的機器負載**有關——同一條命令
在閒置的機器上量到 26 張，在 load 90 的機器上量到 17 張。
`newgame`／`form`／`march` 三段更極端：**不重複張數就是 1，而那是對的**——
編成與行軍指示都是非常駐視窗，開著的時候原版的時鐘停住
（[`../spec/13`](../spec/13-main-window-toggles.md)），畫面連日期都不會變。
