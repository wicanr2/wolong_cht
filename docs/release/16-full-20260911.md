## 3. ⚠ 三件要知道的事

1. **畫面對拍落後規則對拍**：主畫面 `map` 101 px（0.07%）、野戰
   `field` 190 px 與 `sb-minimap` 128 px（**FAIL**）、攻城那一組
   **重跑不出來**。三組都用 2026-09-11 之前的程式碼重截驗證過，
   **數字一模一樣**——不是這一輪造成的
   （[`../playtest/120`](../playtest/120-screen-parity-retest-20260911.md)）。
2. **macOS 是用別的專案的 osxcross image 建的**
   （`kol-osxcross-go:20260907`），因為這台機器上沒有
   `wolong-osxcross-go:20260828`。檔頭是 Mach-O x86-64／arm64，
   但**工具鏈與前幾批不同**，要重現得記這一行。
3. ⛔ **`dist-all/` 裡 2026-09-08 的 16 個 `v.*` 目錄被覆蓋掉了**。
   `release_all_fs.py promote` 是「整個目錄交換 ＋ 成功後刪備份」，
   而 `rebuild` 的「未知目錄拒絕清理」護欄只保護 staging，**保護不到
   正式目錄**。那些是產物、tag `v.1.0.18-20260908` 還在，可以重建。
