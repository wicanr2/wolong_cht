## 1. 為什麼只有 AppImage

使用者要的就是這一支。`tools/release_appimage.sh` 存在的理由也是這個——
它只做 Linux amd64，其餘產物一個都不碰，不需要推廣片與 APK 到位。

代價寫在這裡而不是留在對話裡：**批次不再是同一份程式碼**。
manifest 多了一格 `mixed_build_dates` 記這件事，機器讀得到；
要回到一致批次就跑 `tools/release_all.sh <日期>` 重建全部。
