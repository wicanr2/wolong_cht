## 交付

| 位置 | 內容與界線 |
|---|---|
| `full/` | 三個可直接啟動的完整版封包，含原版資料、字型與音訊；只限本機，不上傳 GitHub |
| `release/` | 三個不含原版素材的引擎包、RRSAL-1.0、第三方條款、安裝文件、雜湊與清單 |
| `promo/` | 56 秒桌面影片、分鏡、來源、接觸表及影音檢查；含原版音訊，留在本機 |
| `verification/` | 本批 AppImage 正常操作、公開包啟動、來源一致性與封包驗收；前版規則證據明確分開 |

## 驗收

- 完整 AppImage：設定重啟 0 像素差異、結果頁提前關閉成功、同程序第二場自然遭遇
  30 秒倒數觀察區間 27.27–30.80 秒；正常操作未使用強制勝負。
- 公開 AppImage：帶自備 `-orig`／`-font` 參數可啟動；實際執行檔雜湊與本批相同。
- 三平台包：架構、每檔雜湊、授權與素材內容核對；公開包排除原版資料、字型與音樂。
- 完整戰況延用 v.1.0.17 的已存證規則重播；不把前版收據換名成本批重新對拍。
- 影片：H.264／AAC、1280×720、30 fps、56 秒，音畫等長；平均 -17.3 dB、峰值 -1.4 dB。
  未檢出黑段與兩秒以上靜音；停格來源為字卡、設定截圖與歷史場景，見推廣片紀錄。
