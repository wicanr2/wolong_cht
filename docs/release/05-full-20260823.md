## 3. ⭐ 我拆錯了一道柵欄

第一版的音樂修正只做了「找得到就自己用」，於是完整包一裝好，
`tools/release_smoke.sh` 立刻掛掉：容器裡沒有音效卡，遊戲開音訊 →
`RunGame` 回錯 → `log.Fatal`，**一張截圖都沒有**。

而 `-audio` 旗標旁邊本來就寫著這件事：

> 沒有音效裝置時 `RunGame` 會直接帶著 ALSA 的錯誤結束——無頭驗收與 CI 全部會掛。

**「留白＝靜音」是一道柵欄，不是疏漏。** 拆之前要先重建它擋住了什麼。

修法是加第三件事：**驗收模式不出聲**（`-shot` 或 `-frames-dir` 有值就開靜音模式）。
⚠ 關掉的是**輸出**不是**狀態**——第一版直接清空音檔目錄，
系統選單「音　效」那一格因此印成「未接入」，對拍差 272 px
（[`../spec/29`](../spec/29-audio.md) §5.1、[`../playtest/49`](../playtest/49-parity-retest-20260827.md) §2）。
判準是**用途**不是環境——要截圖就不需要聲音，關掉沒有代價；
不用「有沒有顯示器」（Xvfb 有 DISPLAY 卻沒有音效卡），也不猜 `/dev/snd`。
