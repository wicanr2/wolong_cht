# 推廣影片

所有影片皆為 H.264／AAC MP4。三支主片是 1280×720、60 秒；
`wolong-remake-yt-comparison.mp4` 是 1280×400、24 秒的代表幀比較短片。影片內容以 remake
的實機畫面、驗收畫面與本專案原創合成音訊製作；不含原版音樂或音效。

- `wolong-remake-trailer.mp4`：remake 主預告。
- `wolong-remake-classic-revival.mp4`：以「讓經典再現」為主題的代表幀比較。
- `wolong-remake-yt-comparison.mp4`：YouTube 原版代表幀與 remake 的結構／色彩比較。
- `wolong-remake-dosv-live-comparison.mp4`：松崗 DOS/V 與 remake 的實機動態比較；原版側為
  使用者指定的推廣比較素材，不是同日期／同輸入的無損逐像素 parity 證據。

各影片的 SHA-256 請見上層 `SHA256SUMS.txt`。完整的研究範圍與重播紀錄仍在原始專案的
`docs/promo/`；此發行根目錄只保留可播放成品與必要說明。
