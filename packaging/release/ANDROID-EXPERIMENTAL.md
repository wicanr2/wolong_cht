# Android 版（未簽章的 debug 包）

這個 APK 是**完整的遊戲**，不是操作 shell：大地圖、據點小卡、武將／據點／勢力／軍團
四張一覽、軍團編成、進言、45 度視角的戰場、四槽存檔、事件訊息，以及三種會擋住世界的
決定（遭遇、外交提案、撥款請求）都在裡面。

規則層與桌面版**是同一份程式碼**，不是另一套實作。驗收方式是拿世界指紋對拍：
同一個劇本、同一個亂數種子，跑到第 1／60／120 幀時模擬器算出來的 SHA-256
與桌面版逐字相同。

## 界線

| 項目 | 現況 |
|---|---|
| 簽章 | **debug 簽章**，不是上架用的正式簽章 |
| 驗收 | 只在 Docker 裡的 Android 模擬器（x86_64、API 34）跑過；**沒有實機驗收** |
| ABI | `arm64-v8a`、`x86_64`；minSdk 29、targetSdk 35 |
| 16 KB page size | `.so` 的 LOAD 段是 16 KB 對齊，Android 15 的 16 KB 裝置載得起來 |
| 原版資料 | **不含**。第一次啟動會請你指定放著松崗 DOS/V 資料的資料夾，程式把它匯進 App 私有目錄 |
